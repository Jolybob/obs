# Bunta
Ce coracle tissé à la main ne semble assez grand que pour accueillir une seule personne. Cependant, lorsque vous pilotez le bateau, vous pouvez embarquer jusqu'à une douzaine de passagers, qui voyagent dans votre âme. Ils sont conscients de tout ce que vous ressentez et peuvent communiquer par télépathie avec vous ou les autres passagers, mais ils ne peuvent pas agir, sauf pour Se souvenir et utiliser des actions qui ne requièrent que l'utilisation de leur esprit (déterminées par le MJ). Ils peuvent quitter votre âme ou vous pouvez en retirer n'importe quel nombre de passagers en utilisant une action unique - qui possède le trait concentration - en les faisant apparaître dans un espace adjacent à *Bunta*. Si vous quittez *Bunta* ou si vous êtes tué, toutes les créatures présentes dans votre âme sortent immédiatement de votre corps et se retrouvent dans l'espace disponible le plus proche. Si vous quittez *Bunta* après l'avoir piloté, vous pouvez utiliser une unique action, qui possède le trait concentration, pour stocker le bateau dans votre âme. Vous pouvez le retirer de votre âme dans une case adjacente avec une autre action de ce type. Si *Bunta* subit suffisamment de dégâts pour être détruit, il éclate en brume dorée, puis se reforme pendant 24 heures dans l'âme de son dernier pilote.
