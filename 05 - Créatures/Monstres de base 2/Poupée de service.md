# Poupée de service
Les poupées de service comptent parmi les formes les plus courantes de poupées. La plupart d'entre elles se trouvent dans les métiers créatifs, en particulier chez les tailleurs et les cordonniers.





Les poupées sont des simples créatures artificielles créées pour aider leurs créateurs dans les tâches les plus élémentaires.
