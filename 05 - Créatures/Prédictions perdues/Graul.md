# Graul
Les cavernes et les tunnels labyrinthiques sous Heaume abritent de nombreux dangers, dont l'insidieux graul est l'une des espèces indigènes les plus remarquables. Ces prédateurs embusqués hautement spécialisés possèdent un camouflage naturel qui les rend totalement imperceptibles à toutes les formes de vision dans le noir, tandis qu'ils flottent silencieusement dans l'obscurité, ce qui leur permet de chasser les créatures qui s'appuient sur des sens spécialisés pour naviguer dans leur domaine sans lumière. Étonnamment rusés, les grauls savent utiliser leurs talents magiques d'illusion et de mimétisme pour séparer leurs proies potentielles de leurs alliés et des sources de lumière.
