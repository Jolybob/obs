# Dauphin de selle
Les dauphins de selle furent domptés pour la première fois dans les Chaînes, faisant partie d'une embuscade entre des pirates rivaux. Les chevaucheurss de dauphins de selle sont encore un spectacle inhabituel car des années de formations sont nécessaires pour arriver à maîtriser ce genre de compétences.
