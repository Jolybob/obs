# Troupe de reconnaissance bourbérine
Les troupes de reconnaissance bourbérines avancent devant les autres troupes bourbérines pour évaluer le terrain. Elles s'engagent parfois si elles pensent pouvoir rapidement vaincre une force ennemie.
