# Choeur angélique
Bien que les anges choristes se contentent de chanter leurs hymnes en Nirvana, ils doivent parfois se rendre dans le plan mortel pour apporter le réconfort nécessaire à ceux qui mènent un combat vertueux contre les forces du mal. Un Choeur angélique agit souvent comme soutien pour les armées qui ont gagné la faveur des royaumes célestes.
