# Rempart d'archons
Les Rekheps, également connus sous le nom d'archons boucliers, s'opposent à toute assaut fiélonne sur leur plan, mais voyagent occasionnellement vers l'Univers des mortels pour protéger les faibles. De grandes formations de rekheps sont un incroyable spectacle à contempler lorsqu'ils verrouillent leurs formes de bouclier en place pour affronter les pervertis.
