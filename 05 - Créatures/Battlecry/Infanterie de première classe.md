# Infanterie de première classe
Les soldats qui participent à plusieurs campagnes de guerre acquièrent l'expérience nécessaire pour devenir les meilleures forces combattantes de leur armée. Les troupes d'infanterie de première classe sont déployées sur les champs de bataille où la victoire est d'une importance capitale.
