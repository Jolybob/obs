# Uthul
Un uthul a le plus souvent l'aspect d'un sombre nuage parcouru de brusques éclairs et dans lequel tourbillonnent des débris volants. Leur nature est clairement élémentaire mais on les trouve presque toujours dans l'Univers où ils se cachent dans les formations nuageuses naturelles, plus particulièrement dans les orages.
