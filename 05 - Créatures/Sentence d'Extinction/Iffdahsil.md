# Iffdahsil
L'horreur rampante portant le nom d'Iffdahsil est un shoggoth mort-vivant qui hante le caveau du désert Noir depuis des millénaires. Iffdahsil est surtout évoqué dans les légendes drows qui terrorisent les elfes depuis leur plus jeune âge.
