# Délivrer
**Fréquence** Une fois par heure


**Déclencheur** Vous faites un test pour mettre fin ou contrer un effet avec les états [[Confus]], [[Contrôlé]], [[Entravé]], [[Fasciné]], [[Immobilisé]] ou [[Paralysé]].





**Effet** Vous lancez les dés deux fois et utilisez le meilleur résultat.
