# Retraite défensive
Vous appelez à effectuer une retraite prudente. Faites signe à tous les membres de votre escouade dans l'aura de votre bannière. Chacun peut immédiatement Faire un pas jusqu'à trois fois par une action gratuite. Chaque pas doit les éloigner d'au moins une créature hostile qu'ils peuvent observer et ne peut les rapprocher d'une créature hostile que si ce rapprochement est le seul moyen de se déplacer vers la sécurité (comme cela serait le cas s'ils étaient encerclés).
