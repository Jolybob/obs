# Lever le voile
**Conditions** Aucun ennemi ne vous observe.





**Effet** Vous vous déphasez dans les interstices, vous voilant vous-même de la réalité physique. Vous êtes [[Masqué]]. Vous pouvez utilisez cet état pour pous [[/act hide]]{Cacher} ou [[/act sneak]]{Être furtif} car votre disassociation de la réalité rend difficile de se concentrer sur vous. Si vous utilisez une action hostile, cet effet se termine après avoir terminé l'action. Sinon, cela dure pendant 1 minute.
