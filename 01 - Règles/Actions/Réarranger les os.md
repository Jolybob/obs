# Réarranger les os
Vous arrangez vos os sous la forme d'un squelette humanoïde de taille Petite ou Moyenne. Cela ne modifie pas vos Vitesses ordinaires, vos Frappes ou vos sens. Si vous portez des vêtements épais ou si vous vous faites passer pour un squelette, cela est considéré comme créer un déguisement pour utiliser l'action de Duperie pour Vous faire passer pour et accorde un bonus de statut de +1 à ces tests de Duperie.
