# Restaurer l'instant
**Déclencheur** Votre tour commence





**Effet** Dépensez un Point mythique. Faites les mêmes actions dans le même ordre, en utilisant les mêmes résultats sur les jets de dés pour résoudre ces actions que celles que vous avez entreprises lors de l'Instant préservé et appliquez les modificateurs à ces jets comme ils existent actuellement (pas ceux qui étaient les votre lorsque vous avez enregistré la boucle), mais à la maîtrise mythique. Les détails exacts de la manière dont vous accomplissez vos actions restaurées peuvent changer. Vous n'avez pas besoin de vous déplacer selon le même schéma ou sur la même distance en Répétant Marche rapide, par exemple pas davantage que vous devez répéter le Frappe contre le même ennemi que vous avez attaqué lors de votre première séquence d'actions, mais vous devez utiliser le même type de déplacement lorsque vous Marchez rapidement et vous devez utiliser le même type d'arme pour Frapper. Si vous êtes incapable à un endroit quelconque pendant votre tour d'entreprendre la prochaine action de la séquence, votre tour s'arrête et vous êtes [[Étourdi 1]]. Par exemple, si vous avez restauré l'exemple cité dans le don contre le wyrm de feu lors d'un round où vous combattez un ogre et que vous n'avez pas été capable de tenter une Frappe avec une épée longue contre l'ogre lors de votre deuxième action, vous devriez devenir Étourdi 1. De même, si à la fin de votre tour, il n'y avait rien à tenter d'Escalader, vous devenez Étourdi 1. Vous pouvez préserver et restaurer une action Lancer un sort, mais si vous ne lancez pas le même sort lorsque vous Restaurez l'instant, vous devenez Étourdi 1 (cependant, vous pouvez Lancer le sort à un rang différent).
