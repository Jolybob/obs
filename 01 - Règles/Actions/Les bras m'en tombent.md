# Les bras m'en tombent
Vous arrachez votre bras, le séparant inoffensivement de votre corps et vous le déposez dans une case adjacente. Vous pouvez également utiliser cette action pour rattacher votre bras sectionné s'il vous est adjacent ; il fonctionne immédiatement normalement. Si le membre détaché était à 0 Point de vie, il faut 10 minutes pour le rattacher au lieu d'une unique action.
