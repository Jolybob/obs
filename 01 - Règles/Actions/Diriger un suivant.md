# Diriger un suivant
Vous adressez un ordre à votre suivant, lui accordant 2 actions. Cette action possède le trait audible ou visuel en fonction de la méthode de communication utilisée, mais il doit posséder l'un ou l'autre. Vous pouvez Diriger votre suivant pour accomplir l'une des actions basiques suivantes : [[Bondir]], [[Chercher]], [[Deviner les intentions]], Faire un pas, Frapper, Interagir, Marcher rapidement, [[Ramper]], Relâcher, [[S'Échapper]], Se jeter à terre, Se relever. Il ne peut utiliser que les Frappes indiquées dans ses statitstiques. Les suivants qui obtiennent une vitesse de creusement ou une vitesse de vol peut utiliser Creuser ou Voler, respectivement. Vous pouvez aussi Diriger votre suivant pour qu'il utilise des actions de compétence pour lesquelles ils remplissent les prérequis. Finalement, vous pouvez diriger le suivant pour accomplir n'importe quelle action indiquée dans son bloc de statistiques. Contrairement aux actions de soutien des compagnons animaux, ces actions spéciales n'imposent pas de restrictions aux autres actions qu'un suivant peut utiliser lors de ce tour.
