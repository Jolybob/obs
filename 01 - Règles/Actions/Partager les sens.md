# Partager les sens
**Conditions** Votre eidolon est manifesté.





Vous projetez vos sens dans votre eidolon, vous permettant de percevoir à travers lui. Lorsque vous le faites, vous perdez toutes les informations sensorielles de votre propre corps, mais pouvez percevoir à travers le corps de votre eidolon jusqu'à 1 minute. Vous pouvez [[Révoquer]] cet effet.





**Spécial** Cette action possède le trait correspondant à la tradition de votre eidolon (arcanique, divine, occulte ou primordiale). Votre eidolon peut aussi utiliser cette capacité. Lorsqu'il le fait, il projette ses sens dans votre corps.
