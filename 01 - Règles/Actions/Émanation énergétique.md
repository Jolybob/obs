# Émanation énergétique
**Fréquence** Une fois par jour





De l'énergie jaillit de votre corps. Vous infligez @Damage[ceil(@actor.level/2)d6[@actor.flags.system.elementalHeartDwarf.damageType]|options:area-damage]{1d6 dégâts} à toutes les créatures adjacentes (@Check[reflex|against:class-spell|basic|options:area-effect] contre le plus élevé entre votre DD de classe ou votre DD de sort). Au niveau 3, puis tous les deux niveaux suivants, ces dégâts sont augmentés de 1d6.
