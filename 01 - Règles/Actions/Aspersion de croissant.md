# Aspersion de croissant
**Conditions** Vous maniez une arbalune





**Effet** Vous Frappez jusqu'à trois fois avec la version à distance de votre arbalune. Si elle se trouve actuellement dans sa configuration au corps-à-corps, vous pouvez passer à sa configuration à distance par une action gratuite avant de tenter ces Frappes. Vous devez déjà avoir un carreau dans la chambre pour chaque Frappe et vous pouvez Interagir pour changer pour une chambre de capacité différente par une action gratuite entre chaque Frappe. Chaque attaque est décomptée de votre pénalité d'attaques multiples, mais vous n'augmentez pas votre pénalité avant d'avoir porté toutes vos attaques.
