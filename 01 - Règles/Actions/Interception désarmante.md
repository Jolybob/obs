# Interception désarmante
**Conditions** Vous avez positionné vos poings pour parer


**Déclencheur** Un ennemi dans votre allonge vous cible, vous ou un allié, avec une Frappe d'arme.





**Effet** Vous tentez de [[Désarmer]] l'arme avec laquelle l'ennemi attaque. Vous bénéficiez d'un bonus de statut de +2 à ce test pour Désarmer et, si le test est réussi, l'attaque déclencheuse est interrompue. Si la tentative de désarmement est un succès critique et que vous disposez d'une main libre, vous pouvez attraper l'arme désarmée dans votre main au lieu qu'elle ne tombe au sol dans l'espace de la cible.
