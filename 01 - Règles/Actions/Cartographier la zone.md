# Cartographier la zone
Tant que votre groupe est parvenu avec succès à Reconnaître l'hexagone, vous pouvez utiliser cette activité pour créer une carte exacte de l'hexagone avec un test de Survie réussi (typiquement un DD qualifié ou expert). Lorsque vous avez une carte exacte de l'hexagone, le DD de n'importe quel test pour naviguer dans cet hexagone est réduit de 2.
