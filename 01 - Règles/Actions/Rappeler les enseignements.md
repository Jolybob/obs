# Rappeler les enseignements
La puissance accrue de votre psyché vous permet de vous rappeler toutes les leçons que vous avez jamais apprises. Vous cherchez dans votre esprit le bon enseignement, qui semble d'abord cryptique mais qui devient clair au moment le plus pertinent. Jusqu'au début de votre prochain tour, vous êtes considéré comme étant prêt à [[Aider]] tous les alliés se trouvant dans un rayon de 9 mètres autour de vous. Si vous utilisez la réaction Aider pour aider l'un d'entre eux pendant ce temps, vous faites un test d'Occultisme pour les [[/act aid skill=occultism traits=auditory,linguistic]]{Aider} en leur énonçant une leçon. La plupart des leçons prennent la forme de courts axiomes, de paraboles ou de dictons, ce qui signifie que les transmettre à votre allié confère généralement à votre réaction Aider les traits audible et linguistique.
