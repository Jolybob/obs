# Sourd
Vous ne pouvez pas entendre. Vous obtenez automatiquement un échec critique aux tests de Perception qui nécessitent que vous puissiez les entendre. Vous subissez une pénalité de statut de -2 à vos tests de Perception pour déterminer l'initiative et aux tests en rapport avec le son mais comptent aussi sur d'autres sens. Si vous accomplissez une action qui possède le trait audible, vous devez réussir un @Check[flat|showDC:all|dc:5] ou perdre l'action. Vous faites ce test après avoir dépensé l'action mais avant que tout effet ne soit appliqué. Vous êtes immunisé contre les effets audibles tant que vous êtes Sourd.
