# Dévier le cours du courant
**Déclencheur** Vous êtes blessé par une Frappe au corps-à-corps d'une créature dans votre allonge.





D'un geste rapide, vous vous adaptez promptement à une attaque comme le ferait le courant. Faites un test d'Athlétisme pour [[Repositionner]] la créature qui vous a infligé les dégâts déclencheurs. Si vous réussissez, vous pouvez faire un Pas par une action gratuite.
