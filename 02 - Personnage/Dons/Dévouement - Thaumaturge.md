# Dévouement - Thaumaturge
Vous avez découvert l'art caché de la thaumaturgie basique. Vous êtes qualifié en DD de classe de thaumaturge. Choisissez un implément. Vous pouvez l'utiliser pour Entrevoir une vulnérabilité, mais vous n'en obtenez pas ses avantages. Vous obtenez également quelques esoterica, vous permettant d'utiliser les actions esoterica. vous êtes qualifié, à votre choix en Arcanes, Nature, Occultisme ou Religion. Si vous étiez déjà qualifié dans ces dernières, vous êtes qualifié dans une compétence de votre choix. Vous obtenez l'action [[Entrevoir une vulnérabilité]].
