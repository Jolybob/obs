# Perdre vos chaînes
**Déclencheur** Un allié obtient l'état [[Agrippé]] ou [[Entravé]].





Vous suscitez la rébellion dans le cœur de vos alliés, les incitant à se libérer de leurs liens. L'allié déclencheur peut faire un test pour s'[[Échapper]] avec une maîtrise mythique.
