# Tir ricochet
Vous faites rebondir votre tir sur une surface proche pour frapper votre adversaire depuis un angle inattendu. Tentez une Frappe avec une arme à feu ou une arbalète. Lorsque vous déterminez si une cible obtient un abri contre cette Frappe, vous pouvez choisir une surface solide dans le premier facteur de portée de votre arme pour faire ricocher votre tir. Si vous le faites, vous déterminez l'abri de la cible à partir du point où vous faites ricocher votre tir plutôt qu'en partant de vous.
