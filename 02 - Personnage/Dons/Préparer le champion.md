# Préparer le champion
Votre volonté se manifeste sous la forme d'armes divines qui protègent et arment vos disciples. Lorsque vous obtenez ce don, choisissez un type d'arme ayant une signification particulière pour vous, comme une épée longue ou une serpe. Elle devient votre arme de prédilection. Vous et votre hiérophante considérez tous les deux cette arme comme une arme simple pour les besoins de la maîtrise. Vous et votre hiérophante obtenez l'effet critique spécialisé de votre arme de prédilection et vous infligez 1d6 dégâts spirituels supplémentaires avec les Frappes effectuées avec celle-ci. Si l'un de vos sorts de domaines actuel peut infliger un type de dégâts autre que spirituel, vous pouvez choisir qu'ils correspondent à ce type de dégâts (par exemple, envelopper votre arme de cendres sacrées qui infligent des dégâts de feu si vous avez le domaine du feu).
