# Apparition effrayante
Vos apparitions dramatiques peuvent effrayer les témoins.


Lorsque vous faites une Apparition surprenante, vous pouvez essayer de [[Démoraliser]] chaque adversaire dans les 3 mètres qui ne vous avait pas remarqué avant que vous ne Frappiez.
