# Pisteur féerique
Vous êtes exceptionnellement doué pour remarquer les techniques subtiles que les fées utilisent pour éviter d'être repérés. Vous obtenez un bonus de circonstances de +2 aux tests de Survie pour [[Pister]] les créatures féeriques, aux tests de Perception pour [[Chercher]] des fées [[Cachées]] et à votre test de Perception pour résister aux tentatives d'une créature féerique de [[Faire diversion]].
