# Ténacité nécromantique
Votre entraînement contre les effets nécromantiques vous permet d'éviter leurs pires conséquences. Si vous obtenez un succès sur un jet de sauvegarde contre un effet de nécromancie, il devient un succès critique. Si vous obtenez un échec critique, il devient un échec.
