# Contre charme
**Déclencheur** Une créature Lance un sort avec le trait illusion ou mental.


**Conditions** Vous devez avoir un sort inné qui n'est pas un tour de magie d'enjôleur avec le même trait.





Vos charmes et vos illusions sont si dominants que vous pouvez les utiliser pour contrer une magie similaire lancée par quelqu'un d'autre. Lorsqu'un ennemi lance un sort avec le trait illusion ou mental et que vous pouvez voir ses manifestations, vous pouvez utiliser votre propre magie innée pour l'interrompre. Vous perdez un sort inné, qui n'est pas un tour de magie, avec le même trait que le sort déclencheur, comme si vous aviez lancé le sort. Vous tentez alors de contrer le sort déclencheur avec votre sort.
