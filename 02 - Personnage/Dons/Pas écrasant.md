# Pas écrasant
Le poids de votre démarche en armure écarte les obstacles naturels. Lorsque vous portez une armure intermédiaire ou lourde, vous ignorez le terrain difficile des sources non magiques. Si vous êtes maître dans le port de l'armure que vous portez, vous ignorez également le terrain très difficile issu de sources non magiques.
