# Repousser les impies
**Déclencheur** Un mort-vivant dans votre allonge obtient un échec critique à un jet d'attaque vous ciblant.





L'échec de votre ennemi vous sert d'ouverture pour le repousser. Vous tentez de [[Pousser]] le mort-vivant.
