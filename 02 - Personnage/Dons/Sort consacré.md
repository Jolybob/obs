# Sort consacré
Vous imprégnez un sort du pouvoir de votre foi, le consacrant. Si votre prochaine action consiste à Lancer un sort qui cible un unique mort-vivant, vous pouvez dépenser un point de focalisation pour canaliser la puissance de vos sorts focalisés dans le sort primaire. Si vous le faites, le sort que vous lancez inflige des dégâts spirituels ou de vitalité supplémentaires (au choix) égaux au rang de vos sorts focalisés. Comme à l'ordinaire avec les dégâts supplémentaires, ces dégâts supplémentaires sont doublés si le sort lancé nécessite un jet d'attaque et que le résultat de ce jet est un coup critique ou si le sort lancé nécessite un jet de sauvegarde et que le résultat de ce jet est un échec critique.
