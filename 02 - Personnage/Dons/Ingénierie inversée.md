# Ingénierie inversée
Vous êtes incroyablement doué pour démonter des objets afin d'en apprendre les formules ou pour les désassembler simplement afin de les désactiver. Si vous utilisez les règles alternatives d'Artisanat critique et que vous obtenez un succès critique sur votre test d'Artisanat pour démonter un objet, vous pouvez réassembler l'objet d'origine avec l'un des avantages du succès critique en Artisanat (tel que déterminé par votre MJ).


De plus, vous pouvez utiliser Artisanat à la place de Vol pour [[/act disable-device skill=crafting]]{Désamorcer un dispositif} ou [[/act pick-a-lock skill=crafting]]{Crocheter une serrure}.
