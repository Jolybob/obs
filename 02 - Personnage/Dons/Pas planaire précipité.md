# Pas planaire précipité
**Fréquence** Une fois par jour





Vous vous déplacez avec une célérité magique, vous faufilant entre les frontières planaires pour raccourcir votre voyage. Marchez rapidement une fois. Cette Marche rapide ne déclenche pas de réactions déclenchée par le déplacement.


Une fois que cette Marche rapide est achevée, vous obtenez un bonus de statut de +1,50 mètre à votre Vitesse jusqu'au début de votre prochain tour.
