# Conjurateur de cadavres
Vous pouvez invoquer de nombreux types de morts-vivants pour accomplir vos désirs. Vous apprenez le sort [[Convocation de mort-vivant]]. Les créatures mortes-vivantes que vous convoquez avec ce sort peuvent être détruits et ciblés par vos sorts et vos capacités comme s'il s'agissait de vos séides. Vous obtenez un emplacement de sort préparé supplémentaire chaque jour de votre rang de sort de nécromancien le plus élevé. Vous ne pouvez préparer que le sort *Convocation de mort-vivant* dans cet emplacement.
