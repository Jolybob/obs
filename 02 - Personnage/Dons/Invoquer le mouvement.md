# Invoquer le mouvement
**Conditions** Vous êtes sous les effets d'Entrer en transe spirituelle.





Vous manifestez une forme de déplacement inspirée des esprits qui vous entourent, comme des ailes d'un esprit animal ou le flux aquatique d'un esprit de la nature. Choisissez un type de déplacement : creusement, escalade, vol ou nage. Vous obtenez une Vitesse dans le mode de déplacement choisi égale à votre vitesse de base (ou à la moitié de votre Vitesse si vous avez choisi creuser) pendant la durée de votre transe spirituelle. Si vous Invoquez le mouvement de nouveau, vous pouvez choisir un type de déplacement différent mais vous perdez la forme de déplacement précédente.
