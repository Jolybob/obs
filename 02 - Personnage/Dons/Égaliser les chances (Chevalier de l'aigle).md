# Égaliser les chances (Chevalier de l'aigle)
**Fréquence** Une fois par jour





Même lorsqu'ils sont débordés, les Chevaliers de l'Aigle gardent l'espoir. Si votre prochaine action consiste à utiliser [[Engagement pour l'égalité]], vous lancez le test de Diplomatie et conservez le meilleur résultat. Si vous obtenez un succès, la cible obtient aussi 25 Points de vie temporaires qui durent pendant 1 minute.
