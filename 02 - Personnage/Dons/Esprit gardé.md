# Esprit gardé
**Fréquence** Une fois toutes les 10 minutes


**Déclencheur** Vous obtenez un échec sur un jet de sauvegarde contre un effet qui possède le trait mental.





Lorsque vos ennemis tentent de retourner votre esprit contre vous, penser àvotre anathème vous apporte du renforce. Vous pouvez relancer le jet déclencheur avec un bonus de circonstances de +2, mais vous devez utiliser le nouveau résultat, même s'il est pire.
