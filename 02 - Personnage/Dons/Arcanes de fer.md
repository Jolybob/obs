# Arcanes de fer
Vous délaissez les baguettes et les bâtons pour un arsenal plus évolué. Vous êtes qualifié avec les armes évoluées. Si vous obtenez la capacité de classe [[Expertise avec les armes]], votre maîtrise avec les armes de guerre et évoluées passe à expert. Les dégâts supplémentaires que vous infligez avec [[Frappes enchantées]] passent à 1d8.
