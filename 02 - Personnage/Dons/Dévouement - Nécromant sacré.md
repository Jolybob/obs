# Dévouement - Nécromant sacré
Vous avez étudié les techniques vous permettant de mêler la nécromancie sacrée ainsi dénommée à votre propre incantation de sort pour renforcer les vivants et détruire les morts-vivants. Vous obtenez le sort focalisé [[Sol sacré]]. Incanter un sort focalisé coûte 1 Point de focalisation. Ce don vous accorde une réserve de focalisation de 1 Point de focalisation que vous pouvez récupérer en utilisant l'activité [[Refocaliser]]. Vous pouvez Refocaliser en méditant ou en priant pour vous connecter vous-mêmes aux courants de vitalité. Les sorts focalisés de l'archétype de nécromant sacré sont de la même tradition que vos emplacements de sorts.


Lancer des sorts qui créent, soignent, aident ou promeuvent les morts-vivants est un acte anathème en ce qui vous concerne, comme l'est toute coopération avec un mort-vivant. Utiliser l'énergie du vide n'est pas un acte anathème lorsqu'elle sert un but naturel mais la dénaturer pour la création est un blasphème pour ce qui vous concerne. Si vous accomplissez un acte qui est un anathème contre vos principes, vous perdez accès à tous les dons de cet archétype. Ces pouvoirs ne peuvent être regagnés que si vous accomplissez un rituel de [[Pénitence]].
