# Inviolable
Votre divinité punit les créatures qui vous blessent. Les créatures qui vous touchent avec une attaque subissent @Damage[3d6[spirit]]{3d6 dégâts spirituels} à chaque fois qu'elles y parviennent. Si vous possédez le trait saint ou impie, vous pouvez l'appliquer à ces dégâts.
