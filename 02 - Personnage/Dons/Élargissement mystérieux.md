# Élargissement mystérieux
Augmentez le nombre de sorts dans votre répertoire et le nombre d'emplacements de sort que vous obtenez des dons d'archétype d'oracle de 1 pour chaque rang de sort autre que vos deux emplacements de sorts d'oracle les plus élevés.
