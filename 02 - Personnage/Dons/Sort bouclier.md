# Sort bouclier
Votre bouclier devient un objet lié capable de stocker vos sorts. Vous obtenez la capacité de classe [[Lien arcanique]] et l'action [[Drain d'objet lié]]. Vous devez choisir un bouclier comme l'objet auquel vous êtes lié. Lors de vos préparatifs quotidiens, vous pouvez préparer un sort de magicien en moins pour imprégner cette magie dans votre objet lié. Ce sort doit être d'au moins 1 rang inférieur au plus haut rang de sort de magicien que vous possédez. Lorsque vous Drainez votre objet lié pour Lancer un sort, ce sort est automatiquement intensifié au rang de sort que vous avez imprégné dans votre bouclier, quel que soit son rang initial de préparation.
