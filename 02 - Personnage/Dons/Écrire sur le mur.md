# Écrire sur le mur
Vous placez des messages cachés écrits dans un code runique de votre conception. Vous pouvez lancer [[Message implanté]] une fois par jour comme un sort inné. Le rang de ce sort est égal à la moitié de votre niveau arrondi au supérieur et sa tradition peut être de toute tradition pour laquelle vous êtes au moins expert dans la tradition correspondante (Arcanes pour arcanique, Nature pour primordiale, Occultisme pour occulte et Religion pour divine). Lorsque vous lancez *Message implanté*, au lieu de choisir une langue que vous connaissez pour le texte du message et pour parler, vous pouvez choisir que le message ne soit que du texte, écrit dans un code runique que seul vous connaissez. Vous pouvez donner connaissance de ce code à 5 créatures au maximum en y consacrant 10 minutes. Ils concervent cette connaissance indéfiniment, mais vous pouvez concevoir un nouveau code runique pour des messages suivants que vous souhaitez encoder.


Une créature peut [[Déchiffrer le texte]] de votre code runique en utilisant la même compétence que celle associée à la tradition choisie contre votre DD de classe.
