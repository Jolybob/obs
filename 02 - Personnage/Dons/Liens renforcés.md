# Liens renforcés
Vos prises sont particulièrement fiables. Lorsque vous obtenez un échec critique sur un test pour [[/act grapple]]{Saisir} une cible, il devient un échec. De plus, lorsqu'une créature que vous avez [[Agrippée]] obtient un échec lors de son test pour [[S'Échapper]], il devient un échec critique et, si elle obtient un succès critique, il devient un succès.
