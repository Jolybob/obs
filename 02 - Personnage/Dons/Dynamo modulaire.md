# Dynamo modulaire
Votre dynamo possède des configurations modulaires qui vous permettent de passer facilement d'une possibilité à l'autre afin de vous adapter à diverses situations de combat. Votre attaque de dynamo obtient le trait configurable ainsi qu'une des configurations suivantes à votre choix : *puissante dynamo conductrice* (1d6 dégâts contondants ; pousser), *dynamo à frappe percussive* (1d4 dégâts contondants ; agile, finesse), *faucille rotative* (1d6 dégâts tranchants ; Croc-en-jambe) ou *barbelés enchevêtrants* (1d6 dégâts perforants ; Saisir). Si vous possédez une dynamo à commande manuelle, le dé de dégâts augmente d'un cran, comme à l'ordinaire et vous pouvez également choisir *bâton extensible* (1d4 dégâts contondants ; finesse, allonge) qui intègre déjà l'augmentation de dégâts.


Lorsque vous utilisez une action Interagir pour changer de configuration à l'aide du trait configurable, vous basculez entre la configuration initiale de dynamo que vous avez choisie pour le don Dévouement : Dynamo sterling et la nouvelle configuration que vous avez choisie avec Dynamo modulaire.





**Spécial** Vous pouvez sélectionner ce don plusieurs fois. À chaque fois, vous choisissez une autre configuration et vous l'ajoutez à la liste des options que vous pouvez choisir lorsque vous utilisez une action Interagir avec le trait configurable.
