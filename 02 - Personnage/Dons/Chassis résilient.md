# Chassis résilient
**Fréquence** Une fois par jour


**Déclencheur** Vous devriez subir des dégâts.





Vous êtes suffisamment robuste pour puiser dans vos propres réserves d'énegie internes lorsque vous avez été endommagé. Vous obtenez 4 Points de vie temporaires qui durent pendant 1 round. Au niveau 8, puis tous les 4 niveaux suivants, Les Points de vie temporaires augmentent de 4.


**Amélioration** La fréquence de Chassis résilient devient une fois toutes les 10 minutes.
