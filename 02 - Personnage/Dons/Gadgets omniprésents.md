# Gadgets omniprésents
Ils ont pensé que vous aviez utilisé toutes vos machines, mais ils se sont trompés ! Vous avez encore plus de gadgets dans votre manche que ce à quoi les autres s'attendent. Augmentez le nombre de gadgets temporaires que vous pouvez créer chaque jour de 2.





**Spécial** Vous pouvez choisir ce don une seconde fois si vous êtes de niveau 14 ou supérieur.
