# Incroyablement crédible
Vos paroles résonnent avec une puissance apaisante et convaincante. Lorsque vous tentez un test pour [[Faire bonne impression]], [[Mentir]], [[Recueillir des informations]] ou [[Solliciter]], vous pouvez dépenser un Point mythique pour tenter le test avec une maîtrise mythique.
