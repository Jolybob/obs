# Contresort du péché
Votre lien profond avec un péché spécifique vous permet d'annuler facilement les sorts auxquels le péché s'oppose. Au lieu de n''être capable que de contrer le sort d'un ennemi que si vous disposez du même sort préparé avec Contresort, votre pouvez utiliser Contresort avec n'importe lequel de vos sorts de cursus si le sort lancé conduit à violer l'anathème de votre péché.
