# Contrer la pensée
**Déclencheur** Une créature Lance un sort avec le trait mental.


**Conditions** Vous avez un emplacement de sort non dépensé que vous pourriez utiliser pour Lancer un sort avec le trait mental.





Lorsqu'un ennemi Lance un sort qui possède le trait mental et que vous pouvez voir ses manifestations, vous pouvez utiliser votre propre magie mentale pour le perturber. Vous dépensez un de vos emplacements de sort pour contrer l'incantation par la créature déclencheuse d'un sort disposant du trait mental. Vous perdez votre emplacement de sort comme si vous aviez lancé le sort déclencheur. Cet emplacement de sort doit être un emplacement pour lequel vous pourriez lancer un sort avec le trait mental. Vous tentez ensuite de contrer le sort déclencheur.
