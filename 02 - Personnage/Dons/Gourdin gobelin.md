# Gourdin gobelin
**Fréquence** Une fois par jour





Vous pouvez conjurer une masse d'énergie magique dans votre main qui, naturellement, vous utilisez pour gifler ceux qui vous ont offensé. Vous faites apparaître un gourdin bangmangi spectral pendant 1 minute, qui apparaît dans vos mains, bien que vous puissiez le remettre à une autre créature pour qu'elle le manie. Cette arme est un *gourdin spectral de frappe +1*.


Au niveau 13, le bangmangi est un *gourdin spectral de frappe supérieure +2*.
