# Vide sans fin
Vous rassemblez le pouvoir de l'ombre dans vos yeux, obtenant la capacité de rassembler l'obscurité pour former une orbe turbulente de vide écrasant dans votre champ de vision. Vous obtenez le sort de domaine [[Lumière noire]]. Augmentez le nombre de Points de focalisation de votre réserve de focalisation de 1.
