# Monture acclimatée
Par la grâce de votre dieu, votre monture peut surmonter les défis naturels et les dangers présents sur un type de terrain spécifique. Choisissez entre aquatique, arctique, ciel, désert, forêt, marais, montagne, plaines ou souterrain. Votre monture doit posséder une Vitesse de nage pour le terrain aquatique et une Vitesse de vol pour prendre le ciel. Votre monture ignore les effets des terrains difficiles lorsqu'elle se trouve sur le terrain choisi.


Si vous devenez expert en Survie, vous pouvez prier au cours de vos préparatifs quotidiens chaque jour pour changer le type de terrain auquel votre monture est acclimatée.
