# Incliner les écailles
Vous êtes un adversaire rusé dans les combats rapprochés et un adepte des tactiques d'escarmouche qui exploitent les avantages de votre petite stature. u fil de votre entraînement, vous avez appris comment faire lorsque vous êtes [[Agrippé]] ou [[Entravé]]. Vous obtenez un bonus de circonstances de +1 aux tests pour vous Échapper et après avoir réussi une action pour vous Échapper, vous pouvez utiliser immédiatement votre réaction pour Faire un pas ou pour [[/act shove]]{Pousser} ou faire un [[/act trip]]{Croc-en-jambe} à la créature dont vous êtes parvenu à vous Échapper.
