# Course en surface
Vous effectuez une course effrénée pour plonger dans l'eau ou regagner la terre ferme. Si vous commencez sur la terre lorsque vous utilisez cette capacité, vous Marchez rapidedment, puis Nagez deux fois si vous êtes dans l'eau. Si vous commencez dans l'eau lorsque vous utilisez cette capacité, vous Nagez, puis Marchez rapidement deux fois si vous êtes sur terre.
