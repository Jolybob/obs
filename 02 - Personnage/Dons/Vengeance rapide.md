# Vengeance rapide
Indigné par quiconque oserait vous frapper, vous ou vos alliés, vous prenez votre revanche. Lorsque vous utilisez [[Intercepter une attaque]] ou [[Blocage au bouclier]], vous êtes [[Accéléré]] lors de votre prochain tour. Vous pouvez utiliser l'action supplémentaire uniquement pour Marcher rapidement pour vous rapprocher de l'ennemi dont l'attaque a déclenché cette réaction ou pour Frapper cet ennemi.
