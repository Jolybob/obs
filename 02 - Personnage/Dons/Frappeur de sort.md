# Frappeur de sort
Vous obtenez l'activité de magus [[Frappe de sort]]. Vous pouvez la recharger par une activité qui vous prend 1 minute. Cette restriction s'applique même si vous obtenez une autre capacité qui recharge normalement Frappe de sort.
