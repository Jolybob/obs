# Gobelin rebondissant
Vous jouissez d'une élasticité particulière qui vous permet de rebondir ou de vous faufiler facilement. Vous êtes qualifié en Acrobaties (ou une autre compétence de votre choix, si vous étiez déjà qualifié en Acrobaties). Vous obtenez aussi un bonus de circonstances de +2 aux tests d'Acrobaties pour effectuer un Déplacement acrobatique pour tenter de traverser l'espace occupé par un adversaire.
