# Fait pour le rôle
Non seulement vous êtes un artiste flamboyant, mais vous avez maîtrisé un secret occulte qui vous permet de revêtir vous-même ainsi que vos compagnons de visages magiques. Vous obtenez la capacité de lancer [[Déguisement illusoire]] comme un sort occulte inné de rang 7 une fois par jour.
