# Enquêter sur les hantises
Vous êtes compétent pour remarquer les signes de l'existence de fantôme et de hantises dans les histoires. Même lorsque vous n'êtes pas en train d'enquêter en mode exploration, vous obtenez un test pour [[Vous souvenir]] à propos des morts-vivants intangibles ou des hantises actives dans la zone. Vous obtenez aussi un bonus de circonstances de +2 aux tests de compétence pour désamorcer les hantises.
