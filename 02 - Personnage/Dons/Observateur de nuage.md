# Observateur de nuage
Votre lien avec l'air vous permet de voir à travers les brumes obscurcissantes.


Vous pouvez voir suffisamment bien à travers le brouillard, la brume et les nuages que vous n'avez pas besoin de réussir un test nu pour cibler les créatures [[Masquées]] par un tel camouflage.
