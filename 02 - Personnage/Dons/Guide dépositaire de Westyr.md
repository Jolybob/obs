# Guide dépositaire de Westyr
**Conditions** Vous avez au moins un emplacement de sort de rang 1 et un guide.





Vous pouvez utiliser un guide pour emmagasiner un petit peu de magie supplémentaire pour quand vous en aurez le plus besoin.


Lorsque vous faites vos préparatifs quotidiens, vous pouvez choisir un sort de rang 1 de votre grimoire ou de votre répertoire de sorts et l'emmagasiner dans votre guide. Vous pouvez lancer ce sort à partir de votre guide en utilisant le nombre d'actions habituel. Une fois que le sort a été Lancé, il est dépensé et vous devez attendre vos prochains préparatifs quotidiens pour emmagasiner un autre sort dans votre guide.
