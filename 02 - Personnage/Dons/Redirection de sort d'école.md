# Redirection de sort d'école
Lorsque vous contrez un sort dont l'école correspond à votre spécialisation, si vous obtenez un succès critique à votre test de contre ou si vous obtenez un succès en utilisant un sort d'un niveau supérieur à celui du sort que vous avez contré, vous pouvez rediriger le sort que vous avez contré. Vous choisissez la cible, la zone et les autres aspects du sort et utilisez votre propre DD de sort, votre jet d'attaque de sort ou toute autre statistique appropriée pour en déterminer les effets.
