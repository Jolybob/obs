# Sifflet kijimuna
**Accès** héritage gnome kijimuna ou originaire du Tian Xia





Votre lien avec la nature, et en particulier avec les arbres, est devenu si fort que vous pouvez invoquer les plantes avec laquelle vous avez noué des amitiés dans les forêts de votre jeunesse. Une fois par jour, vous pouvez siffler le son joyeux distinctif qui est la signature d'une communauté gnome kijimuna pour lancer [[Convocation de plante ou de champignon]] comme un sort inné primordial de rang 5. Le sort perd le trait manipulation puisque les incantations et les gestes utilisés pour ce sort n'impliquent que de siffler. Les gnomes kijimunas proches reconnaissent automatiquement cette trille de célébration et répondront habituellement ou se joindront pour produire de la musique s'ils le peuvent.
