# Empathie avec les vases
Vous pouvez vous lier avec les vases (et les autres aberrations amorphes laissées à l'appréciation du MJ) à un niveau rudimentaire. Vous pouvez utiliser Diplomatie pour [[Faire bonne impression]] sur les vases et pour leur présenter de très simples [[Sollicitations]]. Dans la plupart des cas, les vases vous laisseront le temps de présenter votre cas.
