# Langue éclair
Votre langue pointe plus rapidement que l'œil peut le percevoir pour récupérer les objets abandonnés. Vous Interagissez pour récupérer un objet unique non tenu d'Encombrement léger situé à moins de 3 mètres de vous. Si vous n'avez pas les mains libres pour attraper l'objet, il chute au sol dans votre case.
