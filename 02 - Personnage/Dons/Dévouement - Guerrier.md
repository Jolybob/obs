# Dévouement - Guerrier
Vous êtes qualifié avec les armes de guerre. Vous êtes qualifié à votre choix en Acrobaties ou en Athlétisme. Si vous êtes déjà qualifié dans ces deux compétences, vous devenez à la place qualifié dans une compétence de votre choix. Vous êtes qualifié dans le DD de classe de guerrier.
