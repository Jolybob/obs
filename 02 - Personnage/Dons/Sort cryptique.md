# Sort cryptique
**Conditions** Vous êtes sur un terrain naturel.





Vous cachez votre magie dans le coassement d'une grenouille, dans le balancement des arbres, dans le hurlement du vent et dans le scintillement d'un feu follet. Si la prochaine action que vous entreprenez consiste à Lancer un sort, le sort obtient le trait subtil, cachant les manifestations du sort dans les images et les sons naturels de l'environnement.


Ce trait ne cache que les actions d'incantation et les manifestations du sort, mais pas ses effets. Un observateur peut donc toujours vous voir vous transformer en ours géant.
