# Pionnier des sous-bois
Vous obtenez le don [[Traqueur de terrain]], en choisissant le terrain sous-bois. Si vous possédez déjà le don Traqueur de terrain pour les sous-bois, vous pouvez choisir un type différent de terrain difficile. Si vous [[Échappez aux regards]] lorsque vous explorez et si n'importe quel allié utilise [[Suivre l'expert]] pour vous suivre lorsque vous le faites, vous pouvez étendre les avantages du don Traqueur de terrain à un allié tant qu'il reste dans les 3 mètres de vous. Si vous êtes maître en Discrétion, vous pouvez étendre l'effet à deux alliés. Si vous êtes maître en Discrétion, vous pouvez l'étendre à quatre alliés.
