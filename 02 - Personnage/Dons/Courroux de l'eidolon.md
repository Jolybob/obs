# Courroux de l'eidolon
Votre eidolon obtient le sort de lien [[Courroux de l'eidolon]], qu'il peut lancer à votre place. Vous déterminez le type de dégâts lorsque vous obtenez ce don : acide, électricité, feu, froid, son, spiritualité, vide ou vitalité. Comme à l'ordinaire, votre eidolon partage vous Points de focalisation.
