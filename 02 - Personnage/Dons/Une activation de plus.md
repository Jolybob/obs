# Une activation de plus
Vous avez forgé un lien plus profond avec vos objets investis ce qui vous permet de les activer plus qu'à l'ordinaire. Une fois par jour, vous pouvez activer un objet que vous avez investi même après avoir utilisé cette activation le nombre maximum de fois prévu pour sa fréquence. Vous pouvez le faire uniquement si le niveau de l'objet est inférieur ou égal à la moitié de votre niveau, si l'activation a une fréquence d'au moins une fois par jour et si vous n'avez pas déjà utilisé l'activation ce round.
