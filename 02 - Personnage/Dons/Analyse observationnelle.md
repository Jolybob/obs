# Analyse observationnelle
Vous êtes capable de discerner rapidement les détails pertinents à propos de vos adversaires dans le feu du combat. Lorsque vous utilisez [[Évaluation du combat]] contre une cible que vous ou un allié avez ciblé avec une Frappe ou un sort depuis le début de votre dernier tour, vous obtenez un bonus de circonstances de +2 au test pour [[Se souvenir]] (+4 si la Frappe d'Évaluation du combat est un coup critique).
