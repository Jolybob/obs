# Pas de côté planaire
**Fréquence** Une fois par jour


**Déclencheur** Une créature vous touche avec une Frappe au corps-à-corps.





Votre corps change de plan brièvement, réduisant les dégâts de l'attaque de votre ennemi. Vous obtenez une résistance 25 contre tous les dégâts de l'attaque déclencheuse. Les observateurs vous voient simplement scintiller d'énergie élémentaire pendant un instant, juste au moment où l'attaque vous atteint.
