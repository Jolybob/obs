# Pièges artisanaux nombreux
Vous pouvez préparer un nombre incroyable de pièges artisanaux chaque jour à partir de simples ingrédients. Doublez le nombre de pièges artisanaux préparés accordés par [[Dévouement - Fabricant de pièges artisanaux]].
