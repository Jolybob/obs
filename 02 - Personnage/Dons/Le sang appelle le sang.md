# Le sang appelle le sang
**Déclencheur** Vous avez obtenu un échec sur un test nu pour Lancer un sort ou otre sort devrait être interrompu par la réaction d'une autre créature.





La puissance magique de votre sang ne peut être refusée. Vous terminez l'incantation du sort, puis devenez [[Drainé 1]] ou vous augmentez la valeur de votre état Drainé de 1.
