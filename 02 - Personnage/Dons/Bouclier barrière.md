# Bouclier barrière
Lorsque vous lancez [[Bouclier]], vous pouvez modifier le sort pour créer une barrière solide que vous pouvez utiliser comme [[Abri]] mais pas pour bloquer. Vous ne pouvez pas utiliser la réaction Blocage au bouclier lorsque le sort est modifié de cette manière mais vous (et seulement vous) pouvez dépenser une action pour vous Mettre à l'abri et obtenir un abri standard.
