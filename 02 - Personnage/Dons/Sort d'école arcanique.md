# Sort d'école arcanique
Vous gagnez le sort d'école initial de l'école que vous avez choisie. Si vous n'en avez pas déjà une, vous obtenez également une réserve de focalisation d'une valeur de 1 point de focalisation, que vous pouvez [[Refocaliser]] par l'étude.
