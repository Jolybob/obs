# Rediriger la téléportation
**Déclencheur** Une créature se téléporte dans un espace dans les 18 mètres de vous.





Vous êtes capable d'intercepter un effet de téléportation et de changer l'endroit où une créature apparaît. Vous dépensez un sort préparé qui possède le trait téléportation. Vous perdez votre emplacement de sort comme si vous aviez lancé le sort en question. Vous tentez alors de contrer le sort déclencheur. Le rang de contre de l'effet est celui du rang du sort dépensé. Si votre test de contre est un succès, vous n'interrompez pas le sort. À la place, vous choisissez un espace inoccupé dans les 18 mètres de vous pour que la créature s'y téléporte. Vous ne pouvez pas choisir un espace qui lui cause des dégâts évidents (Comme dans un *Mur de feu* ou sur un terrain dansgereux) ou qui provoquera la chute de la cible.
