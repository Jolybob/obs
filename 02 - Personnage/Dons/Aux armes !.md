# Aux armes !
Avec un cri qui résonne, vous ralliez votre allié à l'offensive. Choisissez un allié dans votre aura de capitaine qui possède une réaction disponible. Si vous dépensez 1 action, cet allié peut utiliser sa réaction pour Marcher rapidement immédiatement. Si vous dépensez 2 actions, cet allié peut utiliser cette réaction pour Frapper immédiatement.
