# Expertise de l'aura
**Déclencheur** Votre tour commence.





Vous avez tellement l'habitude de maintenir vos auras de combat que c'est devenu une seconde nature pour vous. Vous obtenez immédiatement les effets de l'action Maintenir pour une de vos auras de bataille.
