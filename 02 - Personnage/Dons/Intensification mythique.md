# Intensification mythique
**Fréquence** Une fois par jour





Vous surchargez vos sorts mineurs pour leur donner plus d'effet. Dépensez un Point mythique. Si la prochaine action que vous utilisez consiste à Lancer un sort, ce sort est intensifié au rang de sort le plus élevé que vous pouvez lancer. Tout jet d'attaque de sort est faite avec la maîtrise mythique et le DD de sort est calculé avec la maîtrise mythique. L'emplacement de sort utilisé pour lancer le sort n'est pas modifié.
