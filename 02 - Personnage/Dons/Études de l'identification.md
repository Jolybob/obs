# Études de l'identification
Vous disposez des connaissances requises pour comprendre les écrits antiques et les artefacts culturels. Vous pouvez utiliser Société lorsque vous [[/act decipher-writing skill=society]]{Déchiffrez un texte}, quel que soit le type d'écrit que vous examinez.


Vous pouvez également utiliser Société pour [[/act identify-magic skill=society]]{Identifier la magie} Lorsque vous examinez un objet ou un lieu magique porteur d'une signification culturelle.
