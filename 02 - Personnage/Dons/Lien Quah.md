# Lien Quah
**Accès** ethnie Shoanti





Vous avez grandi parmi les tribus Shoanti, avec les esprits qui veillent sur vous et vous offrent leurs conseils. Vous êtes qualifié dans la compétence listée pour votre quah (ou une autre compétence de votre choix, si vous êtes déjà qualifié dans cette compétence). Vous obtenez le don de compétence [[Assurance]] dans cette compétence, parce que l'aide des esprits guide vos actions.




- **Lyrune-Quah** Religion

- **Shadde-Quah** Athlétisme

- **Shriikirri-Quah** Nature

- **Shundar-Quah** Diplomatie

- **Sklar-Quah** Intimidation

- **Skoan-Quah** Médecine

- **Tamiir-Quah** Acrobaties
