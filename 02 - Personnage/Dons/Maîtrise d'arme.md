# Maîtrise d'arme
Vous êtes qualifié dans toutes les armes de guerre. Si vous étiez déjà qualifié dans toutes les armes de guerre, vous êtes qualifié avec l'arme évoluée de votre choix. Si vous êtes au moins de niveau 11, vous devenez également expert avec ces armes.





**Spécial** Vous pouvez sélectionner ce don plus d'une fois. À chaque fois, vous êtes qualifié avec une arme évoluée.
