# Épines tueuses
Vos épines sont nombreuses, vicieuses et pointues sharp. Si vous possédez le don Épine cachée, votre attaque d'épines obtient le trait mortel d6. Si vous avez l'héritage rose à épines, vous pouvez utiliser la réaction [[Terribles épines]] une fois par heure.
