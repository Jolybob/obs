# Dérapage puissant
**Conditions** Vous pilotez un véhicule.





Vous lancez le véhicule dans un dérapage à peine contrôlé et tournez brusquement pour échapper à la poursuite ou pouvoir mettre vos armes à contribution. Vous Dirigez avec une pénalité de -2 à votre test de conduite, en obtenant les effets de l'action de conduite pour le même nombre d'actions que vous avez dépensées pour déraper. À la fin du déplacement, si vous réussissez, vous pouvez tourner le véhicule d'un maximum de 90 degrés. Si vous obtenez un succès critique à votre test de conduite, vous pouvez faire pivoter le véhicule de 180 degrés.
