# Dévouement - Sentinelle
Vous vous êtes entraîné avec soin pour optimiser les qualités protectrices de votre armure. Vous êtes qualifié avec les armures légères et les armures intermédiaires. Si vous étiez déjà qualifié avec les armures légères et intermédiaires, vous devenez également qualifié avec les armures lourdes. Lorsque vous obtenez une capacité de classe qui vous accorde la maîtrise experte ou une maîtrise supérieure avec n'importe quel type d'armure (mais pas avec la défense sans armure), vous obtenez aussi cette maîtrise dans les types d'armure qui vous ont été accordés par ce don. Si vous disposez d'une capacité de classe qui vous accorde la maîtrise experte en défense sans armure et que vous êtes au moins au niveau 13, vous devenez aussi expert dans les types d'armure qui vous ont été accordées par ce don.
