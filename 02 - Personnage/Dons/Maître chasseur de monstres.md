# Maître chasseur de monstres
Vous avez une connaissance presque parfaite de toutes les créatures existantes. Vous pouvez utiliser [[/act recall-knowledge skill=nature]]{Nature} pour identifier n'importe quelle créature avec [[Se souvenir]]. De plus, vous bénéficiez des avantages de [[Chasseur de monstres]] (et de [[Garde-monstres]], si vous le possédez) en cas de succès ou de succès critique.
