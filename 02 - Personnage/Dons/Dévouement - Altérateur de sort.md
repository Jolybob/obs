# Dévouement - Altérateur de sort
Vous pouvez exercer votre volonté sur les sorts lancés à proximité de vous, ce qui peut vous permettre de modifier ou de contrôler leurs effets. Vous accomplissez ceci par l'usage d'un conduit altérant les sorts, un objet magique de votre choix qui a un Encombrement léger et peut être tenu d'une main. Si votre conduit est perdu ou détruit, vous pouvez vous entraîner à en utiliser un nouveau en y consacrant 10 minutes en vous y harmonisant. Vous obtenez l'action [[Altérer le sort]] et l'altération de sort Partager le sort.


**Altération de sort - Partager le fardeau** Vous partagez le fardeau d'un sort, vous permettant de partager le contrôle avec l'incantateur. Si vous Maintenez un sort avec cette altération de sort conduit une créature à tenter un jet de sauvegarde, il est tenté contre le plus élevé entre votre DD de classe ou DD de sort. Si le sort nécessite un jet d'attaque de sorts, portez l'attaque en utilisant votre modificateur d'Arcanes au lieu du modificateur d'attaque de sort habituel.


**Succès critique** Si le sort peut être Maintenu,vous pouvez Maintenir le sort par une action gratuite comme si vous aviez lancé le sort. Pour le restant de la durée du sort, vous pouvez Maintenir le sort comme si vous étiez l'incantateur.
