# Traduction simultanée
**Déclencheur** Une autre créature dans les 18 mètres utilise un effet linguistique dans une langue que vous comprenez.





Vous franchissez la barrière des langages, répétant son message dans une langue différente que vous connaissez. Choisissez une langue que vous parlez dans laquelle vous répétez le message. L'effet linguistique compte pour les deux langages, plutôt que dans le seul langage de la créature qui l'utilise, ce qui permet potentiellement d'affecter une audience plus large. Bien sur, vous pouvez traduire des propos sans utiliser la Traduction simultanée ni de réaction, mais cette réaction permet d'appliquer les bénéfices de la traduction aux sorts et actions tels que Injonction ou [[Démoraliser]].
