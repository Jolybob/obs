# Pacte ouroborique
Vous avez étudié les pactes à Cobyslarni ou appris sous l'égide de quelqu'un qui l'a fait et les comprenez non seulement pour créer un marché entre des individus, mais aussi avec une entité séparée : le pacte lui-même. Vous obtenez l'action [[Puiser dans le pacte]], que vous pouvez utiliser en association avec n'importe quel pacte de l'archétype de pactiseur. Par exemple, si vous avez conclu le [[Pacte de furie draconique]], vous pourriez Puiser dans le pacte pour vous aider lors d'un test de compétence en vue d'obtenir un objet que le dragon désire.





**Spécial** Vos pactes se renforcent continuellement dans une boucle magique circulaire. Vous perdez la possibilité de réapprendre le moindre des dons de l'archétype de Pactiseur.
