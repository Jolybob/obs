# Présages de l'haruspice
**Déclencheur** Une créature dans les 9 mètres est réduit à 0 Point de vie d'une manière qui ne détruit pas son corps.





Bien que les divinations d'un haruspice nécessite des organes et une interprétation longue, vous avez appris comment jeter un œil dans le futur dans une plus simple manière de lire dans les blessures des créatures. Le coup d'œil dans le futur fournit des conseils sur les meilleurs outils à utiliser par la suite. Lancez [[/r 1d12]]{1d12} pour déterminer le type de dégâts révélé par votre prédiction. La prochaine fois avant la fin de votre prochain tour que vous ou un allié infligez ce type de dégâts à un ennemi, cet ennemi a une faiblesse égale à votre niveau contre ce type de dégâts.
