# Retourne à la Fosse !
Vous pouvez renvoyer les fiélons qui vous ont tourmenté vers leur plan d'origine, auquel ils appartiennent. Vous pouvez lancer [[Bannissement]] une fois par jour comme un sort divin inné. Lorsque vous prenez ce don, vous fabriquez un symbole personnel de la ligue des Briseurs d'enfer qui est anathème pour les diables. Si vous brandissez ce symbole dans une main lorsque vous dépensez une action supplémentaire pour lancer *Bannissement* sur un diable, vous n'avez pas besoin de payer le coût supplémentaire pour infliger à cette créature une pénalité de circonstances de -2 à son jet de sauvegarde.
