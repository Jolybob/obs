# Artisanat intuitif
Votre affinité avec le processus et l'ordre fait de vous un artisan naturel. Vous êtes qualifié en Artisanat. Si vous êtes déjà qualifié en Artisanat, vous obtenez à la place le don de compétence [[Artisanat spécialisé]] dans une spécialité de votre choix. Si vous avez les deux, vous êtes qualifié dans une compétence de votre choix. De plus, lorsque vous obtenez un échec critique pour Réparer un objet, il devient un échec.





*Note : Si vous êtes déjà qualifié dans en Artisanat, vous devez ajouter manuellement le don Artisanat spécialisé ou choisir une compétence alternative.*
