# Contre mythique
Vous pouvez écraser les conceptions magiques des autres avec la seule puissance de votre magie. Lorsque vous tentez un test pour contrer un sort, vous pouvez dépenser un Point mythique pour tenter le test avec une maîtrise mythique. Si la cible du test de contre est dans votre aura de [[Déferlement de sort]], les échecs critiques sur ce test sont considérés comme des échecs.
