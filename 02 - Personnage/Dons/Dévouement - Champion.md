# Dévouement - Champion
Choisissez une divinité. Vous êtes lié par l'anathème de votre divinité et vous obtenez l'aura de champion et la sanctification comme indiqué dans la classe de champion. Choisissez une cause comme si vous étiez champion, avec les mêmes options auxquelles le champion doit se plier. Vous obtenez ses édits et anathèmes mais n'obtenez pas les autres capacités.


Vous êtes qualifié en Religion et dans la compétence associée à votre divinité. Pour chacune de ces compétences dans lesquelles vous étiez déjà qualifié, vous devenez à la place qualifié dans une compétence de votre choix. Vous êtes qualifié dans le DD de classe de champion. Si vous obtenez par la suite un sort de dévotion, vous êtes qualifié en modificateur d'attaque de sorts et en DD de sort.


Vous êtes qualifié avec les armures légères et intermédiaires. Si vous étiez déjà qualifié avec les armures légères et intermédiaires, vous devenez également qualifié avec les armures lourdes. Lorsque vous obtenez une capacité de classe qui vous accorde la maîtrise experte ou une maîtrise supérieure avec n'importe quel type d'armure (mais pas avec la défense sans armure), vous obtenez aussi cette maîtrise dans les types d'armure qui vous ont été accordés par ce don. Si vous êtes au moins au niveau 13 et que vous disposez d'une capacité de classe qui vous accorde la maîtrise experte en défense sans armure, vous devenez aussi expert dans les types d'armure qui vous ont été accordés par ce don.
