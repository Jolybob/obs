# Pinacle kinétique
Personne ne peut rivaliser avec le rythme auquel vous faites jaillir de vous les éléments. Vous êtes [[Accéléré]] de manière permanente. Vous pouvez utiliser votre action supplémentaire pour [[Canaliser les éléments]] à une action, utiliser [[Déflagration élémentaire]] à une action ou utiliser une posture d'impulsion à 1 action.
