# Levier pivotant
Vous pouvez envelopper votre fouet autour d'une branche d'arbre ou d'une rambarde, puis vous tirer où vous avez besoin d'aller. Choisissez un point d'ancrage solide dans l'allonge de votre fouet. Vous Volez de votre Vitesse lorsque vous pivotez autour de l'ancrage, terminant dans un espace libre où l'ancre est toujours dans l'allonge de votre fouet. Si vous ne terminez pas votre tour dans un espace où vous pourriez tenir debout, vous chutez.
