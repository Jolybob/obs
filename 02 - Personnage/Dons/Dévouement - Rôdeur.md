# Dévouement - Rôdeur
Vous êtes qualifié en Survie. Si c'était déjà le cas, vous devenez à la place qualifié dans une autre compétence de votre choix. Vous êtes qualifié dans le DD de classe de rôdeur. Si vous obtenez un sort de gardien par le biais de cet archétype, vous êtes qualifié en attaques de sort et en DD de sort. Votre attribut d'incantation est la Sagesse. Vous pouvez utiliser l'action [[Chasser une proie]].
