# Nageur naturel
L'eau s'écoule autour de vous, vous permettant de fendre les vagues comme si vous étiez né pour cela. Vous obtenez une Vitesse de nage de 4,50 mètres. Si vous avez déjà une Vitesse de nage permanente, nager vers le haut ou vers le bas n'est pas considéré comme du terrain difficile.
