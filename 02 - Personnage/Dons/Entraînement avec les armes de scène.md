# Entraînement avec les armes de scène
Vous êtes compétent avec les armes qui en jettent et pouvez les utiliser à bon escient. Vous avez une familiarité avec le [[Bo]], la [[Cape de duel]], la [[Chaîne cloutée]], la [[Canne-épée]], le [[Trident]], le [[Fléau de guerre]] et le [[Fouet]]. Pour les besoins de déterminer votre maîtrise, vous considérez ces armes comme des armes simples. Le MJ peut ajouter d'autres armes de guerre à cette liste selon le monde ou la région dans lesquels vous jouez.


Lorsque vous obtenez un coup critique avec l'une de ces armes, vous bénéficiez de son effet critique spécialisé.
