# Sort rafale
Vous manipulez les courants de l'énergie de vos sorts, vous permettant de planer gracieusement avec vos ailes. Si la prochaine action que vous utilisez consiste à Lancer un sort avec le trait air ou électricité, vous pouvez Voler de 3 mètres avant ou après avoir lancé le sort.
