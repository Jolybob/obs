# Abordage explosif
**Conditions** Vous maniez une arbalète à deux mains ou une arme à feu qui possède le trait recul ou dispersion.





Vous vous jetez sur un ennemi, en arc-boutant votre arme contre lui et en la rapprochant avant de libérer un tir destructeur. Tentez de [[Saisir]] ; si vous maniez votre arme à deux mains, vous relâchez une main pour le faire. Si vous réussissez à le saisir, vous pouvez immédiatement porter une Frappe contre la cible Agrippée avec l'arme requise, même si votre arme est une arme à deux mains. Cette frappe inflige 3d6 dégâts de précision supplémentaires.


Tant que la créature reste [[Agrippée]] ou [[Entravée]], vous pouvez utiliser une seule main pour recharger l'arme et porter une Frappe contre cette créature avec.
