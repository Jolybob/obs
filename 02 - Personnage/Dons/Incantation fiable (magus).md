# Incantation fiable (magus)
Confiant dans votre technique, vous ne perdez pas facilement votre concentration lorsque vous Lancez un sort.


Si une réaction d'une autre créature devrait interrompre votre action pour Lancer un sort, faites un @Check[flat|showDC:all|dc:15]. En cas de succès, votre action n'est pas interrompue.
