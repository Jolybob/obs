# Négociateur tendu
Vous constatez que, souvent, la première méthode à adopter pour gagner un conflit consiste à éviter le combat. Vous êtes doué pour parler à des adversaires potentiels sans aggraver les choses. Si vous effectuez un échec critique à un test pour Faire bonne impression, il devient un échec. Vous pouvez effectuer des tests pour Solliciter des créatures qui sont indifférentes ou inamicales envers vous.
