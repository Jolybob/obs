# Souvenirs incroyables
Vous pouvez passer au tamis la connaissance bloquée dans votre esprit à une vitesse incroyable. Vous utilisez instantanément jusqu'à 5 actions Se souvenir. Si vous avez n'importe quelle capacité spéciale ou des actions gratuites qui devraient normalement être déclenchées lorsque vous Souvenez, vous ne pouvez pas utiliser ces actions.
