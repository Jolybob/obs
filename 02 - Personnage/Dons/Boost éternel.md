# Boost éternel
Votre lien avec votre eidolon est si intense que vous renforcez continuellement ses capacités. Vous êtes en permanence [[Accéléré]]. Vous ne pouvez utiliser votre action supplémentaire que pour lancer [[Booster l'eidolon]] ou [[Renforcer l'eidolon]].


Lorsque vous êtes en mode exploration, vous pouvez déclarer que vous lancez constamment *Booster l'eidolon* ou *Renforcer l'eidolon* même lorsque vous utilisez aussi une activité d'exploration différente. Si vous le faites, même avant votre premier tour dans une rencontre de combat, ce tour de magie est actif comme si vous l'aviez lancé lors de votre tour précédent.
