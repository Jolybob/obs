# Fleur sainte
La grâce de Milani vous rend encore plus puissant. Vous obtenez le sort de domaine avancé du domaine que vous avez choisi avec Sainte floraison.





**Spécial** Si vous avez sélectionné [[Sainte floraison]] deux fois, vous pouvez choisir ce don une seconde fois, en obtenant le sort de domaine avancé de l'autre domaine.
