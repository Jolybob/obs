# Placer une preuve
Vous pouvez placer un unique objet que vous tenez d'encombrement léger ou négligeable sur une personne sans qu'elle le remarque en réussissant un test de @Check[thievery|defense:perception] contre son DD de Perception.


Si vous avez le trafic de roublard de voyou, vous pouvez le faire par une action gratuite quand vous réussissez à [[Pousser]] une cible.
