# Terrain dissimulé
Lorsque vous lancez [[Brume]], vous pouvez modifier le sort pour remplacer ses effets ordinaires par les suivants : Un nuage d'épaisse fumée couvre la zone, rendant difficile de voir le sol. La zone au sein du brouillard est un terrain difficile pour les créatures qui ne peuvent voir à travers le brouillard ou la brume. Vous pouvez Révoquer le nuage.
