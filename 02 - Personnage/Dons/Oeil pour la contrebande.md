# Oeil pour la contrebande
Le temps passé à vérifier les navires de marchandises apparemment innocents à la recherche de marchandises illicites vous a rendu aussi rusé que méfiant. Vous obtenez un bonus de circonstances de +2 aux tests de Perception pour localiser les panneaux cachés, les portes secrètes ou les trappes, les objets cachés et objets similaires (à la discrétion du MJ). Si vous n'utilisez pas l'action [[Chercher]] ou [[Fouiller]], le MJ effectue automatiquement un test secret pour vous permettre de remarquer ce types d'objets lorsque vous passez à moins de 3 mètres d'eux.
