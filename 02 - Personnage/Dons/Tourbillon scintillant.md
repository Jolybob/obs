# Tourbillon scintillant
Vous utilisez vos mouvements et vos déguisements pour faire de vous une image floue. Vous êtes [[Masqué]] jusqu'à votre prochain tour. Comme lorsque l'état Masqué implique une manifestation visuelle évidente, vous ne pouvez pas utiliser cet état Masqué pour [[Vous cacher]].
