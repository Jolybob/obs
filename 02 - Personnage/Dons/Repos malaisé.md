# Repos malaisé
Lorsque vous Lancez [[Sommeil]], vous pouvez modifier le sort pour ajouter les éléments suivants à ses effets habituels : Les sujets de votre sort font des rêves troublés. Lorsqu'une cible qui a obtenu un échec ou un échec critique sur son jet de sauvegarde se réveille, elle est [[Effrayée 1]].
