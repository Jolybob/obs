# Bond explosif
Vous obtenez une explosion de votre innovation dirigée vers le bas pour vous lancer dans les airs. Vous sautez jusqu'à 9 mètres dans n'importe quelle direction sans toucher le sol. Vous devez atterrir sur une case de terre ferme ou vous tombez après avoir utilisé votre prochaine action. Comme c'est le cas normalement pour les effets où vous tombez après avoir utilisé votre prochaine action, vous tombez quand même à la fin de votre tour, même si vous n'utilisez pas d'autres actions au cours de ce tour.





**Spécial** Si votre innovation est un sbire, il peut effectuer cette action plutôt que vous.
