# Réprimande tranchante
Si les mots pouvaient tuer, le poète pourrait régner sur le monde. Vos mots le peuvent. Vous obtenez le don de compétence [[Bon Mot]]. Vous pouvez dépenser un Point mythique lorsque vous faites un test de Diplomatie pour Bon Mot pour tenter le test à une maîtrise mythique. Si le test est un succès, vous pouvez aussi infliger des @Damage[(@actor.level)[mental]]{dégâts mentaux égaux à votre niveau} à la cible (le double sur un succès critique).
