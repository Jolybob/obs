# Expertise avec les armes des génies
Lorsque vous obtenez une capacité de classe qui vous accorde une maîtrise experte ou supérieure avec certaines armes, vous obtenez cette maîtrise avec les [[Cimeterres à deux mains]], les [[Corsèques]], les [[Cimeterres]], les [[Tridents]] et toutes les armes des génies dans lesquelles vous êtes qualifiées.
