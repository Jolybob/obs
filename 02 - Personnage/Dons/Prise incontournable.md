# Prise incontournable
Votre prise présente une qualité surnaturelle, empêchant vos ennemis de s'échapper facilement, avec ou sans aide magique. Si une créature que vous avez [[Agrippé]] tente d'utiliser un sort ou un effet de téléportation, elle doit réussir un @Check[flat|dc:15] ou le sort échoue. Si une créature que vous avez Agrippé tente de [[S'Échapper]] alors qu'elle est sous l'effet d'un sort de [[Mouvement sans entrave]], elle doit réussir un @Check[flat|dc:15] ou être forcée de lancer le test pour S'Échapper normalement, au lieu d'obtenir un succès automatique.
