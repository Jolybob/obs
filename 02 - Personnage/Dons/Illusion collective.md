# Illusion collective
Vous brandissez des preuves fabriquées qui contredisent ce que vos ennemis savent être vrai. Lorsque vous Fabriquez la vérité, vous pouvez affecter tous les ennemis dans les 9 mètres autour de vous. Comparer le résultat de votre test de Duperie au DD de Volonté de toutes les cibles. Il est possible d'obtenir un degré de succès différent pour chaque cible.
