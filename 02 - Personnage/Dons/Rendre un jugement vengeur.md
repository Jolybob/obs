# Rendre un jugement vengeur
**Fréquence** Une fois par jour


**Conditions** Votre hiérophante a invoqué votre jugement lors de son tour précédent





Pour vous empêcher d'invoquer frivolement le terrible pouvoir de la colère divine, vous avez juré de ne le faire qu'avec l'assentiment de votre hiérophante mortel. Si votre hiérophante Frappe avec succès une cible, il peut dépenser une action unique pour invoquer votre courroux. Lors de votre tour, vous pouvez alors Rendre un jugement vengeur sur la cible, invoquant un pilier d'énergie divine décapant qui inflige @Damage[20d10[spirit]]{20d10 dégâts spirituels} avec un jet de @Check[fortitude|basic|against:class-spell]. Vous n'avez pas besoin de disposer d'une ligne d'effet vers la cible et cela fonctionne à n'importe quelle distance. Si l'un de vos domaines actuels peut infliger un type de dégâts autre que spirituel, vous pouvez choisir de le faire correspondre à ce type de dégâts (par exemple, invoquer un pilier enflammé qui inflige des dégâts de feu si vous possédez le domaine du feu).


Si vous dépensez un Point mythique en Rendant un jugement vengeur, l'explosion s'étend dans les cieux, éparpillant les nuages dans une détonation visible pour toutes les créatures dans un rayon de 15 kilomètres, comme une démonstration de courroux et un avertissement à tous ceux qui oseraient blesser vos fidèles, ou remettre en question vos commandements. Pendant le mois suivant, vous et votre hiérophante obtenez un bonus de statut de +2 aux tests d'Intimidation contre les créatures dans la zone.


[[Effet - Rendre un jugement vengeur]]





**Spécial** Si vous avez Source de vie ou de mort, vous pouvez choisir que ce type de dégâts soit de vitalité (si vous choisissez *Guérison*) ou de vide (si vous choisissez *Mise à mal*) lorsque vous utilisez cette capacité.





*Note : Paizo n'a pas précisé le DD pour cette capacité. Le bouton ci-dessus utilise le plus élevé entre votre DD de classe ou votre DD de sort.*
