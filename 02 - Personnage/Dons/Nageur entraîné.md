# Nageur entraîné
Grâce à une pratique infatigable, l'eau est devenue un environnement naturel pour vous. Vous obtenez une vitesse de nage de 4,50 mètres. Si vous disposez déjà d'une vitesse de nage permanente, la nage vers le haut ou le bas ne constitue pas un terrain difficile.
