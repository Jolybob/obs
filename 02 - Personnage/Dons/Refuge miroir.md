# Refuge miroir
**Fréquence** Une fois par jour


**Conditions** vous êtes à 1,50 mètre d'une surface réfléchissante.





Votre origine issue de l'espace derrière les miroirs vous permet d'utiliser un miroir comme cachette, comme le sort [[Uni à la pierre]]. Vous vous fondez dans un miroir adjacent. Vous pouvez entendre mais pas voir en dehors de cet espace et les créatures à l'extérieur ne peuvent pas vous voir ou vous entendre. Vous pouvez lancer des sorts lorsque vous êtes dans le miroir, mais aucun effet ne peut traverser le miroir. Votre refuge dans le miroir dure 10 minutes sauf si le miroir est brisé, ce qui vous expulse et vous inflige @Damage[10d6]{10d6 dégâts}. Vous pouvez Révoquer l'effet. Vous apparaissez dans une case adjacente au miroir lorsque l'effet prend fin.
