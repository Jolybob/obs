# Voler le ciel
Vous pouvez retirer l'air qui permet à un adversaire volant de rester en l'air. Vous obtenez le Sort Qi [[Voler le ciel]]. Augmentez le nombre de Points de focalisation de votre réserve de focalisation de 1.
