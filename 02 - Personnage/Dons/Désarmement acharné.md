# Désarmement acharné
Quand vous obtenez un succès, mais pas un succès critique, à un test pour [[Désarmer]] une créature, votre bonus de circonstances pour des tests ultérieurs pour Désarmer cette créature est de +4 au lieu de +2. Les autres créatures obtiennent uniquement le bonus ordinaire.


Quand vous obtenez un succès critique sur un test de Désarmement, vous pouvez immédiatement [[Démoraliser]] votre cible en dépensant une réaction.
