# Rechargement de l'infiltré
Vous vous spécialisez dans le rechargement en vous préparant pour la prochaine étape de votre infiltration. Interagissez pour recharger une arme avec laquelle vous êtes familier du fait de cet archétype, puis soit vous vous Cachez, [[Êtes furtif]] ou vous vous [[Mettez à l'abri]].
