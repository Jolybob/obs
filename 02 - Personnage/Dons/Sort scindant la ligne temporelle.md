# Sort scindant la ligne temporelle
**Fréquence** Une fois par jour





Vous investissez dans deux avenirs avant de choisir celui qui deviendra réalité. Vous Lancez deux sorts qui nécessitent chacun 1 ou 2 actions pour pouvoir être lancés. Il ne peut s'agir d'un même sort intensifié à deux rangs différents. Vous dépensez les ressources pour les deux sorts, comme les emplacements de sorts, les points de focalisation et les coûts, comme les po ou les objets de valeur. Déterminez immédiatement les résultats des deux sorts, y compris les jets d'attaque, les jets de sauvegarde, les dégâts et tout autre jet de dé. Choisissez ensuite lequel des deux sorts prendra effet, en utilisant les jets précédemment effectués. Les ressources de l'autre sort sont toujours dépensées mais le sort n'a aucun effet puisque sa magie disparaît dans l'autre ligne temporelle.
