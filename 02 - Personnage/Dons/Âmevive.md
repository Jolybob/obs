# Âmevive
L'élément métallique dans votre lignée coule littéralement dans vos veines sous le forme de liquides métalliques comme le mercure, le rubidium, le gallium et le djezet, donnant à vos action une fluidité langoureuse. Vous êtes qualifié en Acrobaties. Si vous êtes déjà qualifié en Acrobaties (du fait de votre historique ou de votre classe, par exemple), vous êtes alors qualifié dans une autre compétence de votre choix. Comme ces métaux sont largement toxique pour la vie organique, vous obtenez aussi l'action [[Contact toxique]].
