# Pont cosmique aux sept couleurs
**Utilisation** imprégné dans une ikône d'arme au corps-à-corps





Votre étincelle divine brille dans une émeute de couleurs chatoyantes, capable de vous transporter à travers le monde aussi vite que la lumière elle-même. L'ikône imprégnée obtient les capacités suivantes.


**Immanence** (lumière, téléportation) Votre arme asperge de lumière aux couleurs de l'arc-en-ciel votre voisinage immédiat, devenant une possible destination. Lorsque vous réussissez à Frapper un ennemi, vous pouvez choisir de vous téléporter dans un endroit inoccupé dans les 3 mètres par une action gratuite.


**Transcendance** - [[Un arc fugace traverse les cieux et la terre]] 3 (lumière, spirituel, téléportation, transcendance)
