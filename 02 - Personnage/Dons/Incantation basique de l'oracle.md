# Incantation basique de l'oracle
Vous obtenez les avantages du don [[incantation basique]]. Lorsque vous obtenez un emplacement de sort d'un nouveau rang de l'archétype d'oracle, ajoutez un sort divin courant ou un autre sort divin que vous avez appris ou découvert (incluant les sorts accordés par votre mystère) à votre répertoire de ce rang du sort.
