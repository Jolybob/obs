# Vision d'ombre
**Fréquence** Une fois par heure





Vous tirez sur votre lien avec le Nébulmonde pour voir à travers tout sauf l'obscurité la plus profonde. Vous obtenez [[Vision dans le noir supérieure]] pendant 1 minute.
