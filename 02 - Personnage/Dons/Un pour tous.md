# Un pour tous
Avec précisément les bons mots d'encouragement, vous soutenez les efforts d'un allié. Désignez un allié dans les 9 mètres. Cette action compte comme une préparation suffisante pour [[Aider]] cet allié. Lorsque vous utilisez la réaction Aider pour aider cet allié, vous pouvez lancer un test de @Check[diplomacy|traits:action:aid,bravado] au lieu du test habituel et l'action acquiert le trait bravade.
