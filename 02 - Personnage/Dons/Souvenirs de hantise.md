# Souvenirs de hantise
Votre âme porte les marques métaphysiques des innombrables autres esprits emprisonnés avec vous dans la [[Lame Finale]] dont vous vous êtes échappé, ce qui vous permet de puiser dans leurs souvenirs. Lors de vos préparatifs quotidiens, vous pouvez soit obtenir le rang de compétence expert dans une compétence dans laquelle vous n'êtes pas qualifié, soit augmenter votre rang de compétence à maître dans une compétence dans laquelle vous êtes déjà qualifié ou expert. Vous obtenez également un don de compétence dont le prérequis minimal est le rang correspondant à votre nouveau niveau de maîtrise dans la compétence choisie. Pour déterminer si vous remplissez les prérequis de niveau pour ce don, considérez que votre niveau est égal à la moitié de votre niveau réel.


Cette maîtrise temporaire et ce don durent jusqu'à vos prochaines préparatifs quotidiens. Étant donné que la maîtrise est temporaire, vous ne pouvez pas l'utiliser comme prérequis pour une option de personnage permanente.
