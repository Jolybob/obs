# Luminosité vitale
Vous apprenez comment créer un réservoir lumineux de vitalité que vous pouvez utiliser pour flétrir les morts-vivants qui osent vous attaquer. Vous obtenez le sort de domaine [[Luminosité vitale]]. Cela coûte 1 Point de focalisation de lancer un sort focalisé. Ce don vous accorde une réserve de focalisation de 1 Point de focalisation que vous pouvez récupérer en utilisant l'activité Refocaliser.
