# Sang de pierre (rochelié)
Votre sang devient épais et lent, mais il n'en est pas moins efficace pour oxygéner vos cellules. Vous pouvez décider d'arrêter le saignement avec facilité. Vous pouvez utiliser une unique action avec le trait concentration pour obtenir un test de récupération anticipé sans avoir à refermer physiquement les blessures. Vous vous remettez de l'état drainé deux fois plus rapidement que la normale.
