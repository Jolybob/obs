# Explorateur vigilant
Vous avez exploré suffisamment de tombes poussiéreuses et de chambres fortes pour développer un sixième sens concernant les pièges et vous les remarquez parfois sans même les avoir cherchés.


Même si vous n'êtes pas en train de [[Fouiller]] dans une phase d'exploration, vous faites un test pour trouver des pièges qui nécessiteraient normalement que vous Fouilliez. Vous devez tout de même répondre à toute autre condition pour trouver le piège.
