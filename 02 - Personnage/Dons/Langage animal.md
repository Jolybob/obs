# Langage animal
Vos liens avec les habitants de la nature devient plus importante encore plus fort et vous êtes capable de parler avec les animaux comme si vous le faisiez dans votre langue maternelle. Vous pouvez parler avec tous les animaux et les bêtes. Si vous possédez Empathie animale, vous obtenez un bonus de circonstances de +1 aux tests pour [[Faire bonne impression]] sur les animaux.
