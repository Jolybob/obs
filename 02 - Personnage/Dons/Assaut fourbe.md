# Assaut fourbe
Vous capitalisez sur la diversion que vous procure un allié. Vous [[/act sneak options=underhanded-assault]]{Êtes furtif} jusqu'à un adversaire adjacent à l'un de vos alliés. Vous pouvez lancer le test contre l'adversaire face auquel vous Êtes furtif, même s'il vous observe, comme si vous étiez Caché. Vous subissez une pénalité de -2 à votre test de Discrétion. Si votre test de Discrétion contre l'adversaire choisi est un succès, vous pouvez faire une Frappe au corps-à-corps contre cet adversaire à la fin de votre déplacement Furtif.
