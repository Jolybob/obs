# Aisance gracieuse
En adoptant la bonne position, votre main secondaire peut frapper comme le ferait le dard d'un scorpion. Tant que vous êtes dans cette posture, si vous effectuez votre deuxième Frappe grâce à [[Double taille]] avec une arme agile, Double taille compte comme une attaque dans le calcul de votre pénalité d'attaques multiples.
