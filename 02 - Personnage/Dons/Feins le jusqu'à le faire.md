# Feins le jusqu'à le faire
Lorsque vous assumez un rôle, vous devenez plus compétent pour toutes sortes de tâches relatives à ce rôle. Lorsque vous Assumez un rôle, choisissez deux compétences associées au rôle d'une manière ou d'une autre. Si vous n'êtes pas qualifié, vous pouvez utiliser votre niveau comme bonus de compétence pour ces compétences et vous obtenez un bonus de circonstances de +1 aux tests de compétence avec ces compétences tant que vous restez dans ce rôle. Vous et le MJ déterminez quelles compétences vous assumez.
