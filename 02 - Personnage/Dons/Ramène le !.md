# Ramène le !
**Conditions** Vous maniez un harpon, une arme du groupe des lances ou un filet attaché à une corde.





Vous avez développé les techniques de combat inspirées par les méthodes que les pêcheurs utilisent pour attraper un gros poisson. Portez une Frappe avec une arme requise ou [[/act grapple]]{Saisissez} avec un filet. Si l'attaque touche, vous pouvez tenter un test d'@Check[athletics|against:fortitude]{Athlétisme} contre le DD de Vigueur de la cible. En cas de succès, vous tirez la cible de 3 mètres vers vous.
