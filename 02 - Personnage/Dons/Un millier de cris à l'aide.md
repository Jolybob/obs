# Un millier de cris à l'aide
Vous avez appris à communiquer avec les créatures partout dans le monde, surmontant les barrières de langue pour prêter main forte et aider là où l'on a besoin de vous. Vous êtes constamment affecté par un sort de [[Xénoglossie]].


Lorsque vous tentez un test de Diplomatie pour [[Faire bonne impression]] ou [[Solliciter]], vous pouvez dépenser un point mythique pour faire le test avec la maîtrise mythique.
