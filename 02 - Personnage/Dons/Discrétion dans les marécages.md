# Discrétion dans les marécages
**Conditions** Vous êtes dans un environnement marécageux  près d'un élément de l'environnement qui vous permettrait de vous [[Mettre à l'abri]].





Dans les marécages, vous êtes particulièrement doué pour vous cacher rapidement derrière des sous-bois ou le feuillage ou à vous déplacer silencieusement à travers les eaux troubles. Vous vous Mettez à l'abri puis utilisez cet abri pour vous [[Cacher]].
