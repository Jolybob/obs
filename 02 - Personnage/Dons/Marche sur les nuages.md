# Marche sur les nuages
Votre lien grandissant avec les dragons des nuages vous fait bénéficier de la capacité de marcher sur les nuages. Une fois par heure, vous pouvez lancer [[Marche dans les airs]] sur vous-même comme un sort inné arcanique mais seulement pour marcher sur des nuages ou du brouillard.
