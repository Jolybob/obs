# Détourner le mauvais sort
**Déclencheur** Vous devriez tenter un jet affecté par un effet d'infortune.





Vous accomplissez un geste de superstition, comme jeter du sel au-dessus de votre épaule pour conjurer la malchance. Le trait fortune de Détourner le mauvais sort annule l'effet d'infortune, vous permettant de faire un jet normal. Comme à l'ordinaire, vous ne pouvez appliquer qu'une seule capacité de fortune à un jet, donc si vous avez Détourné le mauvais sort sur un jet d'attaque, vous ne pouvez pas également utiliser une capacité comme [[Chance du Halfelin]] pour modifier le jet davantage.
