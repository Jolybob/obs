# Lire dans le vent
Lorsque vous traquez un ennemi, vous pouvez tirer un sens des plus infimes détails. Lorsque vous réussissez un test pour [[Pister]] avec une maîtrise mythique, vous pouvez immédiatement tenter un test pour Vous Souvenir à propos de la créature que vous pistez, également avec une maîtrise mythique et avec une compétence appropriée déterminée par le MJ.
