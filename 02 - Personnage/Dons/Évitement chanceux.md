# Évitement chanceux
**Fréquence** Une fois par jour


**Déclencheur** Une créature vous cible avec une attaque même si vous n'en êtes pas conscient.





Votre ennemi vous attend patiemment, vous met en joue pour porter le tir parfait et appuie sur la détente... puis, à ce moment exact, vous vous baissez pour remarquer quelque chose griffonné à la craie sur les pavés, une pièce brillante ou tout autre distraction, la coïncidence créant une opportunité pour que l'attaque vous manque. L'attaquant doit lancer deux fois l'attaque et utiliser le plus mauvais résultat.
