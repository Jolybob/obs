# Voler la magie
Vous ne vous contentez pas de contrer la magie de votre ennemi, vous la maîtrisez instantanément et la faites vôtre. Lorsque vous réussissez à contrer un sort ennemi en utilisant [[Contresort mythique]], vous pouvez apprendre ce sort tant qu'il figure dans la liste des sorts de votre tradition. Si vous disposez d'un grimoire, le sort est instantanément inscrit dans le livre, créant de nouvelles pages blanches si nécessaire. Si vous disposez d'un répertoire de sort,vous pouvez instantanément réapprendre n'importe quel sort dans votre répertoire pour le sort contré, bien que si le sort remplace celui qui vous a été accordé par une capacité de classe (tel que les sorts d'apparition de l'animiste ou les sorts de lignage d'un ensorceleur), le sort revient à celui normalement accordé par cette capacité de classe au cours de vos prochains préparatifs quotidiens.
