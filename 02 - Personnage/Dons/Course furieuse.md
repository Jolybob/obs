# Course furieuse
Vous vous précipitez en avant. Vous Marchez rapidement 5 fois ou jusqu'à 8 fois si vous avez utilisé 3 actions. L'entièreté de ce déplacement doit se faire en ligne droite (bien que le MJ puisse autoriser des ajustements raisonnables). Vous pouvez remplacer n'importe laquelle de ces Marches rapides par une action de [[Garder l'équilibre]] si cela s'avère nécessaire, pour lequel vous tentez d'utiliser un test d'[[/act balance skill=athletics]]{Athlétisme} au lieu d'utiliser Acrobaties, en utilisant le même DD.
