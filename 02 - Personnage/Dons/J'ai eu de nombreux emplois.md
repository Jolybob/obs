# J'ai eu de nombreux emplois
Trouver et exceller dans les petits boulots est un jeu d'enfant pour celui qui a exercé de nombreux métiers au cours de nombreuses vies. Lorsque vous tentez de [[Gagner de l'argent]], vous fonctionnez comme si vous étiez qualifié dans la compétence utilisée. Si vous êtes au moins expert dans la compétence utilisée, le DD pour le test de compétence est réduit de 2.
