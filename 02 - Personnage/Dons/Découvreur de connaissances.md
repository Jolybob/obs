# Découvreur de connaissances
Vous savez que parfois le destin complote à cacher les connaissances ou les objets dangereux loin des yeux de ceux capables de les comprendre. Vous refusez au destin la capacité de vous cacher les vérités. Vous pouvez lancer [[Localisation]] comme un sort inné occulte une fois par jour.


Lorsque vous atteignez le niveau 14, ce sort est intensifié au rang 5.
