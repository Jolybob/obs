# Charge dispersante
**Conditions** Vous maniez une armure intermédiaire ou lourde.





Vous chargez un groupe d'ennemis pour les envoyer valdinguer. Marchez rapidement à votre Vitesse. À la fin de votre déplacement, vous pouvez [[Pousser]] jusqu'à trois  créatures dans votre allonge. Vous n'avez pas besoin d'avoir une main disponible pour le faire. Vous tentez un test d'Athlétisme pour chacun. Chaque tentative est décomptée de votre pénalité d'attaques multiples, mais la pénalité n'augment que lorsque vous avez effectué toutes vos tentatives. Quel que soit vos résultats, vous ne pouvez Marcher rapidement pour suivre aucune des cibles.
