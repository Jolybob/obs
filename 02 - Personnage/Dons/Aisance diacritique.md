# Aisance diacritique
**Fréquence** Une fois toutes les 10 minutes





Lorsque vous prêtez davantage attention, vous pouvez modifier une rune avec une grande rapidité. La prochaine fois que vous [[Tracez une rune]] durant ce tour, vous pouvez également Tracer une Rune diacritique sur cette rune.
