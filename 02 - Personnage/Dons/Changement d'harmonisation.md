# Changement d'harmonisation
**Fréquence** Une fois toutes les 10 minutes


**Conditions** Votre précédente action consistait à Lancer un sort avec le trait air, eau, feu, froid, plante ou terre.





La magie de votre sort vous envahit, prenant le pas sur votre lien avec la terre qui vous environne. Vous modifiez le terrain de votre harmonisation pour un terrain qui correspond à un trait du sort que vous venez de lancer. Vous gagnez ainsi l'avantage d'harmonisation du terrain lorsque vous lancez d'autres sorts avec le même descripteur, au lieu d'utiliser le terrain dans lequel vous vous trouvez réellement. Par exemple, si vous lancez [[Flore enchevêtrante]], votre harmonisation de terrain change pour devenir à votre choix celle correspondant à forêt ou marais et votre harmonisation de terrain s'applique lorsque vous lancez un autre sort avec le trait plante.


Votre harmonisation au terrain revient à celle du terrain sur lequel vous vous trouvez 1 minute après avoir utilisé Changement d'harmonisation.
