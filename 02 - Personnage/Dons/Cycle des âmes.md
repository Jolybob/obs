# Cycle des âmes
**Déclencheur** Votre tour commence.





Vos alliés spirituels guident vos déplacements, vous permettant de vous préparer pour les épreuves qui vous attendent à une vitesse plus rapide que la pensée. Vous Faites un pas, puis prenez une posture d'animiste que vous connaissez.
