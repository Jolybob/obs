# Sort purifiant
Imprégné de lumière céleste, votre magie peut plus efficacement guérir les blessures et purger les afflictions. Si votre prochaine action consiste à Lancer un sort avec le trait guérison sur une créature vivante, une cible de ce sort regagne un @Damage[(@actor.level)[healing]]{nombre de Points de vie égal à votre niveau} (en plus de tout Point de vie qu'elle devrait normalement obtenir). De plus, vous pouvez tenter de contrer une maladie ou un poison affectant une cible de ce sort. Ces deux cibles peuvent être la même créature ou des créatures différentes, tant qu'elles sont toutes deux les cibles du sort de guérison.
