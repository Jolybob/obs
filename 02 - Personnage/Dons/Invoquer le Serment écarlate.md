# Invoquer le Serment écarlate
Vous pouvez invoquer le Serment écarlate pour relâcher des explosions d'énergie de couleur rubis à partir de votre arme. Vous obtenez le sort focalisé [[Invoquer le Serment écarlate]]. Si vous n'en possédiez pas déjà une, vous obtenez une réserve de focalisation avec 1 Point de focalisation qui peut être regagné en utilisant l'activité [[Refocaliser]] en récitant le Serment écarlate et en méditant sur ses enseignements. Si vous possédiez déjà une réserve de focalisation, augmentez le nombre de Points de focalisation de votre réserve de focalisation de 1. Vos sorts focalisés de Chevalier reconquérant sont des sorts divins ; Lorsque vous obtenez ce don, vous êtes qualifié dans les attaques de sorts et le DD des sorts divins.
