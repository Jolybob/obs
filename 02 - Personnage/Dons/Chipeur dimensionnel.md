# Chipeur dimensionnel
Vous avez une capacité surnaturelle à voler des objets sous le nez de leurs propriétaires. Faites un test de Vol pour Escamoter un objet ou [[/act steal]]{Voler} un objet que vous pouvez voir dans les 18 mètres. Si vous êtes voilé, vous obtenez un bonus de circonstances de +2 à ce test. Si vous réussissez, l'objet disparaît de son emplacement actuel et apparaît sur votre personne.
