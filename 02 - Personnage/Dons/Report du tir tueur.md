# Report du tir tueur
**Conditions** Votre Frappe de sort réduit un ennemi à 0 PV.





Lorsque vous abattez un ennemi, un écho retentissant se fait entendre lorsque vous liez l'énergie du sort à une créature proche. Choisissez un cible secondaire dans les 3 mètres de la créature que vous avez amenée à 0 PV. Cette cible secondaire est affectée par le sort vous avez utilisé pour votre Frappe de sort. La créature bénéficie de toute défense contre le sort que cette Frappe de sort permet normalement et vous utilisez le résultat de votre Frappe de sort pour le jet d'attaque de sort si nécessaire. Si la cible secondaire était déjà affectée par le sort d'une quelconque manière (dans la zone d'une [[Frappe de sort étendue]], par exemple), il ne peut être affecté une seconde fois.
