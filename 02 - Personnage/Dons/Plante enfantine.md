# Plante enfantine
Vous êtes capable de dissimuler vos traits végétaux pour vous faire passer pour un humain. Vous êtes qualifié en Duperie (ou dans une autre compétence si vous étiez déjà qualifié en Duperie). Vous n'avez pas besoin d'un kit de déguisement lorsque vous tentez des tests de Duperie pour Vous faire passer pour un humain. De plus, vous obtenez un bonus de circonstances de +4 aux tests pour Vous faire passer pour une version humaine de vous-même, au lieu d'un léchi. Ce bonus ne s'applique pas aux autres tests pour Vous faire passer pour un humain.
