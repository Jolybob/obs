# Développement psy
Vous avez trouvé une nouvelle forme mentale. Vous obtenez un autre tour de magie psy de votre esprit conscient : soit le tour de magie ordinaire que vous n'avez pas pris avec Dévouement : Psychiste, soit le tour de magie unique de surface. Vous obtenez les avantages du psychiste pour ce second tour de magie psy. Vous obtenez la capacité d'amplifier vos tours de magie psy. Si vous n'en avez pas, vous obtenez une réserve de focalisation de 1 point de focalisation, que vous pouvez utiliser pour amplifier vos tours de magie psy et vous pouvez Refocaliser en méditant sur vos nouveaux pouvoirs.
