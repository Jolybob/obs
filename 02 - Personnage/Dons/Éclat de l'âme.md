# Éclat de l'âme
**Déclencheur** Une attaque que vous avez faite avec une arme mentallurgique rate une créature ou une créature vous touche avec une attaque alors que vous portez soit une armure mentallurgique manifestée, soit que votre bouclier mentallurgique levé.


**Conditions** Votre arsenal mentallurgique est manifesté.





Vous vous efforcez de changer l'issue avec un zèle sans faille. Vous obtenez un bonus de statut de +1 à votre jet d'attaque si vous portez une attaque ou à votre CA si vous avez été touché. Cela peut changer le résultat du jet. Si ce bonus transforme votre attaque manquée en un succès ou le succès contre vous en échec, faites un @Check[flat|dc:5]. En cas d'échec, votre arsenal mentallurgique est Révoqué : votre arme si vous avez attaqué ou votre armure ou votre bouclier si vous vous défendiez.
