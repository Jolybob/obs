# Jambes de pierre
Vous obtenez un bonus de statut de +2 aux DD de vos tests de Vigueur et de Réflexes contre les tentatives pour vous [[Pousser]] ou pour vous faire un [[Croc-en-jambe]]. Vous pouvez Pousser les créatures même si vous ne disposez pas d'une main libre. Lorsque vous parvenez à Pousser un adversaire, vous pouvez Marcher rapidement pour vous éloigner de votre adversaire (au lieu d'avancer vers lui), mais vous devez vous déplacer de la même distance dans la direction opposée à celle dans laquelle vous l'avez poussé.
