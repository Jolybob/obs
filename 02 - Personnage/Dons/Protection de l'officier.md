# Protection de l'officier
Lorsque vous utilisez [[Engagement de protection]], vous pouvez cibler tous les alliés dans un rayon de 9 mètres. Si vous avez [[Protection durable]], les effets sur tous les alliés s'appliquent jusqu'au début de votre prochain tour.
