# Rechargement à deux armes
Vous transportez vos munitions d'une manière qui vous permet de recharger tout en portant deux armes. Lorsque vous maniez deux armes à une main, chacune dans une main différente, vous n'avez pas besoin de disposer d'une main libre pour recharger une arme à une main que vous êtes en train de manier.
