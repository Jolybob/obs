# Passer entre
**Fréquence** Une fois toutes les 10 minutes





En un clin d'œil, vous vous transportez vous-même ainsi que tout objet que vous maniez ou portez de votre espace actuel à un espace inoccupé dans les 18 mètres que vous pouvez voir. Si cela devrait emmener une autre créature avec vous, même si vous la transportez dans un conteneur extradimensionnel, vous ne pouvez pas Passer entre. Lorsque vous arrivez à votre destination, vous pouvez Lever le voile par une action gratuite, même si vous ne devriez pas en remplir les conditions. Si vous êtes Caché, cette action n'a pas pour effet de vous rendre observé tant que vous avez toujours un abri, un abri supérieur ou restez masqué des créatures dont vous étiez Caché après la téléportation.
