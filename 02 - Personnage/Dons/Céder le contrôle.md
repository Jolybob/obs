# Céder le contrôle
**Déclencheur** Votre tour commence.





Votre apparition prend le dessus et vous protègent des influences extérieures. Jusqu'au début de votre prochain tour, vous obtenez un bonus de statut de +4 sur les jets de sauvegarde contre les sorts et les effets qui vous donnent l'état [[Contrôlé]] ou tentent d'influencer vos actions (tel que [[Charme]], [[Injonction]] ou la mélodie envoûtante d'un nosoi). Quoi qu'il en soit, les seules actions que vous pouvez entreprendre sont [[Se souvenir]], Faire un pas, Frapper, Lancer un sort d'apparition, Lancer un sort de réceptacle, Maintenir un sort de réceptacle ou utiliser une action qui possède le trait apparition. Vous obtenez un bonus de circonstances de +2 sur tous les tests pour Vous souvenir effectués en utilisant les compétences de connaissances accordées par vos apparitions harmonisées.





**Spécial** Ce don nécessite un lien particulièrement fort avec une apparition spécifique pour l'apprendre. Choisissez une apparition à laquelle vous avez accès. Une fois que vous apprenez ce don, vous devez toujours choisir cette apparition comme l'une des apparitions avec laquelle vous vous harmonisez chaque jour.
