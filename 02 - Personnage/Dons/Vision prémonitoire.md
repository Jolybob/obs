# Vision prémonitoire
**Conditions** Vous êtes en [[Transe du rêve éveillé]]





Vous utilisez vos rêves éveillés pour prédire le succès des actions, visionnant rapidement les possibilités. Une fois avant la in de votre prochain tour, vous pouvez faire appel à ces prédictions avant de lancer un jet de sauvegarde ou un test de compétence. Vous pouvez lancer le jet de sauvegarde ou le test de compétence deux fois et conserver le meilleur résultat.
