# Érudit du bestiaire
Vous apprenez comment appliquer votre connaissance approfondie de certaines des créatures en utilisant les connaissances que vous possédez. Quand vous obtenez ce don, choisissez l'une des compétences suivantes dans laquelle vous êtes devenu maître : Arcanes, Artisanat, Nature, Occultisme ou Religion. Vous pouvez utiliser la compétence choisie pour Vous souvenir afin d'identifier toute créature normalement identifiable par l'une des compétences ci-dessus. En outre, lorsque vous obtenez un succès critique pour identifier une créature, vous obtenez un bonus de circonstances de +1 à votre prochain jet d'attaque ou de sauvegarde contre cette créature.
