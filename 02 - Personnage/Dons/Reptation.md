# Reptation
Vous êtes un expert lorsqu'il s'agit de vous déplacer à travers les espaces extrêmement étroits. Vous obtenez le don de compétence [[Se faufiler rapidement]], même si vous n'êtes pas qualifié en Acrobaties. Lorsque vous obtenez un succès sur un test d'Acrobaties pour Vous faufiler, il devient un succès critique.
