# Métamorphose explosive
Vous utilisez de l'énergie primordiale supplémentaire pour vous transformer, créant ainsi une poussée d'énergie élémentaire pour compléter votre transformation. Si votre prochaine action consiste à lancer un sort qui n'est pas un tour de magie de transformation ou de métamorphose, choisissez entre acide, électricité, feu ou froid. Votre transformation crée une @Template[emanation|distance:5]{émanation de 1,50 mètre} autour de votre nouvelle forme qui inflige 1d6 dégâts de ce type par rang du sort. Chaque créature dans cette zone tente un jet de Réflexes basique contre votre DD de sort.


Si votre action de métamorphose possède un trait correspondant à un type d'énergie, vous devez choisir celui là si c'est possible. Cette action obtient le trait correspondant au type d'énergie choisi.
