# Leurrer
**Déclencheur** Un allié est sur le point d'utiliser une action qui nécessite un jet d'attaque, ciblant une créature dans le premier facteur de portée de votre arme.


**Conditions** Vous maniez une arme à feu ou une arbalète chargée.





Grâce à un mouvement alambiqué avec votre arme, vous forcez un ennemi à vous considérer comme une menace. Faites un jet d'attaque pour [[Aider]] l'attaque déclencheuse. Si vous aviez infligé des dégâts à cet ennemi avec la même arme depuis le début de votre dernier tour, vous obtenez un bonus de circonstances de +1 sur ce jet.
