# Prendre son envol
**Fréquence** Une fois par round





Vous avez renforcé vos ailes et pouvez désormais voler sur de courtes distances. Vous Volez. Si vous ne possédez pas déjà une vitesse de vol, vous obtenez une Vitesse de vol de 4,50 mètres pour ce déplacement. Si vous n'êtes pas sur un sol solide à la fin de ce déplacement, vous tombez.
