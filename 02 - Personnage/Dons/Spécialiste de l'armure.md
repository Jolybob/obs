# Spécialiste de l'armure
Vous vous êtes entraîné dur à optimiser les qualités protectrices uniques de votre armure pour maximiser l'usage de matériaux utilisés dans sa fabrication. Vous obtenez les effets de spécialisation des armures avec toutes les armures pour lesquelles vous avez une maîtrise.
