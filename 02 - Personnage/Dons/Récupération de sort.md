# Récupération de sort
**Conditions** L'action d'un ennemi a interrompu votre tentative pour Lancer un sort depuis le début de votre dernier tour.





Vous récupérez l'énergie d'un sort récemment interrompu, vous permettant de le lancer de nouveau tant que vous le faites immédiatement, avant que l'énergie ne se dissipe. Vous récupérez l'utilisation d'un sort qui a été interrompu depuis le début de votre dernier tour mais vous devez immédiatement Lancer le sort avec votre prochaine action ou bien vous perdez le sort. Comme à l'ordinaire avec la mutamagie, ce doit être durant le même tour que celui de l'utilisation de Récupération de sort. Vous pouvez changer la zone, les cibles et d'autres variables, y compris le nombre d'actions utilisées pour Lancer le sort si celui-ci le permet, comme lorsque vous lancez [[Guérison]] ou [[Salve de force]].
