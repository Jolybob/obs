# Déduction trompeuse
**Déclencheur** Une créature que vous pouvez voir utilise [[Se Souvenir]].





Vous avez dû endosser de nombreux rôles lorsque vous avez travaillé sous couverture de sorte que vous êtes habitué à suivre l'exemple de ceux qui vous entourent pour prétendre être experts dans divers domaines. Vous apprenez quelle compétence la créature utilisait pour Se Souvenir et si cette créature est qualifiée dans cette compétence. Si elle est qualifiée, vous pouvez utiliser Duperie pour Vous Souvenir comme s'il s'agissait de cette compétence pendant la minute suivante.
