# Compagnon endurci par le combat
Le compagnon que vous avez obtenu avec [[Compagnon du commandant]] est désormais un compagnon animal agile ou sauvage.


Votre compagnon animal est particulièrement réceptif à votre volonté. Au cours d'une rencontre, même si vous n'utilisez pas l'action Diriger un animal, votre compagnon peut tout de même utiliser une action à votre tour durant ce round pour Marcher rapidement ou Frapper. S'il le fait, il obtient aussi une réaction qu'il peut utiliser pour répondre à vos tactiques, mais ce sont les seules actions qu'il obtient lors de ce round. Vous ne pouvez plus le Diriger par la suite durant ce même round.
