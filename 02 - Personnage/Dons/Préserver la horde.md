# Préserver la horde
**Déclencheur** Vous Lancez [[Convocation de mort-vivant]].


**Conditions** Votre horde est relevée.





L'acte de convoquer des sbires morts-vivants supplémentaires ne vous fait pas perdre la concentration nécessaire pour maintenir l'animation de votre horde. Vous Maintenez votre horde.
