# Image rémanente
**Déclencheur** Vous utilisez une action ou lancez un sort avec le trait téléportation.





Vous laissez derrière vous une image rémanente de vous-même dans votre précédent emplacement. Cette image rémanente vous ressemble et peut reproduire des comportements simples pour rendre la supercherie plus plausible mais elle ne peut ni se déplacer, ni entreprendre d'action. Une créature peut distinguer entre vous et votre image rémanente facilement. Votre image rémanente obtient automatiquement un échec sur tous les tests et DD et est détruite si elle subit le moindre dégât. Autrement, elle persiste pendant 1 minute. Lorsque vous accomplissez l'action Faire un pas, vous pouvez à la place vous pouvez vous téléporter à la place jusqu'à l'image rémanente. Si vous le faites, l'action obtient le trait téléportation et l'image rémanente est détruite.
