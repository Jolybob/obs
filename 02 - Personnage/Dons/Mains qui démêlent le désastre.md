# Mains qui démêlent le désastre
Vos mains se déplacent avec une étrange sûreté, démantelant les dangers. Lorsque vous tentez un test d'Acrobaties pour [[Se raccrocher in extremis]], vous pouvez dépenser un Point mythique pour tenter le test avec une maîtrise mythique. Vous pouvez dépenser un Point mythique lorsque vous tentez de [[Désamorcer un dispositif]] pour tenter le test avec une maîtrise mythique. Comme à l'ordinaire en tentant un test avec une maîtrise mythique, ceci permet de tenter de Désamorcer un dispositif même si le test nécessite normalement une maîtrise experte ou supérieure.
