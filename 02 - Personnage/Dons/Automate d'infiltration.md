# Automate d'infiltration
Vous disposez d'articulation silencieuses et bien graissées et vous déplacez autour aussi silencieusement qu'une ombre, bien que vous puissiez quelques fois utiliser un renfort magique. Vous obtenez un bonus de circonstances de +2 aux tests de Discrétion contre les tests de perception basés sur l'ouïe. Vous pouvez lancer [[Silence]] une fois par jour sur vous-même comme un sort inné arcanique de rang 2.


**Amélioration** Vous pouvez lancer *Silence* sur fois par jour sur vous-même et vous pouvez choisir de le lancer comme un sort de rang 2 ou de rang 4.
