# Glissant comme une anguille
Vous imitez les mouvements ondulants d'une anguille. Lorsque vous êtes sous l'eau, vous obtenez un bonus de circonstances de +2 aux tests d'Acrobaties pour vous [[/act escape skill=acrobatics]]{Échapper}, vous [[/act squeeze]]{Faufiler} et pour effectuer un [[/act tumble-through]]{Déplacement acrobatique}.
