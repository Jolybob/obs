# Dévouement - Jongleur
Vous êtes qualifié en Représentation ; si vous l'étiez déjà, vous êtes qualifié dans une compétence de votre choix. Vous obtenez aussi le don de compétence [[Jonglage]], même si vous n'en remplissez pas les conditions.





**Spécial** Vous ne pouvez obtenir un autre don de dévouement avant d'avoir obtenu un autre don de l'archétype de [[jongleur]].
