# Visualisation métallique
Vous tenez toujours compte de toutes les faiblesses, permettant à votre esprit d'imaginer la forme physique idéale pour prendre l'avantage sur vos adversaires. Choisissez entre fer froid et argent. Toutes les Frappes de votre arme spirituelle sont traitées comme si elles étaient réalisées avec le type de métal choisi.
