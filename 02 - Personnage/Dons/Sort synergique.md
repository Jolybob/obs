# Sort synergique
Vous combinez votre synergie et vos sorts en une fantastique toile de magie, vous permettant de lancer deux sorts en même temps. Si la prochaine action que vous utilisez consiste à Lancer un sort de l'un de vos emplacements syncrétiques, après que ce sort soit résolu, vous pouvez Lancer un autre sort par une action gratuite. Ce sort doit être lancé à partir de l'un de vos emplacements de sort syncrétique et être un de ceux qui se lancent normalement en utilisant deux actions pour le lancer.
