# Détecteur de mort-vivant
Vos études sur les morts-vivants vous ont appris les signes révélateurs d'une créature morte-vivante déguisée. Lorsque vous [[Suivez une piste]] qui implique un cadavre ou une créature dans votre allonge, vous pouvez toucher ce cadavre ou cette créature pour déterminer immédiatement si elle est morte-vivante. Vous obtenez aussi un bonus de circonstances de +1 aux tests pour [[Vous souvenir]] à propos de créatures mortes-vivantes et pour déterminer si une créature est morte-vivante.
