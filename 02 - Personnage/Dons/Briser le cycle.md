# Briser le cycle
Parfois, des personnes qui n'ont pas de différend à proprement parler se sont battues les unes contre les autres par simple dépit. Vous venez briser ce cercle vicieux de la haine. Vous obtenez le don de compétence [[Négociation légendaire]], même si vous ne devriez âs normalement être qualifié. De plus lorsque vous faites un test de Diplomatie, vous pouvez dépenser un point mythique pour le faire avec la maîtrise mythique.
