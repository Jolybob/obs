# Éclaireur perpétuel
Vous remarquez tout ce qui n'est pas à sa place dans les zones que vous connaissez le mieux. Lorsque vous êtes sur votre [[Terrain de prédilection]], vous obtenez toujours les avantages de l'activité d'exploration [[Reconnaître]], même si vous accomplissez une autre activité d'exploration.


Si vous êtes légendaire en Survie, vous obtenez ces avantages sur tous les terrains.
