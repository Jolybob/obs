# Sort de lignage basique
Vous gagnez le sort de lignage initial de votre lignage. Si vous n'en avez pas déjà une, vous obtenez également une réserve de focalisation d'une valeur de 1 point de focalisation, que vous pouvez Refocaliser sans effort particulier.
