# Grimpeur expérimenté
Vous pouvez naviguer sur des surfaces verticales avec facilité. Vous obtenez une Vitesse d'escalade de 3 mètres. Si vous possédez également le don ancestral Détaler vers le haut, votre Vitesse d'escalade est égale à votre Vitesse terrestre lorsque vous montez aux arbres ou escaladez les parois des cavernes.
