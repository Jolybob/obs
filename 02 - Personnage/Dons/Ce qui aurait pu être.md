# Ce qui aurait pu être
Au lieu de conjurer des créatures d'ailleurs dans le monde ou sur les plans, vous pouvez temporairement tirer une version très différente de vous-même d'une ligne temporelle alternative. Par exemple, au lieu d'invoquer un troll générique ou aléatoire avec [[Convocation de géant]], vous invoquez une version troll de vous-même d'une ligne temporelle où vous êtes un troll. Si votre prochaine action consiste à Lancer un sort qui invoque une créature, cette créature est une autre version de vous. Cette créature reste du type de créature que vous avez invoqué et possède en grande partie les mêmes capacités (plus les ajustements suivants) mais elle vous ressemble clairement, partageant probablement certains traits distinctifs, comme vos manières, vos habitudes de parole, vos tatouages ou les mêmes vêtements. La créature invoquée bénéficie d'un bonus de statut de +1 à tout test de compétence dans lequel vous êtes qualifié, de +2 si vous êtes expert, de +3 si vous êtes maître ou de +4 si vous êtes légendaire. La créature subit également une pénalité de -2 à toutes les compétences dans lesquelles vous n'êtes pas qualifié.
