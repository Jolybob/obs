# Bombe incapacitante
Vous pouvez ajouter un additif cristallin à une bombe alchimique pour qu'elle ébranle votre ennemi. Choisissez entre les états [[Ébloui]], [[Pris au dépourvu]], [[Sourd]] ou une pénalité de statut de -1,50 mètre à toutes les Vitesses. Si l'attaque avec cette bombe touche, la cible doit réussir un jet de @Check[fortitude|against:class] ou subir l'effet choisi jusqu'au début de votre prochain tour. Utilisez votre DD de classe pour ce jet de sauvegarde, même si quelqu'un d'autre lance la bombe.
