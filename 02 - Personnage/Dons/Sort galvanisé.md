# Sort galvanisé
**Fréquence** Une fois par jour


**Conditions** Votre aura de [[Déferlement de sort]] est active.





Vous réabsorbez la magie de votre *déferlement de sort* pour alimenter un peu de votre puissante magie. Dépensez un Point mythique. Votre *Déferlement de sort* se termine. Si votre prochaine action consiste à Lancer un sort qui est d'au moins 2 rangs inférieurs à l'emplacement de sort le plus élevé que vous possédez, vous réduisez le nombre d'actions pour le lancer de 1 (1 action minimum). Vous regagnez alors immédiatement la capacité de lancer ce sort de nouveau (avec les paramètres normaux) ou l'emplacement du sort utilisé.
