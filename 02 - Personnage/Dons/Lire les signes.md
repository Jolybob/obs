# Lire les signes
Vous avez un don pour tirer la carte parfaite, que ce soit d'un jeu du Tourment, d'un jeu de cartes ou même lorsque vous la tirez d'un *[[Paquet de cartes merveilleuses]]*. Lorsque vous tentez un test de Connaissance impliquant que le tirage de cartes ou pour résoudre les effets d'un effet de divination (incluant tenter un jet de sauvegarde contre un effet de divination hostile contre vous), vous obtenez un bonus de statut de +2 au test. Lorsque vous tirez une carte pour déterminer votre présage de Tourment, accomplir une Incantation du Tourment, lancer [[Tirage du Tourment]] ou si vous activez un paquet de cartes magiques, tirez 2 cartes et choisissez celle que vous préférez comme carte actuelle. Vous pouvez même utiliser cette capacité lorsque vous tirez une carte d'un *Paquet de cartes merveilleuses*, mais seulement une fois par paquet. La carte inutilisée est remise dans la pile.
