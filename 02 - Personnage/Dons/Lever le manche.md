# Lever le manche
Vous savez comment utiliser le manche des armes plus grandes pour parer les attaques de vos ennemis. Les armes à deux mains que vous maniez obtiennent le trait parade. Si l'arme possède déjà le trait parade, le bonus de circonstances à la CA qu'elle procure passe à +2.
