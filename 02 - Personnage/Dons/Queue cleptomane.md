# Queue cleptomane
Vous pouvez effectuer des méfaits mineurs avec votre queue. Vous pouvez utiliser votre queue pour [[Voler]] un objet, bien que votre queue ne puisse pas le garder à la fin de votre action. Si vous disposez d'une main libre, vous pouvez transférer l'objet volé dans votre main. Autrement, votre queue le lâche subrepticement sur le sol dans votre case, où vous pouvez le ramasser après coup. Les observateurs autres que votre cible qui n'ont pas été les témoins d'un vol commis avec votre queue sont habituellement distraits, ce qui signifie que le MJ devrait normalement abaisser leur DD de Perception, comme à l'ordinaire lorsque vous tentez de Voler quelque chose.
