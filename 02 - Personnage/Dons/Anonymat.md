# Anonymat
Votre masque vous protège de tout acte de divination.


Une fois par jour, vous pouvez lancer sur vous le sort [[Voile de confidentialité]], intensifié au plus haut rang de sort que vous pouvez lancer. Le sort prend immédiatement fin si votre masque est ôté, même pour un bref instant. Le sort est de la même tradition que vos sorts focalisés.
