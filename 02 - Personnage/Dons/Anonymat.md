# Anonymat

Votre masque vous protège de tout acte de divination.

Une fois par jour, vous pouvez lancer sur vous le sort [[Antidétection]], intensifié au plus haut niveau de sort que vous pouvez lancer ; le sort prend immédiatement fin si votre masque est ôté, même pour un bref instant.
