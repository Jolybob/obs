# Spirale de vague
**Fréquence** Une fois par minute


**Conditions** Vous êtes dans la posture de l'onde réfléchissante.





Vous vous trempez et vous essorez, en relâchant un large tourbillon d'eau. Faites un test d'Athlétisme pour faire un [[Croc-en-jambe]] à chaque créature se tenant sur le sol dans une @Template[type:emanation|distance:10]{émanation de 3 mètres}.


Ces attaques sont toutes prises en compte dans le calcul de votre pénalité d'attaques multiples mais la pénalité n'augmente pas, tant que vous n'avez pas fait toutes les attaques.
