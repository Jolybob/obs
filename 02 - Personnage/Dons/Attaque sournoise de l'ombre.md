# Attaque sournoise de l'ombre
Vous obtenez la capacité de classe [[Attaque sournoise]], sauf que vous infligez 1d6 dégâts de précision quel que soit votre niveau.


L'attaque sournoise issue de plusieurs sources n'est pas cumulative. Si vous possédez une attaque sournoise de plus d'une source, utilisez seulement le plus élevé nombre de dés lorsque vous portez une attaque sournoise au lieu d'ajouter les montants les uns aux autres.
