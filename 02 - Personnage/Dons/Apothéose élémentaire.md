# Apothéose élémentaire
Vous prenez une apparence élémentaire, ressemblant à un type d'élémentaire de votre élément. Vous obtenez toutes les Vitesses figurant dans le sort [[Forme élémentaire]] pour votre élément et obtenez Vision dans le noir si vous ne la possédez pas déjà. Vous obtenez aussi le trait élémentaire et le trait de votre élément choisi.
