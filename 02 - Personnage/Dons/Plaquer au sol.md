# Plaquer au sol
Vous portez une attaque pour déséquilibrer un ennemi, puis vous enchaînez immédiatement avec un balayage pour le faire basculer.


Effectuez une Frappe au corps-à-corps. Si elle touche et inflige des dégâts, vous pouvez tenter un test d'Athlétisme pour faire trébucher la créature que vous avez touchée avec un [[/act trip]]{Croc-en-jambe}. Si vous maniez une arme de corps-à-corps à deux mains, vous pouvez ignorer la condition selon laquelle vous devez disposer d'une main libre pour faire un croc-en-jambe.


Les deux attaques comptent dans le calcul de votre pénalité d'attaques multiples mais la pénalité n'augmente qu'après avoir effectué ces deux attaques.
