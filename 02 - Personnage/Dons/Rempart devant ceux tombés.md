# Rempart devant ceux tombés
**Déclencheur** Un allié subit des dégâts qui devrait les amener à 0 Point de vie





Vous protégez vos alliés au prix de votre propre sang, mais votre divinité vous protège du pire des blessures. Marchez rapidement deux fois pour être adjacent à l'allié déclencheur. Vous pouvez Creuser, Escalader, Nager ou Voler à la place de Marcher rapidement si vous disposez du type de déplacement correspondant. Vous subissez alors les dégâts qui devraient avoir amené votre allié à 0 Point de vie, bien que vous obtenez aussi une résistance contre tous les dégâts contre les dégâts égal à votre niveau.
