# Stabilisation d'apparition
L'apparition à laquelle vous êtes harmonisée garantit que même si vous êtes distrait ou interrompu, votre magie n'est pas gaspillée. Si une réaction devrait interrompre votre action d'incantation, faites un @Check[flat|showDC:all|dc:15]. Si vous obtenez un succès, votre action n'est pas interrompue. Lorsque vous obtenez la capacité de classe troisième apparition, ce DD est de 13 et lorsque vous obtenez la capacité de classe quatrième apparition, ce DD est réduit à 10.
