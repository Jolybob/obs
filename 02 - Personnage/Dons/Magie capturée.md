# Magie capturée
**Déclencheur** Vous réussissez un jet de sauvegarde contre le sort nuisible d'un ennemi ou un ennemi obtient un échec sur un jet d'attaque de sort contre vous pour un sort nuisible.





Lorsque vous résistez à un sort, vous capturez une partie de sa magie pour votre propre usage. Vous entrez dans la posture de Cascade arcanique, en utilisant le sort déclencheur pour déterminer le type de dégâts infligés par votre Cascade arcanique.


De manière alternative, si vous êtes déjà dans la posture de Cascade arcanique, vous pouvez à la place amplifier ses effets de manière temporaire. Jusqu'à la fin de votre prochain tour, vous obtenez un bonus de statut de +2 aux dégâts supplémentaires que vous obtenez de votre cascade arcanique.
