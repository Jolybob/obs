# Purge des moments
**Fréquence** Une fois par heure





Toutes les choses ont une fin, une vérité que vous pouvez mettre en pratique en accélérant votre passage dans le temps pour vous débarrasser des effets néfastes. Cinq rounds de temps apparent se produisent pour vous. Personne, pas même vous, ne peut agir pendant cette période, mais les effets sur vous suivent leur cours, y compris les effets bénéfiques, les effets de vide, les afflictions, les états et les dégâts persistants. Effectuez les jets de sauvegarde, les tests nus, les dégâts et tout autre jet pour ces effets normalement comme si le temps était passé. Un usage excessif à cette technique est responsable de plus de quelques cheveux gris précoces parmi les mages temporels.
