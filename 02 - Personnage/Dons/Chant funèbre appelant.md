# Chant funèbre appelant
**Fréquence** Une fois par jour





Votre chant funèbre appelle, débordant dans un séide dans les 18 mètres. Ce tour, vous pouvez Lancer un sort qui est dans votre chant funèbre sans dépenser un sort ou sans même l'avoir préparé. Le rang maximum de ce sort est inférieur de 1 à votre emplacement de sort de nécromancien le plus élevé. Le séide choisit devient le point d'origine de votre sort et vous calculez la portée et les abris à partir de son espace à la place du vôtre. Le séide est alors détruit.
