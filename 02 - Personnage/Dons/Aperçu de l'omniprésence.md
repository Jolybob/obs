# Aperçu de l'omniprésence
**Fréquence** Une fois par heure





Doté d'une énergie divine, vous pouvez être aux côtés d'un allié en un clin d'œil. Vous vous téléportez dans un espace vide adjacent à un allié dans les 30 mètres. Si vous dépensez un Point mythique au cours de cette action, vous pouvez vous téléporter dans un rayon de 1,5 km et, lorsque vous arrivez, tous les ennemis qui vous sont adjacents doivent réussir un jet de @Check[will|against:class-spell] contre le plus élevé entre votre DD de classe ou votre DD de sort ou être [[Étourdis 1]].
