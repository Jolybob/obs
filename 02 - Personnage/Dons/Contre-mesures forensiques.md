# Contre-mesures forensiques
Votre maîtrise du raisonnement déductif vous permet de mettre des bâtons dans les roues de vos collègues enquêteurs. En l'espace d'une minute, vous pouvez trafiquer une seul endroit (comme une petite pièce) pour soit brouiller la scène ou ajouter des éléments trompeurs. Si vous ajoutez une preuve trompeuse, vous choisissez les détails incorrects qu'elle implique. Une créature peut perce ces contre-mesures en réussissant un test pour [[Se Souvenir]] contre votre DD de Duperie, mais uniquement si elle recherce activement cette altération.
