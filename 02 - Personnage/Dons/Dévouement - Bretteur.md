# Dévouement - Bretteur
Choisissez un style de bretteur. Vous obtenez les capacités de classe [[Panache]] et [[Combattant stylé]] et vous ajoutez le trait bravade à votre [[Déplacement acrobatique]] ainsi qu'à toutes les actions indiquées dans votre style de bretteur qui vous permettent d'obtenir du panache. Vous êtes qualifié en Acrobaties ou dans la compétence associée avec votre style. Si vous étiez déjà qualifié dans ces deux compétences, vous êtes qualifié dans une compétence de votre choix. Vous êtes aussi qualifié dans le DD de classe de bretteur. Vous n'obtenez aucun autre des effets du style de bretteur choisi.
