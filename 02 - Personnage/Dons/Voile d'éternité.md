# Voile d'éternité
Vous pouvez rester dans les interstices de la réalité plus longtemps. La durée de Lever le voile est d'une heure, bien que cela se termine toujours si vous entreprenez une action hostile. De plus, lorsque vous Échappez aux regards au cours d'une période d'exploration, vous pouvez également Lever le voile.
