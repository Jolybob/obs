# Non !!!
**Déclencheur** un allié qui n'est pas un sbire dans un rayon de 18 mètres est réduit à 0 Point de vie.





Le choc de voir votre allié proche de la mort brise toutes les limites qui existent dans votre esprit faisant jaillir votre pouvoir. Si votre psyché est actuellement libérée, vous pouvez immédiatement utiliser une action de psyché qui nécessite 1 action ou moins pour l'utiliser. Si votre psyché n'est pas encore déchaînée, vous déchaînez votre psyché, qui reste déchaînée jusqu'à la fin de votre prochain tour. Vous pouvez ignorer la condition Déchaîner la psyché en ayant [[Lancé un sort]] lors de votre tour précédent mais vous ne pouvez toujours pas [[Déchaîner votre psyché]] si vous êtes Stupéfié ou pendant 2 rounds lorsque votre psyché se calme.
