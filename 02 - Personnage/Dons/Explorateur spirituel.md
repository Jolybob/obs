# Explorateur spirituel
Vous êtes familier avec le danger que les esprits des morts peuvent représenter pour un explorateur inattentif et vous êtes particulièrement sensible à leur présence.


Même si vous n'êtes pas en train de Fouiller en phase d'exploration, vous pouvez faire un test pour repérer des hantises qui devraient normalement nécessiter que vous Fouilliez pour les trouver. Vous avez toujours besoin de remplir les autres conditions pour repérer une hantise donnée.
