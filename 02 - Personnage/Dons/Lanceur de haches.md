# Lanceur de haches
Vous avez maîtrisé le poids et l'équilibre d'une grande variété de haches et pouvez les lancer avec facilité.


Toute hache à une main que vous maniez obtient le trait jet avec une portée de 3 mètres. Pour les haches qui ont déjà ce trait, le facteur de portée augmente de 3 mètres.


Lorsque vous obtenez un succès critique sur un jet d'attaque avec une hache que vous lancez, vous appliquez l'effet critique spécialisé de l'arme.
