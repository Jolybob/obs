# Déferlement revigorant
**Conditions** Votre aura de [[Déferlement de sort]] est active.





Vous modifiez l'aura de magie qui vous entoure pour protéger un allié proche. Vous accordez à une créature au sein de votre aura de *Déferlement de sort* un nombre de Points de vie temporaires égal à votre niveau. Ces Points de vie temporaires durent aussi longtemps que la cible se trouve dans l'aura. Utiliser cette capacité à nouveau annule les Points de vie temporaires accordés précédemment. Si vous dépensez un Point mythique dans le cadre de cette action, vous pouvez accorder ces Points de vie temporaires à un nombre de créatures pouvant aller jusqu'à la moitié de votre niveau dans l'aura.
