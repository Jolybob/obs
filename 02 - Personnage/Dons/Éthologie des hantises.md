# Éthologie des hantises
Votre ingéniosité vous confère la capacité de remarquer l'écho émotionnel d'une âme trépassée en laissant une hantise dans son sillage. En mode exploration, même si vous n'êtes pas en train de Chercher, le MJ lance un test secret pour savoir si vous remarquez les hantises qui nécessiteraient normalement que vous soyez en train de Chercher pour espérer les remarquer.


Vous pouvez désactiver les hantises qui nécessitent que vous soyez maître dans une compétence tant que vous êtes au moins qualifié dans cette compétence. Si vous êtes maître dans cette compétence, vous pouvez désactiver les hantises qui nécessitent un rang légendaire.
