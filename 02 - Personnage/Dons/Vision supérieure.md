# Vision supérieure
Vos sens sont sans égal. Vous obtenez un bonus de circonstances de +2 à vos tests de Perception et vous obtenez [[Vision nocturne]]. Si vous possédiez déjà vision nocturne, vous obtenez [[Vision dans le noir]].


De plus, lorsque vous ciblez un ennemi, vous réussissez automatiquement le test nu si cet ennemi est [[Masqué]], [[Caché]] ou [[Non-détecté]].
