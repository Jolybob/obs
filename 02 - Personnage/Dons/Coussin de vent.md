# Coussin de vent
Les vents vous ont murmuré toute votre vie et l'essence même de l'air vous aide de temps à autre, vous faisant quelque peu flotter lorsque vous êtes suspendu dans l'espace. Considérez que toutes vos chutes font 3 mètres de moins que la distance réellement franchie. Vous obtenez aussi le don de compétence Bond puissant, même si vous ne remplissez pas les prérequis du don.
