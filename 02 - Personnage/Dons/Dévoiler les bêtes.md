# Dévoiler les bêtes
Vous êtes habile à révéler - ou à créer - la peur parmi ceux qui menacent la civilisation. Si vous obtenez un succès sur un test pour [[Vous souvenir]] en vue d'identifier un animal, une bête, un champignon ou une plante, il devient un succès critique à la place. De plus, chaque fois que vous réussissez un test pour Vous souvenir contre un animal, une bête, un champignon ou une plante, cette créature devient [[Effrayée 1]].
