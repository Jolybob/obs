# Vision sans lumière
Vous obtenez vision dans le noir tant que vous maniez votre arme d'éclat de guerre. Si vous aviez déjà vision dans le noir, cela devient vision dans le noir supérieure. Vous obtenez également la capacité [[Vision de l'arme]].
