# Pour l'amour, pour la foudre
**Accès** Un personnage qui accomplit une mission spécialisée pour Clarethe Iomedar a accès à cette option.





Les rumeurs suggèrent que cette technique a été mise au point par les chevaliers qui ont entrepris des missions pour Clarethe Iomedar à la demi-lune, mais de nombreux Reconquérants écarlates l'ont maîtrisée depuis. Vous apprenez le sort focalisé [[Pour l'amour, pour la foudre]]. Si vous n'en avez pas déjà une, vous obtenez une réserve de focalisation de 1 Point de focalisation, que vous pouvez regagner en utilisant l'activité Refocaliser pour réciter le Serment écarlate et médite sur ses enseignements ; si vous avez déjà une réserve de focalisation, augmentez le nombre de Points de focalisation de 1. Vos sorts focalisés de chevaliers reconquérants sont des sorts divins ; lorsque vous obtenez ce don, vous êtes qualifié en attaques de sorts et en DD de sort divins. Le charisme est l'attribut essentiel d'incantation pour les sorts focalisés de chevaliers reconquérants.
