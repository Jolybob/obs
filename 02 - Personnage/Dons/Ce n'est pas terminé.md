# Ce n'est pas terminé
**Déclencheur** Vous êtes réduit à 0 Point de vie


**Fréquence** Une fois par jour





Dans le monde du théâtre, le final d'une représentation n'est pas forcément la fin, et pour vous, cela s'étend maintenant à la vie elle-même. Lorsque les dégâts vous réduisent à 0 Point de vie, vous pouvez utiliser cette réaction pour soudainement se replonger dans l'action. Au lieu d'obtenir l'état Mourant et de tomber [[Inconscient]], vous regagnez un nombre de Points de vie égal à @Damage[(10+@actor.level+@actor.system.abilities.con.mod)[healing]]{10 + votre niveau + votre modificateur de Constitution}.
