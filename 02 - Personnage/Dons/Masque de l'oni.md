# Masque de l'oni
Vous n'êtes pas aussi malléable lorsque vos ancêtres onis mais pouvez toujours vous déguiser. Vous pouvez lancer [[Déguisement illusoire]] comme un sort inné primordial de rang 1 une fois par jour. Ce sort ne peut pas déguiser vos cornes, bien que vous pouvez toujours les cacher avec une coupe de cheveu ou une capuche.
