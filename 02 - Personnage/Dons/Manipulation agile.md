# Manipulation agile
Lorsque vous lancez [[Manipulation télékinésique]], vous pouvez modifier sa cible pour qu'il s'agisse de [[Matériel de voleur]]. Lorsque vous Lancez le sort de cette manière, les outils se déplacent de 6 mètres vers un mécanisme ou une serrure. Après avoir Maintenu le sort lors de vos prochains tours, vous pouvez utiliser les outils pour tenter des tests de Vol pour [[Désamorcer un dispositif]] ou [[Crocheter une serrure]] dans la portée du sort mais vous subissez une pénalité de -2 à votre test de Vol. En cas d'échec critique, le sort prend fin et vous ne pouvez plus utiliser cette modification pendant 24 heures.
