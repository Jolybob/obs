# Regard de discernement
Vous sentez lorsque les gens vous mentent. Vous obtenez un bonus de circonstances de +1 sur vos tests secrets de Perception pour [[Deviner les intentions]].


Si vous utilisez Deviner les intentions sur une créature qui est actuellement condamnée par votre Jugement sévère, votre MJ lance les tests de Perception deux fois et conserve le meilleur résultat (c'est un effet de fortune).
