# Tir avancé
Vous obtenez un don de franc-tireur. Pour savoir si vous remplissez les prérequis, votre niveau de franc-tireur est égal à la moitié de votre niveau.





**Spécial** Vous pouvez choisir ce don plus d'une fois. Chaque fois que vous le choisissez, vous obtenez un autre don de franc-tireur.
