# Attraction du tourbillon
Vous conjurez brièvement une liane d'eau qui vous permet d'attraper une arme improvisée, puis d'incorporer cette eau pour alimenter votre magie. Vous Interagissez pour ramasser un objet non tenu situé dans les 4,50 mètres que vous pourriez utiliser comme arme improvisée, puis Lancez un sort qui est un tour de magie ou un sort de confluence dont l'incantation nécessite 1 action.
