# Seul le valeureux
Vous pouvez décider que seules votre main pourra déplacer vos ikônes, les laissant fichée sur place aussi sûrement que si elles étaient logées dans la pierre. Lorsque vous Lâchez une ikône, vous pouvez passer une action à lui ordonner de rester immobile. Lorsqu'elle est immobile, l'ikône ne peut être déplacée que si 4 tonnes de pression lui sont appliquées ou si une créature utilise Athlétisme pour [[Ouvrir de force]] l'ikône avec un DD égal à votre DD de classe. Vous pouvez Lâcher votre ikône sur un adversaire [[À terre]] pour l'obliger à rester immobile avec l'ikône. Lorsqu'elle est Lâchée de la sorte, vous ne pouvez utiliser l'ikône, mais l'ennemi doit réussit un test d'Athlétisme pour Se relever ou pour se déplacer. L'ikône retourne automatiquement dans votre main lorsque l'effet est brisé ou si vous passez une action Interagir pour lever la main et la ramener.
