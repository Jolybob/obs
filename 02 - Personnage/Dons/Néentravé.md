# Néentravé
Votre lignée montre les signes de déformation velstrac, incluant une excentricité bizarre transmise par ces chirurgiens de la chair et de l'âme. Votre chair se soigne proprement et rapidement — les deux principales qualités pour pouvoir servir comme sujet pour leur art épouvantable. Vous obtenez le don [[Récupération rapide]], même si vous ne remplissez pas les prérequis.
