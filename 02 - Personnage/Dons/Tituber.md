# Tituber
Vous êtes peut-être plus lent que vous ne l'étiez dans la vie, mais votre rythme est constant. Marchez rapidement deux fois, ou trois fois si vous dépensez 3 actions pour tituber. Au cours de ce déplacement, vous ignorez le terrain difficile et le terrain très difficile.


Vous pouvez choisir d'ignorer toutes les pénalités de circonstances et de statut à votre Vitesse lorsque vous Titubez. Si vous le faites, vous devez obtenir un succès à un @Check[flat|dc:6] lorsque vous finissez de Tituber ou votre corps se détériore.
