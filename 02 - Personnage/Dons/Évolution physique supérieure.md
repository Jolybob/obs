# Évolution physique supérieure
Vous changez facilement de forme. Une fois par jour, vous pouvez utiliser un emplacement de sort d'ensorceleur pour lancer n'importe quel sort courant de métamorphose ayant une forme de combat du rang de l'emplacement du sort comme s'il s'agissait d'un sort emblématique de votre répertoire. Vous pouvez utiliser l'emplacement de sort supplémentaire provenant d'[[Évolution primordiale]] au lieu d'un emplacement de sort d'ensorceleur.
