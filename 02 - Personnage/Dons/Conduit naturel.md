# Conduit naturel
**Conditions** Vous disposez d'une ligne d'effet pour votre compagnon animal ou un autre animal amical dans les 18 mètres.





Vous pouvez utiliser un animal en tant que conduit pour votre magie. Si votre prochaine action que vous utilisez consiste à Lancer un sort qui possède une portée, le sort utilise l'animal comme son point d'origine.
