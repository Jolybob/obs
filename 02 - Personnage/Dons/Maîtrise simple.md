# Maîtrise simple
**Fréquence** Une fois toutes les 10 minutes





La faim jamais satisfaite des autres incantateurs pour la nouvelle magie les empêchent de pleinement comprendre à quel point la simple magie peut être poussée lorsqu'elle est réellement maîtrisée. Si votre prochaine action consiste à Lancer un sort que vous avez préparé provenant de votre fétiche, vous Lancez le sort comme si il était de 1 rang supérieur, jusqu'au plus haut rang de sort que vous pouvez lancer.
