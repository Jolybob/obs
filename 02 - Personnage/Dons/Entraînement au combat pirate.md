# Entraînement au combat pirate
Vous êtes particulièrement doué dans le maniement les armes traditionnellement utilisées par les pirates. Vous obtenez soit le don de compétence [[Combattant grimpeur]], soit [[Maraudeur aquatique]], même si vous n'en remplissez pas les prérequis. Vous avez une familiarité avec les armes suivantes : [[Hachette]], [[Rapière]], [[Cimeterre]] et [[Fouet]]. Pour les besoins de déterminer votre maîtrise, vous considérez chacune de ces armes comme des armes simples. Votre MJ pourrait ajouter d'autres armes de guerre à cette liste également appropriées à votre monde ou à votre région.


Au niveau 5, lorsque vous obtenez un coup critique avec l'une de ces armes, vous bénéficiez de son effet critique spécialisé.
