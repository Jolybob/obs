# Enjôlement intensifié
**Fréquence** Une fois par jour





Vous pouvez placer dans vos charmes et vos illusions davantage de pouvoir. Si votre prochaine action consiste à lancer un sort qui n'est pas un tour de magie accordé par les dons d'archétype d'enjôleur d'au moins 1 rang inférieur au plus haut rang de sort qui n'est pas un tour de magie d'enjôleur, ce sort est intensifié au plus haut rang de sort d'enjôleur que vous pouvez lancer.
