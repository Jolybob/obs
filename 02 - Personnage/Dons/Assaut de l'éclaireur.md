# Assaut de l'éclaireur
Vous serpentez autour de vos ennemis de manière imprévisible et les faites tomber dans une embuscade sans le moindre avertissement.


Choisissez un ennemi. Marchez rapidement, [[Feintez]] contre cet adversaire, puis faites une Frappe contre lui. Pour effectuer votre Feinte, vous pouvez faire un test de [[/act feint skill=stealth]] au lieu du test de Duperie habituellement requis, utilisant le terrain autour de vous pour surprendre votre adversaire.
