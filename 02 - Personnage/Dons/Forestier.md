# Forestier
Vous avez une familiarité innée avec les zones forestières. Lorsque vous êtes en forêt ou dans une jungle, si vous obtenez un échec critique sur un test de compétence de Survie pour Déterminer la direction, Subsister ou Effacer vos traces, il devient un échec et si vous obtenez un succès, il devient un succès critique.
