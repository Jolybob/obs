# Déjouer le mal
**Fréquence** Une fois par jour


**Déclencheur** Une créature que vous pouvez voir utilise un sort ou une capacité qui possède les traits négatif ou mal.





Vous réagissez instinctivement lorsque vous sentez le mal se former, en propulsant votre énergie spirituelle vers la source pour étouffer le mal avant qu'il ne se manifeste pleinement. Vous tentez de contrer le sort ou la capacité déclencheuse en utilisant votre modificateur de Religion comme modificateur de contre.
