# Chance incroyable (Halfelin)
Même les autres halfelins vous considèrent particulièrement chanceux. Vous pouvez utiliser Chance halfeline une fois par heure au lieu d'une fois par jour.


Si vous possédez [[Chance directrice]], vous pouvez toujours utiliser Chance halfeline lorsque vous manquez un test de Perception ou un jet d'attaque seulement une fois par jour (bien que vous puissiez l'utiliser durant la même heure au cours de laquelle vous avez utilisé Chance halfeline) et si vous possédez [[Halfelin utile]], vous pouvez toujours utiliser Chance halfeline sur un allié au lieu de vous-même une fois par jour seulement.
