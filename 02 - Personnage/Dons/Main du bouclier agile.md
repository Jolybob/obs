# Main du bouclier agile
Vous êtes tellement habitué à manier un bouclier que vous pouvez le faire lorsque vous utilisez la main qui est en train de le tenir pour d'autres taches nécessitant la dextérité d'une main.


La main que vous utilisez pour manier le bouclier compte comme une main libre pour les besoins de l'action [[Interagir]].


Vous pouvez aussi tenir un autre objet dans cette main (mais vous ne pouvez toujours pas l'utiliser pour manier une arme). Cet avantage ne s'applique pas au [[pavois]], lequel est toujours trop encombrant.
