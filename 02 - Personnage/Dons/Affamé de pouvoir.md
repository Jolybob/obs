# Affamé de pouvoir
Vous concentrez votre faim, vous permettant de consommer encore plus de pouvoir de vos séides. Lorsque vous détruisez trois séides avec [[Réclamer le pouvoir]], vous remplissez totalement votre réserve de focalisation.
