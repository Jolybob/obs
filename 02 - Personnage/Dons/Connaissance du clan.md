# Connaissance du clan
Votre identité en tant que membre de votre clan est aussi central à votre identité propre que votre ascendance naine. Vous êtes qualifié dans les deux compétences de votre clan. Si vous deviez automatiquement être qualifié dans l'une des ces compétences (du fait de votre historique ou de votre classe, par exemple), vous devenez aussi qualifié dans une compétence de votre choix. Vous êtes aussi qualifié dans la connaissance de votre clan. Si vous venez d'un clan qui n'est pas répertorié ici, vous serez qualifié dans une sélection appropriée de compétences déterminée par votre MJ. Comme il faut du temps pour apprendre le métier d'un clan, ces compétences ne changent pas automatiquement si vous quittez votre clan pour en rejoindre un autre, bien que votre MJ puisse vous permettre de changer ces compétences dans le cadre d'un réapprentissage pendant les temps d'intermède.
