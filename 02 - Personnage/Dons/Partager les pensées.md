# Partager les pensées
Vous avez une facilité déconcertante pour communiquer avec les autres elfes sans parler, bien que cette habitude mette souvent mal à l'aise les observateurs. Vous pouvez lancer [[Lien mental]] comme un sort occulte inné une fois par jour mais vous ne pouvez cibler que d'autres elfes ou aiuvarins.
