# Yeux affamés
Vos yeux peuvent percer les ténèbres avec l'acuité visuelle d'un oni. Vou obtenez vision nocturne ou vous obtenez vision dans le noir si vous aviez déjà vision nocturne.





**Spécial** Vous pouvez choisir ce don deux fois, la première pour obtenir vision nocturne et la seconde pour obtenir vision dans le noir.
