# Énergie Qi entrelacée
Vous pouvez transformer votre puissance intérieure en un type d'énergie pour renforcer vos capacités Qi. Lorsque vous obtenez ce don, vous pouvez choisir entre des dégâts d'acide, d'électricité, de feu, de froid ou de son. Lorsque vous utilisez [[Explosion Qi]], vous pouvez choisir que le sort inflige le type de dégâts que vous avez choisi au lieu de dégâts de force. Lorsque vous lancez [[Forme Qi]] ou [[Bouleversement intérieur]], ajoutez le type de dégâts que vous avez choisi à la liste des types de dégâts que vous pouvez sélectionner pour le sort.





**Spécial** À la discrétion du MJ, ce don peut modifier d'autres sorts Qi.
