# Miniaturiser
Votre eidolon peut se rétrécir encore davantage. Lorsqu'il utilise [[Rétrécir]], votre eidolon peut réduire sa taille jusqu'à être Très petit. Lorsqu'il est Très petit, son allonge est de 0 mètre.
