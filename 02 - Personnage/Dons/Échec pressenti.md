# Échec pressenti
**Fréquence** Une fois par jour


**Déclencheur** Un sort que vous lancez n'a aucun effet parce que vous avez obtenu un échec critique à tous vos jets d'attaque de sort ou parce que toutes les cibles ont obtenu un succès critique à leurs jets de sauvegarde.





Vous voyez votre sort échouer et se terminer de façon désastreuse puis revenez à la réalité - ce n'était qu'une précognition et vous savez qu'il faut essayer un autre sort. Votre sort est dépensé mais vous pouvez Lancer un sort qui nécessite le même nombre d'actions que le sort déclencheur ou moins pour être lancé. Le second sort doit être un sort différent du premier.
