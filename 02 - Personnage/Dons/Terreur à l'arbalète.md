# Terreur à l'arbalète
Votre habileté à manier l'arbalète sème la terreur chez vos adversaires lorsque vous les menacez avec le prochain carreau. Interagissez pour recharger une arbalète et tentez ensuite un test d'Intimidation pour [[Démoraliser]]. Vous obtenez un bonus de circonstances de +2 à ce test si vous avez réussi une [[Frappe]] avec une arbalète durant ce tour.
