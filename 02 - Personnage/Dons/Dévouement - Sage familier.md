# Dévouement - Sage familier
Vous avez forgé un lien mystique puissant avec votre familier. Vous obtenez le don [[Familier amélioré]], augmentant ainsi le nombre de pouvoirs de votre familier.





**Spécial** Vous pouvez prendre le Dévouement : Sage familier même si vous n'avez pas encore obtenu trois dons de l'archétype [[Maître familier]] et vous pouvez prendre le Dévouement : Maître familier même si vous n'avez pas encore obtenu trois dons de l'archétype du Sage familier. Vous ne pouvez pas choisir un autre don de dévouement tant que vous n'avez pas obtenu deux autres dons de l'archétype Maître familier ou [[Sage familier]].
