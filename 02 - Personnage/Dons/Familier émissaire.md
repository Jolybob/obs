# Familier émissaire
Vous forgez un lien mystique avec un esprit ou créez un esprit à partir d'un fragment de votre propre âme. Vous obtenez un familier. Si vous possédez déjà un familier, vous obtenez le don [[Familier amélioré]].


Votre familier obtient deux pouvoirs de familier chaque jour, dont l'un doit être  utilisé pour choisir [[Synchroniser les esprits]].
