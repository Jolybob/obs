# Enchevêtrement réactif
**Déclencheur** Une créature Moyenne ou plus petite dans votre allonge utilise une action de déplacement ou quitte une case au cours d'une action de déplacement qu'il utilise.


**Conditions** Vous tenez un filet.





Vous enroulez le filet autour du pied de la créature pour l'empêcher de s'échapper. Utilisez le filet pour [[/act grapple]]{Saisir} la créature déclencheuse. Cela présente les effets de l'utilisation d'un filet qui est attachée à une corde pour Saisir, sauf que la créature doit rester dans votre allonge au lieu de rester dans les 3 mètres pour que vous puissiez continuer à le Saisir.
