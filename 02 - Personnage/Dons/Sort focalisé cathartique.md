# Sort focalisé cathartique
Vous apprenez le sort focalisé indiqué dans l'entrée correspondant à votre émotion. Vous ne pouvez le lancer que lorsque vous êtes en état de ferveur émotionnelle. Si vous n'en avez pas déjà une, vous obtenez une réserve de focalisation de 1 point de focalisation. Vous pouvez Refocaliser lorsque vous [[Maîtrisez vos émotions]].
