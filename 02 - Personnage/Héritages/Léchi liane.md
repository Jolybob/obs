# Léchi liane
Des lianes préhensiles vous donnent une compétence inégalée pour Escalader. Vous n'avez pas besoin d'avoir une vos mains libres pour [[Escalader]]. De plus, si vous obtenez un succès à un test d'Athlétisme pour Escalader, il devient un succès critique.
