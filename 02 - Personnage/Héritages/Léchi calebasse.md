# Léchi calebasse
Vous avez une grosse calebasse à la place d'un crâne et comme vous n'avez pas de cerveau physique, vous pouvez utiliser l'espace à l'intérieur de votre tête. Vous pouvez emmagasiner une collection de petits objets dans la limite d'1 Encombrement à l'intérieur de votre tête. Le DD des tests pour [[Voler]] des objets qui s'y trouvent augmente de 4. De plus, si vous ne stockez qu'un unique objet à l'intérieur de votre tête, vous pouvez le retirer sans effort dans votre main comme partie d'une autre action pour utiliser l'objet. Dégainer l'objet donne à cette autre action le trait manipulation.
