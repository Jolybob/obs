# Hobgobelin commandant d'avortons
Vous descendez d'une longue lignée de hobgobelins qui ont dirigé des gobelins. Vous êtes plus petit que les autres hobgobelins, mais les gobelins écoutent toujours chacun des ordres que vous beuglez. Vous obtenez le don de compétence [[Contraindre un groupe]]. Si vous obtenez un succès sur un test d'Intimidation pour [[Contraindre]] un gobelin, il devient un succès critique. Si vous obtenez un échec critique, il devient un échec.
