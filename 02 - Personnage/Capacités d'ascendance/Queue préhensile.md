# Queue préhensile
Vous pouvez utiliser votre longue queue flexible pour accomplir des actions Interagir nécessitant une main libre, même si vos deux mains sont occupées par ailleurs. Votre queue ne peut pas effectuer d'actions qui nécessitent des doigts ou une dextérité manuelle importante, y compris une action qui nécessiterait un test pour être accomplie et vous ne pouvez pas l'utiliser pour tenir des objets.
