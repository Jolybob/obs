# Symbiose de l'eidolon
Le lien que vous avez noué avec votre eidolon se renforce, accordant à votre eidolon l'accès à une nouvelle capacité qui dépend de son type, comme indiqué dans les capacités de l'eidolon dans chaque description d'eidolon.
