# Voie mythique - Tragédien
Le monde entier est une scène et vous n'en êtes pas un simple acteur, mais un dramaturge dont l'histoire peut changer le cours de l'histoire. Lorsque vous utilisez Représentation pour une [[Représentation]] ou [[Gagner de l'argent]], vous pouvez dépenser un Point mythique pour tenter le test avec la maîtrise mythique. Chaque jour, la première fois que vous obtenez un succès critique sur un test pour une Représentation, vous regagnez un Point mythique.





**Édits** Maîtriser de nouvelles représentations, choisir des opportunités pour jouer devant de nouveaux publics, soutenir d'autres acteurs


**Anathèmes** Refuser une demande de rappel, refuser une demande de jouer devant un public, saboter un autre artiste
