# Corps trempé par les sorts
Les sorts qui s'écoulent à travers votre corps vous ont permis de vous renforcer. Vous devenez maître en jets de Vigueur. Lorsque vous obtenez un succès sur un jet de Vigueur, il devient un succès critique.
