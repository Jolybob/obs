# Sorts emblématiques illimités
Tous vos sorts sont des sorts de signature. Ça signifie que si vous connaissez un sort, vous pouvez l'intensifier gratuitement en le lançant à partir d'un emplacement de sort plus élevé, jusqu'au rang maximum de sort que vous pouvez lancer. Vous pouvez également lancer les versions de rang inférieur de ces sorts sans avoir à les apprendre séparément.
