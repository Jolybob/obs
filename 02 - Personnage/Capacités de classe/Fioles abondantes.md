# Fioles abondantes
Vous êtes [[Accéléré]] de manière permanente et ne pouvez utiliser l'action supplémentaire que pour utiliser [[Alchimie rapide]] pour créer une fiole rapide. Vous ne pouvez créer qu'une fiole avec cette action, même si vous avez [[Double breuvage]] ou une capacité similaire.
