# Lignage - Draconique
Le sang des dragons coule dans vos veines. Ces bêtes sont à la fois effrayantes en combat et habiles en magie.


**Tradition** variable (voir les modèles draconiques ci-dessous)


**Compétences de lignage** Intimidation et une autre compétence (voir les modèles draconiques ci-dessous)


**Legs d'ensorceleur** tour de magie [[Bouclier]] ; 1er : [[Terreur]] ; 2e : voir les modèles draconiques ci-dessous ; 3e : [[Rapidité]], 4e : [[Vol]] ; 5e : voir les modèles draconiques ci-dessous ; 6e : [[Forme de dragon]] (doit correspondre à votre modèle draconique), 7e : [[Masque terrifiant]] ; 8e : voir les modèles draconiques ci-dessous ; 9e : [[Présence écrasante]]


**Sorts de lignage***initial* [[Déluge de griffes]], avancé : [[Souffle de dragon]], supérieur : [[Ailes de dragon]]


**Magie du sang — Peau écailleuse** Des écailles de dragon apparaissent brièvement sur vous ou une cible en conférant un bonus de statut de +1 à la CA pendant 1 round.


Modèles draconiques
Au niveau 1, choisissez le type de dragon qui a influencé votre lignage. Vous ne pouvez plus changer de modèle draconique par la suite. Comme indiqué, cela affecte à la fois les traits de votre lignage et les sorts de vos Legs d'ensorceleur.




    
- **Arcanique — Tradition** arcanique ; **Compétence de lignage** Arcanes ; **Legs d'ensorceleur** 2e : [[Trait flamboyant]] ; 5e : [[Suggestion subconsciente]] ; 8e : [[Dilemme]]
    
- **Divin — Tradition** divine ; **Compétence de lignage** Religion ; **Legs d'ensorceleur** 2e : [[Augure]] ; 5e : [[Immolation divine]] ; 8e : [[Inspiration divine]]
    
- **Occulte — Tradition** occulte ; **Compétence de lignage** Occultisme ; **Legs d'ensorceleur** 2e : [[Vendetta du sang]] ; 5e : [[Nid de serpent]] ; 8e : [[Observation implacable]]
    
- **Primordial — Tradition** primordiale ; **Compétence de lignage** Nature ; **Legs d'ensorceleur** 2e : [[Fracassement]]; 5e: [[Blizzard hurlant]] ; 8e : [[Tremblement de terre]]
