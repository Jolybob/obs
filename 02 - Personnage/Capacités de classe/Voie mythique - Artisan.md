# Voie mythique - Artisan
Vous ressentez une envie de créer qui résonne dans tout votre être et vous savez qu'un jour, vous réaliserez une œuvre qui surpassera tout ce que le monde a vu jusque là. Lorsque vous [[Fabriquez]] ou [[Réparez]] un objet (y compris des véhicules et des structures), vous pouvez dépenser un Point mythique pour tenter le test avec une maîtrise mythique. Chaque jour, la première fois que vous obtenez un succès critique sur un test pour Réparer un objet, vous regagnez un Point mythique.





**Édits** Soyez le premier à tester un objet ou une arme fabriquée de vos seules mains, chercher ou inventer des formules pour des créations toujours plus complexes.


**Anathèmes** Détruire les créations d'autres artisans, refuser une sollicitation sincère de réparer quelque chose qui a été brisé, utiliser une arme ou un objet fabriqué pas quelqu'un d'autre, sauf dans le but d'apprendre son fonctionnement pour comprendre comment le créer vous-même.
