# Don d'évolution
Les dons d'évolution sont un type spécifique de don de classe du conjurateur qui vous permet de personnaliser votre eidolon à travers votre lien partagé. Vous choisissez un don d'évolution pour votre eidolon au niveau 1, représentant les différences qui le rendent unique par rapport aux autres eidolons de son type. Si vous utilisez le réapprentissage de ce don, le don par lequel vous le remplacez doit aussi être un don d'évolution.
