# Lignage - Génie
Par le biais de votre lignée, la magie ou des vœux devenus réalité, le sang d'un noble génie coule dans vos veines.


**Tradition** arcanique


**Compétences de lignage** Arcanes, Duperie


**Legs d'ensorceleur** tour de magie : [[Détection de la magie]] ; 1er : [[Déguisement illusoire]] ; 2e : variable (en fonction du type de génie, voir ci-dessous) ; 3e : [[Discours captivant]] ; 4e : [[Création]] ; 5e : variable (en fonction du type de génie, voir ci-dessous) ; 6e : [[Vision véritable]] ; 7e : [[Égide énergétique]] ; 8e : variable (en fonction du type de génie, voir ci-dessous); 9e : [[Manoir resplendissant]]


**Sorts de lignage** initial [[Voile du génie]] ; *avancé* [[désir du cœur]] ; supérieur [[Forme modifiée par un souhait]]


**Magie du sang** Votre incantation distord la réalité et distrait vos ennemis. Soit vous obtenez un bonus de statut de +1 aux tests de Duperie pendant 1 round, soit une cible subit une pénalité de statut de -1 à la Perception pendant 1 round.


[[Effet - Magie du sang génie]]


Type de génie
Au niveau 1, choisissez le type de génie qui a influencé votre lignage : faydhaan, ifrit, jaathoom, jabali ou jann. Vous ne pouvez plus changer le type de génie par la suite. Cela conditionne les sorts qui vous sont accordés aux niveaux 2, 5 et 8.




- **Faydhaan** 2e : [[Marche sur l'eau]] ; 5e : [[Contrôle de l'eau]] ; 8e : [[Dessécher]]

- **Ifrit** 2e : [[Agrandissement]] ; 5e : [[Forme élémentaire]] (feu uniquement) ; 8e : [[Dilemme]]

- **Jaathoom** 2e : [[Invisibilité]] ; 5e : [[Scène illusoire]] ; 8e : [[Vents punitifs]]

- **Jabali** 2e : [[Lumière révélatrice]]; 5e : [[Mur de pierre]]; 8e : [[Tremblement de terre]]

- **Jann** 2e : [[Création de nourriture]] ; 5e : [[Bannissement]] ; 8e : [[Couleurs déroutantes]]
