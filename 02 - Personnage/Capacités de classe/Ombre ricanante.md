# Ombre ricanante
La magie est libératrice, un moyen de parvenir à vos fins, et vous pouvez l'utiliser pour aller où vous voulez, faire ce qui vous plaît et éviter les conséquences. Vous êtes une ombre ricanante de sort et de lame, toujours un pas devant vos adversaires, toujours avec un atout dans votre manche.


Lorsque vous adoptez la posture Cascade arcanique, vous obtenez un bonus de statut de +1,50 mètre à vos Vitesses ou un bonus de +3 mètres si vous ne portez pas d'armure. Si vous Frappez une créature [[Prise au dépourvu]] alors que vous êtes dans cette posture et disposez d'une main libre, les dégâts supplémentaires de Cascade arcanique de cette Frappe passent à 3. Les dégâts supplémentaires passent à 5 si vous disposez de spécialisation martiale ou à 7 si vous disposez de la spécialisation martiale supérieure. Vous devez avoir votre autre main complètement libre. Les dégâts supplémentaires ne s'appliquent pas si vous avez une arme permettant de disposer d'une main libre ou un autre objet dans cette main, même si vous devriez normalement être capable d'utiliser la main pour faire d'autres choses.


**Sort de confluence** [[Assaut dimensionnel]]


**Sorts studieux** 7e : [[Flou]] ; 11e : [[Arme fantomatique]] ; 13e : [[Translocation]]
