# Avantage naturel
Vous trouvez toujours les points faibles dans les défenses de vos ennemis quand ils se trouvent sur un terrain défavorable. Les ennemis sont [[Pris au dépourvu]] à votre égard lorsqu'ils se trouvent sur un terrain difficile.
