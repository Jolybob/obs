# École élémentaire
Si vous choisissez une école élémentaire, vos sorts de cursus peuvent être n'importe lequel des sort auquel vous avez accès et qui possède le trait de l'élément que vous avez choisi. Vos sorts d'école sont les sorts focalisés élémentaires de l'élément que vous avez choisi, le sort de rang 1 étant votre sort d'école initial et le sort de rang 3 votre sort d'école avancé.
