# Double préparation
Vous connaissez vos formules tellement bien que vous pouvez concoctez deux objets à la fois.


Quand vous utilisez l'action [[Alchimie rapide]], vous pouvez créer deux objets. Ces objets n'ont pas besoin d'être les mêmes. Si vous créez deux consommables, vous devez dépenser une fiole polyvalente pour chacune.
