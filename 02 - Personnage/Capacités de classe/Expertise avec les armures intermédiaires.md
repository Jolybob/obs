# Expertise avec les armures intermédiaires
Vous avez appris à vous défendre mieux contre les attaques. Vous devenez expert avec les armures légères, les armures intermédiaires et en défense sans armure.


**Inventeur** Si vous possédez une innovation d'armure intermédiaire ou lourde, vous obtenez accès à l'effet de spécialisation critique avec votre innovation d'armure.
