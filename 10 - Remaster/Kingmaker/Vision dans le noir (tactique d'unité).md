# Vision dans le noir (tactique d'unité)
L'armée inclut plusieurs guetteurs et éclaireurs ayant Vision dans le noir et les autres soldats ont été formés pour les suivre, ce qui fait que l'armée entière fonctionne comme si elle avait Vision dans le noir.
