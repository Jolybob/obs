# PF2e FR — Obsidian Vault (v1)

A starter Obsidian vault structure for the French Pathfinder 2e reference.

## Contents

- `00 - Index/` — navigation and Dataview dashboards
- `01 - Règles/` — rules, actions, conditions
- `02 - Personnage/` — character options
- `03 - Magie/` — spells and magic
- `04 - Équipement/` — gear
- `05 - Créatures/` — creatures
- `06 - Dangers/` — hazards
- `07 - Divinités/` — deities
- `08 - Véhicules/` — vehicles
- `09 - Traits/` — traits
- `10 - Remaster/` — Remaster material
- `_Templates/` — reusable note templates

This is **v1: structure and templates only**. Source content is not included yet.
