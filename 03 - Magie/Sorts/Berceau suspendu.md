# Berceau suspendu
Vous libérez temporairement un objet de l'emprise de la gravité, ce qui vous permet de le lâcher sans qu'il ne tombe au sol. L'objet flotte à côté de vous dans votre espace, en vous suivant si vous vous déplacez. Pendant votre tour, vous pouvez Interagir pour récupérer l'objet par une action gratuite. Si vous êtes dans l'allonge d'une autre créature, celle-ci peut utiliser une action unique possédant le trait attaque pour tenter un test d'Athlétisme contre votre DD de sort afin de récupérer l'objet dans les airs en cas de succès. La créature doit disposer d'une main libre pour tenter ce test. Le sort prend fin si une créature réussit à récupérer l'objet. Si l'objet flotte encore lorsque le sort prend fin, il tombe.
