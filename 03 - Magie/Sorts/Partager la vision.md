# Partager la vision
Votre patron lie temporairement votre vision à celle d'une autre personne, vous permettant à tous les deux de voir à travers les yeux de l'autre. Pendant la durée du maléfice, vous partagez tous les sens basés sur la vision (comme la Vision dans le noir ou la Vision nocturne) et obtenez un bonus de statut de +2 aux tests de Perception, mais si l'un de vous est [[Aveuglé]] ou [[Ébloui]], vous l'êtes tous les deux.


Si vous lancez *Partager la vision* alors qu'une précédente incantation de ce maléfice est encore active, l'effet précédent prend fin.
