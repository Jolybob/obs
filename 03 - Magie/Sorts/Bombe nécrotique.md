# Bombe nécrotique
Vous surchargez l'un de vos séides d'énergie du vide, ce qui le fait exploser. Chaque créature située dans une émanation de 3 mètres autour du séide subit 1d12 dégâts de vide avec un jet de Vigueur basique. Cela détruit le séide.





**Intensifié (+1)** Les dégâts augmentent de 1d12.
