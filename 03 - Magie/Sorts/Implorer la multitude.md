# Implorer la multitude
Vous manifestez les échos de tous les esprits avec lesquels vous vous êtes lié un jour en même temps, dans une trombe cyclonique de formes colorées. Ils infligent 8d8 dégâts de force à chaque ennemi dans la zone, avec un jet de Vigueur basique. De plus, les créatures qui obtiennent un échec critique sur leur jet de sauvegarde sont mises [[À terre]].





**Intensifié (+1)** Les dégâts augmentent de 1d8.
