# Saut temporel
Vous faites un bond dans le temps, apparaissant sur le champ de bataille en un clin d'œil. Vous gagnez 2 actions, chacune d'entre elles devant être utilisée pour Bondir, Se relever, Faire un pas ou Marcher rapidement. Si vous avez une Vitesse appropriée, vous pouvez ajouter [[Creuser]], [[Escalader]], [[Nager]] ou [[Voler]] à cette liste.


Pendant que vous effectuez ces actions, le temps s'arrête. Toutes les autres créatures sont complètement inconscientes de vos actions, ne peuvent pas parler et ne peuvent pas utiliser d'actions qui seraient déclenchées par votre déplacement. En effectuant ces actions, vous ne pouvez effectuer aucune autre action, y compris celles qui seraient déclenchées par les actions de mouvement. Une fois les actions terminées, le temps recommence et, pour les spectateurs, il semble que vous vous soyez soudainement téléporté sur la distance que vous avez parcourue. Bondir dans le temps est désorientant, donc si vous utilisez *Saut temporel* à nouveau dans la minute qui suit l'utilisation du sort, vous devenez [[Stupéfié 4]] pendant 1 minute.
