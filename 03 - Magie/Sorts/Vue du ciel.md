# Vue du ciel
Vous levez les yeux et voyez clairement le ciel malgré les conditions environnementales. Vous pouvez voir à travers les phénomènes météorologiques et les obstacles physiques tels que la canopée d'une forêt, les matériaux d'un bâtiment ou les parois d'une grotte. Cela peut être utilisé pour voir des créatures en vol ou pour vous orienter grâce aux étoiles même lorsque vous ne pourriez normalement pas les voir.
