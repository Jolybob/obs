# Précaution du conjurateur
En invoquant une magie protectrice complexe, vous créez une sorte de tampon dans le lien qui vous relie à votre eidolon., permettant à votre allié lié de sacrifier son existence pour vous sauver en cas de besoin. Vous obtenez la réaction [[Couper le conduit]]. Après l'avoir utilisée, le sort s'achève.
