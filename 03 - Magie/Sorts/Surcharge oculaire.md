# Surcharge oculaire
Lorsqu'une créature est sur le point de vous attaquer, vous l'assaillez avec des illusions secouantes, entourant complètement leurs yeux avec des flashs aveuglants colorées et de déplacement. Lorsque le sort est terminé, vous obtenez la réaction [[Vision surchargée]] ; une fois que vous utilisez la réaction, le sort se termine.


@Check[fortitude|name:Overload Vision|traits:illusion]
