# C'est écrit
Vous entrevoyez un avenir pour vous-même, confiant dans la certitude que cette vision est votre destinée. Avant la fin de la durée du sort, si vous devez tenter un jet d'attaque, un test de Perception, un jet de sauvegarde ou un test de compétence qui vous aiderait à accomplir cette destinée, vous pouvez tenter ce jet avec une maîtrise mythique. Vous choisissez sur quel jet utiliser cet effet avant de lancer le jet. Si vous utilisez cet effet, le sort prend fin. Dans tous les cas, vous êtes alors temporairement immunisé contre *C'est écrit* pendant 1 heure.
