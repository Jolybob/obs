# Convocation d'instrument
Vous matérialisez un [[Instrument de musique portatif]] dans votre main. L'instrument est banal pour son type, mais vous seul pouvez en jouer. L'instrument s'évanouit lorsque le sort se termine. Si vous lancez encore *Convocation d'instrument*, tout instrument que vous avez auparavant convoqué disparaît.





**Intensifié (5e)** L'instrument est un [[Instrument de musique portatif virtuose]]
