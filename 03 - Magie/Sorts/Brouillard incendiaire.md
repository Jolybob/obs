# Brouillard incendiaire
Vous invoquez un nuage de poudre noire inflammable. Le nuage fonctionne comme [[Brume]]. Si une flamme nue ou un effet de feu se trouve dans la zone du sort au moment où il est lancé, si elle entre par la suite ou si il se produit dans la zone, le nuage s'embrase. Les créatures dans le nuage subissent @Damage[10d6[fire]]{10d6 dégâts de feu} (Réflexes basique) et le sort se termine.
