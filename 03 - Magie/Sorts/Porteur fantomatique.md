# Porteur fantomatique
Vous créez une personnage Très petit semi tangible d'une forme de votre choix. Il plane à vos côtés pendant la durée du sort. Lorsque vous Lancez un sort dont le portée est contact, vous pouvez faire en sorte que le porteur se déplace dans la portée, délivre le sort à une créature qui s'y trouve, puis vous revienne. Si le porteur doit tenter un jet d'attaque de sorts, il utilise vos bonus normaux. Le porteur possède votre CA et vos jets de sauvegardes, mais il est détruit s'il subit le moindre dégât.
