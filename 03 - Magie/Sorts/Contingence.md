# Contingence
Vous préparez un sort qui se déclenchera plus tard. Lorsque vous lancez *Contingence*, vous lancez aussi un autre sort de rang inférieur ou égal à 4, avec une durée d'incantation qui ne dépasse pas 3 actions. Ce sort accompagnateur doit en être un qui puisse vous affecter. Vous devez prendre toutes les décisions concerne le sort accompagnateur lorsque vous lancez *Contingence*, tel que choisir un type de dégâts pour [[Résistance à l'énergie]]. Lors de l'incantation, choisissez un déclencheur qui déclenchera le sort accompagnateur sera lancé, en utilisant les mêmes restrictions que pour le déclencheur de l'action Préparer. Une fois *Contingence* lancé, vous pouvez déclencher le sort accompagnateur en réaction au déclencheur choisi. Il n'affecte que vous, même s'il devrait affecter plus de créatures. Si vous définissez des conditions compliquées, selon l'avis du MJ, le déclencheur pourrait ne pas fonctionner. Si vous lancez de nouveau *Contingence*, la nouvelle incantation supplante la précédente.





**Intensifié (8e)** Vous pouvez choisir un sort de rang inférieur ou égal à 5.


**Intensifié (9e)** Vous pouvez choisir un sort de rang inférieur ou égal à 6.


**Intensifié (10e)** Vous pouvez choisir un sort de rang inférieur ou égal à 7.
