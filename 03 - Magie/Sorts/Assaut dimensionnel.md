# Assaut dimensionnel
Vous vous déplacez dans l'espace, faisant un court saut dimensionnel pour mieux vous positionner pour une attaque. Vous vous téléportez vers toute case à portée qui est dans l'allonge d'une créature puis faites une Frappe au corps-à-corps contre une créature dans votre allonge.
