# Bénédiction de l'arme de siège
Vous tracez une rune magique sur le corps d'une arme de siège, en invoquant le destin ou votre dieu pour guider les attaques que font vos alliés avec cette machine. Pendant la durée du sort, tous les tests de compétence tentés pour Charger l'arme de siège peuvent être lancés deux fois, en conservant le meilleur résultat. Ces tests de compétence obtiennent le trait fortune. De plus, tous les jets de sauvegarde tentés par des créatures pris dans la zone de Tir de l'arme de siège doivent être lancés deux fois, en conservant le pire résultat. Ces jets de sauvegarde obtiennent le trait infortune.





**Intensifié (9e)** La durée est de 8 heures.
