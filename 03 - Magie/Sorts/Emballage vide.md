# Emballage vide
Vous rendez [[Invisible]] chaque objet à l'intérieur du contenant que vous touchez , bien que le récipient lui-même reste visible. Les objets qu'il contient sont [[Non détectés]] pour toutes les créatures. Une créature peut cependant tenter de trouver un objet en mettant la main dans le contenant : si elle réussit, l'objet devient simplement Caché pour elle. De plus, le sort n'empêche pas les objets de faire des protubérances dans le sac, d'ajouter du poids, de faire du bruit lorsqu'il est secoué et ainsi de suite. Cependant, le sort empêche tout ce qui se trouve dans le contenant de tomber s'il est renversé. Tout objet retiré du contenant devient visible et le reste même s'il est remis dans le contenant.





**Intensifié (4e)** La durée devient jusqu'à vos prochains préparatifs quotidiens.
