# Oeil aveugle
Vous enchantez un seul objet, l'empêchant d'être utilisé pour l'observation magique. Si vous lancez ce sort sur un objet non magique utilisé pour lancer des sorts de scrutation, comme une sacoche de composants de sorts ou un focalisateur de sorts, l'objet ne peut pas être utilisé pour lancer le sort. Si vous lancez *Oeil aveugle* sur un objet magique qui peut être activé pour la scrutation (comme une [[Boule de cristal]] ou un [[Oeil de guenaude]]), l'objet ne peut pas être activé pour obtenir des effets de scrutation. Les objets magiques dont le rang du sort est supérieur ou égal à deux fois celui d'*Oeil aveugle* ne sont pas bloqués de cette manière.
