# Lueurs féeriques
Toutes les créatures dans la zone lorsque vous lancez le sort sont délimitées par un feu sans chaleur coloré (de la couleur de votre choix). Les créatures visibles ne peuvent pas être [[Masquées]] tant qu'elles sont affectées par *Lueurs féeriques*. Si les créatures sont [[Invisibles]], elles sont Masquées tant qu'elles sont affectées par le sort *Lueurs féeriques* plutôt que d'être [[Non détectées]].
