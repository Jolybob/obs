# Arme disparue
**Déclencheur** Une créature obtient un succès, mais pas un succès critique, ou un échec sur une Frappe au corps-à-corps effectuée avec une arme vous prenant pour cible.





Vous créez un petit espace extradimensionnel que vous pouvez utiliser pour happer des armes. Vous tentez de [[/act disarm]]{Désarmer} la créature déclencheuse en effectuant un jet d'attaque de sort au corps-à-corps à la place d'un test d'Athlétisme. Vous n'avez pas besoin d'avoir une main libre pour effectuer cette tentative. Si vous réussissez à faire tomber l'arme des mains de la créature déclencheuse, celle-ci disparaît dans votre espace extradimensionnel. Vous pouvez Interagir pour dégainer l'arme comme si vous la portiez. Si vous le faites, le sort prend fin. Si l'arme se trouve encore dans l'espace extradimensionnel lorsque le sort prend fin, elle tombe au sol à vos pieds. Vous pouvez Révoquer ce sort.


Cette réaction n'empêche pas les dégâts infligés par une Frappe réussie.
