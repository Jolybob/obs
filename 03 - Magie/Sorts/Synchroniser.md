# Synchroniser
Vous placez de manière inoffensive votre symbole magique unique dans la forme de votre choix, d'une taille d'environ 2,5 cm carré, sur vos cibles. Lorsque vous lancez le sort, vous définissez la durée en choisissant un moment auquel le symbole clignote faiblement trois fois. À cet instant, le sort prend fin. Même si les durées des sorts ne sont normalement pas exactes, les effets de *synchroniser* sont précis à la seconde près. Le chronomètre est basé sur l'endroit où le sort a été lancé, de sorte que pénétrer sur un Plan ou dans une zone où le temps s'écoule différemment change la façon dont le temps s'écoule de manière parfois imprévisible.





**Intensifié (2e)** Le sort peut cibler jusqu'à 20 créatures consentantes.
