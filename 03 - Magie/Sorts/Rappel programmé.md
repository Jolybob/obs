# Rappel programmé
Vous vous envoyez un message qui vous sera remis ultérieurement, à un moment de votre choix. Murmurez un message de 8 mots maximum et concentrez-vous sur une date et une heure situées au cours de l'année suivante. Au moment choisi, un léger carillon résonne dans votre esprit, suivi du message répété deux fois d'un ton neutre et régulier. Vous pouvez Révoquer ce sort à tout moment. Si vous lancez de nouveau *Rappel programmé*, le premier message est effacé dès que le nouveau message est créé.





**Intensifié (5e)** Vous envoyez le message de rappel à une autre créature consentante que vous connaissez. Si cette créature ne se trouve pas sur le même plan d'existence que vous lorsque vous Lancez ce sort, le sort échoue.
