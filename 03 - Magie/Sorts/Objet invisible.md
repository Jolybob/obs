# Objet invisible
Vous rendez l'objet [[Invisible]]. Cela le rend [[Non détecté]] pour toutes les créatures, bien que les créatures puissent essayer de trouver la cible, la rendant [[Cachée]] à leurs yeux à la place s'ils obtiennent un succès. Si l'objet est utilisé comme élément d'une action hostile, le sort s'achève après que cette action hostile soit terminée. Rendre une arme invisible ne permet pas d'obtenir un avantage lors de l'attaque, sauf qu'une arme de jet ou une munition invisible peut être utilisée pour une attaque sans nécessairement donner d'information sur le lieu où se cache l'attaquant à moins que l'arme ne revienne à l'attaquant.





**Intensifié (3e)** La durée passe à jusqu'à vos prochains préparatifs quotidiens.


**Intensifié (7e)** La durée est illimitée.
