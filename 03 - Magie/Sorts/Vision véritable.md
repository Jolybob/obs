# Vision véritable
Vous voyez les choses dans un rayon de 18 mètres telles qu'elles sont réellement. Le MJ effectue secrètement un test de contre contre toute illusion ou effet de transformation ou de métamorphose, mais seulement dans le but de déterminer si vous les percez (par exemple, si le test réussit contre un sort de métamorphose, vous pouvez voir la véritable forme de la créature, mais vous ne mettez pas fin au sort de métamorphose).
