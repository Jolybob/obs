# Forme éthérée
Vous vous rendez sur le Plan éthéré, qui chevauche l'Univers. Les créatures de l'Univers ne vous voient pas et vous pouvez traverser des choses se trouvant dans l'Univers. Vous vous déplacez à la moitié de votre Vitesse normale, mais vous pouvez aller dans n'importe quelle direction (y compris vers le haut ou le bas). Vous voyez ce qui se trouve dans l'Univers dans un rayon de 18 mètres, mais tout est gris, brumeux et [[Masqué]]. Vous ne pouvez pas affecter l'Univers ni être affecté par ce qui s'y trouve, sauf les effets de force et d'abjuration qui en émanent. Vous retournez dans l'Univers quand le sort se termine. Si vous êtes dans les airs, vous tombez (sauf si vous pouvez Voler) et si vous êtes dans un objet, vous êtes repoussé dans l'espace dégagé le plus proche et subissez 1d6 dégâts par tranche de 1,50 mètre sur lesquels vous avez été poussé. Si vous n'êtes pas dans l'Univers quand vous lancez ce sort, il est perdu.





**Intensifié (9e)** Vous pouvez viser jusqu'à cinq créatures consentantes de plus pour une portée de 9 mètres. La durée passe à 10 minutes.
