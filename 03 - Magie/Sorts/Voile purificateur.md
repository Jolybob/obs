# Voile purificateur
En puisant dans les pouvoirs purificateurs de l'eau, vous faites apparaître un voile de fines gouttelettes d'eau imprégnées d'énergie sainte. Le voile entoure la cible. Tout ce qui se trouve de chaque côté du voile est [[Masqué]] des créatures du côté opposé, mais l'eau n'empêche pas les attaques ou les mouvements de passer à travers le voile. Si la cible se déplace à travers le voile, elle subit 4d6 dégâts spirituels avec un jet de Volonté basique. Si la cible quitte le voile, le sort prend fin.





**Intensifié (+1)** les dégâts augmentent de 1d6.
