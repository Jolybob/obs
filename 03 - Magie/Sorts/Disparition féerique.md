# Disparition féerique
Vous devenez [[Invisible]] et ignorez les terrains difficiles naturels (tels que les taillis). Toute action hostile que vous effectuez met fin à cette invisibilité mais vous continuez d'ignorer les terrains difficiles naturels.





**Intensifié (5e)** L'invisibilité n'est pas rompue si vous faites une action hostile.
