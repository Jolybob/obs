# Voile spirituel
Vous attirez un voile d'esprits occultant autour de vous-même, vous cachant particulièrement bien aux yeux des morts-vivants. Vous êtes [[Masqué]] à l'égard de toutes les créatures et vous êtes [[Caché]] aux yeux des créatures mortes-vivantes quels que soient les sens précis qu'elles possèdent. Cela vous accorde les effets d'[[Invisibilité]] mais contre tous les sens précis des créatures mortes-vivantes. Si vous interagissez physiquement avec une créature morte-vivante ou utilisez une action hostile, le sort se termine.





**Intensifié (+1)** Vous pouvez cibler une créature supplémentaire consentante dans les 9 mètres. Le sort se termine si une cible quelconque interagit physiquement avec une créature morte-vivante ou utilise une action hostile.
