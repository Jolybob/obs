# Implanter un message
Vous projetez des vibrations psychiques dans l'objet ciblé, lui implantant un court message ou un thème émotionnel de votre choix. Cette sensation implantée est révélée à une créature qui lance [[Lecture d'objet]] sur l'objet cible, remplaçant tout évènement émotionnel qui était présent sur l'objet. Si l'objet est dans une zone d'un sort de [[Rétrocognition]], le message qui a été placé apparaît comme un évènement majeur durant le cours du temps mais il n'interfère pas avec toute autre vision.


Si l'objet est ciblé avec un sort [[Lecture d'Aura]] d'un rang de sort supérieur au sort Implanter un message, l'incantateur apprend que l'objet a été magiquement modifié. Lorsque vous [[Lancez ce sort]], n'importe quelle vibration précédente placée sur l'objet par de précédentes incantations de *Implanter un message* disparaît.
