# Retour en arrière
Vous ancrez votre position dans le temps de manière à pouvoir rapidement revenir sur vos pas plus tard à l'aide de chronomancie complexe. L'espace dans lequel vous vous trouvez lorsque vous Lancez le sort devient votre espace ancre temporelle. Tant que vous vous trouvez dans les 150 mètres de votre espace ancre temporelle, vous pouvez Maintenir ce sort pour revenir dans cet espace instantanément (Vous n'avez pas besoin d'avoir cette case dans votre ligne de vue). Le sort s'achève alors. Vous ramenez n'importe quel objet en votre possession lorsque vous entreprenez le retour.


Si l'espace ancre est occupé lorsque vous tentez d'y revenir ou si ce sort devrait emporter une autre créature avec vous, le sort échoue à vous transporter, puis se termine.





**Intensifié (7e)** Vous pouvez revenir si vous vous trouvez dans les 300 mètres de l'espace ancre.


**Intensifié (9e)** Vous pouvez revenir si vous vous trouvez dans les 1,5 km de l' espace ancre.
