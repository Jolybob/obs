# Terrain déformé
Vous créez des dangers illusoires qui recouvrent toutes les surfaces dans la zone (typiquement au sol). Toute créature qui traverse l'illusion considère que les cases sont un terrain difficile. Une créature peut tenter de percer l'effet comme à l'accoutumée après avoir effectué une action [[Chercher]] ou si elle effectue des actions pour interagir avec l'illusion. Si elle réussit à percer l'illusion, elle ignore l'effet pendant la durée restante. Pour chaque action supplémentaire utilisée pour lancer le sort, le rayon de l'explosion augmente de 1,50 mètre, jusqu'à un maximum de 3 mètres supplémentaires pour 3 actions.





**Intensifié (4e)** Vous pouvez faire apparaître l'illusion dans les airs et plutôt que sur une surface pour qu'elle fonctionne comme un terrain difficile pour les créatures volantes.
