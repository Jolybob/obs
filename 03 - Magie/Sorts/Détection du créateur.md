# Détection du créateur
Vous examinez les restes ou les résidus spirituels d'une créature morte-vivante détruite pour localiser le créateur de ce mort-vivant, peut-être un nécromancien ou un vampire. Si le créateur est à portée, vous connaissez la direction qui vous mène à lui. Si le créateur est dans les 30 mètres, vous sentez sa présence dans les 30 mètres et votre sort se termine ; vous ne pouvez pas mieux le localiser. S'il y a du plomb ou de l'eau courante entre vous et le créateur du mort-vivant, ce sort ne peut le localiser. Ce sort échoue automatiquement si le mort-vivant n'a pas de créateur spécifique ou si le créateur spécifique n'est pas sur le même plan.
