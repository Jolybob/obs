# Sivanah - Grâce majeure
Vous répandez vos illusions sur une zone plus étendue.


Vous pouvez désigner une zone pour qu'elle obtienne en permanence les effets de [[Mirage]]. Toutes les créatures se trouvant dans cette zone obtiennent les effets de Déguisement illusoire, en modifiant leurs formes comme vous le souhaitez. Vous pouvez désigner une nouvelle zone en y consacrant une activité d'une minute, mais le faire annule toute zone que vous avez précédemment désignée.
