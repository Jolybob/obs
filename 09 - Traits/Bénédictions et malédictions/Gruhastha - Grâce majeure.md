# Gruhastha - Grâce majeure
Vous êtes une source d'inspiration divine pour ceux qui vous entourent.


Lorsque vous tentez n'importe quel test de compétence pour [[Vous souvenir]], vous pouvez lancer deux fois le dé et conserver le meilleur résultat. Ceci est un effet de fortune. De plus, les alliés dans un rayon de 18 mètres obtiennent un bonus de statut de +2 à leurs jets de Volonté.
