# Nocticula - Grâce modérée
Vous puisez dans le pouvoir de minuit pour vous guider dans vos voyages.Vous obtenez Vision dans le noir. Si vous aviez déjà Vision dans le noir, vous pouvez lancer [[Ténèbres]] une fois par jour comme un sort divin inné.
