# Irori - Malédiction majeure
Irori fait oublier votre existence de toutes les créatures vivantes.Cela peut se produire en provoquant l'ire d'Irori, de sorte que votre nom est oblitéré de tous les registres écrits. Dans les deux cas, les mémoires et les écrits se réarrangent eux-mêmes pour vous omettre doucement, plutôt que de laisser des trous évidents.
