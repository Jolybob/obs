# Gruhastha - Malédiction majeure
Les mots écrits se rebelle, se brouillant pour être inintelligibles.Vous êtes incapable de lire quoique ce soit ou de déchiffrer n'importe quel symbole, ce qui inclut les mots sur les parchemins, les livres de sorts ou les objets magiques.
