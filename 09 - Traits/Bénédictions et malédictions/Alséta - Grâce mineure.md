# Alséta - Grâce mineure
La main directrice d'Alséta vous aide dans votre voyage.


Une seule fois, lorsque vous utiliser la magie de la téléportation, vous vous retrouvez exactement sur la localisation ciblée, même si vous avez utilisé un sort notoirement imprécis comme [[Téléportation interplanaire]].


Alséta accorde généralement cette grâce pour des voyages magiques extrêmement importants, surtout lorsque le temps est compté.
