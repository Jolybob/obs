# Abadar - Grâce modérée
Abadar bénit toutes vos entreprises, menant au succès financier car toutes vos affaires semblent toujours aboutir.


Si vous faites un échec critique lors d'un test pour [[Gagner de l'argent]], il devient un échec.


Si vous obtenez un succès lors d'un test pour [[Gagner de l'argent]], alors vous gagnez le double du revenu habituel.
