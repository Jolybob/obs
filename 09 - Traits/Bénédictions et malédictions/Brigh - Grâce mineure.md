# Brigh - Grâce mineure
La connaissance emplit vos pensées.


Une seule fois, vous pouvez relancer un test de compétence raté lorsque vous tentez de [[Vous souvenir]]. Vous devez utiliser le second résultat même s'il est pire que le précédent.
