# Irori - Grâce mineure
Irori vous accorde une grande connaissance et la sagesse.


Utilisé qu'une seule fois : lorsque vous obtenez un échec lors d'un test pour [[Vous souvenir]], il devient un succès critique. De plus, le test perd le trait secret, de manière à ce que vous sachiez avec certitude que le résultat était un succès critique.


Irori accorde typiquement cette bénédiction pour un test de Se souvenir ayant d'importantes conséquences.
