# Effet - Stimulateur électromusculaire (Échec)
Accordé par [[Stimulateur électromusculaire]]


Vous obtenez l'état Accéléré et vous pouvez utiliser l'action supplémentaire soit pour Marcher rapidement soit pour Frapper. Vous subissez également 3 dégâts d'électricité persistants.
