# Effet - Masque branchies de côte rouge inférieur
Accordé par [[Masque branchies de côte rouge inférieur]]


Vous obtenez un bonus d'objet de +1 aux jets de Vigueur contre les effets inhalés. Ce bonus est de +2 contre le gaz volcanique mortel connu autour du lac Terwa sous le nom d'Haleine du mort.
