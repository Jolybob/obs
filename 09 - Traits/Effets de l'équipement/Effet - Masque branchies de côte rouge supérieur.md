# Effet - Masque branchies de côte rouge supérieur
Accordé par [[Masque branchies de côte rouge supérieur]]


Vous obtenez un bonus d'objet de +3 aux jets de Vigueur contre les effets inhalés. Ce bonus est de +4 contre le gaz volcanique mortel connu autour du lac Terwa sous le nom d'Haleine du mort.
