# Effet - Cape mécanique
Accordé par [[Cape mécanique]]


Vous subissez une pénalité de -4 aux tests de Perception lorsque vous êtes en mode veille. Si vous quittez le mode veille pour une initiate au combat, vous obtenez un bonus d'objet de +2 à votre jet d'initiative.
