# Effet - Menottes
Accordé par [[Menottes médiocres]], [[Menottes simples]], [[Menottes intermédiaires]], [[Menottes bonnes]], [[Menottes supérieures]]


**Jambes** Vous subissez une pénalité de circonstances de -4,50 mètres à votre Vitesse


**Poignets** Vous devez réussir un test nu 5 chaque fois que vous utilisez une action de manipulation ou que cette action échoue.
