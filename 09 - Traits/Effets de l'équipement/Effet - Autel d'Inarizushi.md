# Effet - Autel d'Inarizushi
Lorsque vous êtes en mode exploration, faites un test pour [[Fouiller]] séparément avec un bonus de statut de +1. Cela n'affecte pas votre Vitesse. Si le test est un succès, un renard apparaît pour vous informer de sa découverte du mieux qu'il peut, bien qu'il ne puisse parler.
