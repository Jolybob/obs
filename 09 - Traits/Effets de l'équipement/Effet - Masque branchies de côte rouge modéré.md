# Effet - Masque branchies de côte rouge modéré
Accordé par [[Masque branchies de côte rouge modéré]]


Vous obtenez un bonus d'objet de +2 aux jets de Vigueur contre les effets inhalés. Ce bonus est de +3 contre le gaz volcanique mortel connu autour du lac Terwa sous le nom d'Haleine du mort.
