# Effet - Rune énergisante
Accordé par [[Énergisante]]


L'arme est imprégnée avec le type d'énergie déclencheur. Elle inflige 1d8 dégâts supplémentaires du type déclencheur jusqu'à la fin de votre prochain tour.
