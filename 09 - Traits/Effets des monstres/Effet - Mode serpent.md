# Effet - Mode serpent
Le serpent mécanique se transforme en un mode différent. Lancez 1d3 et consultez les options ci-dessous.




- **Mode cobra** Le serpent mécanique peut utiliser Capuche intimidante.

- **Mode constricteur** Le serpent mécanique peut utiliser sa Frappe d'anneaux et peut utiliser Constriction.

- **Mode serpent à sonnette** Le serpent mécanique peut utiliser Sonnette brisante.
