# Effet - Charge profonde
Vous subissez une pénalité de circonstances de -2 aux tests d'Acrobaties aux tests pour Garder l'équilibre et aux tests d'Athlétisme pour Nager. Si vous obtenez un échec critique sur le jet de sauvegarde, vous êtes également sourd.
