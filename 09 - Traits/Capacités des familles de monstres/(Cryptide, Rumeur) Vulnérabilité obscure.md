# (Cryptide, Rumeur) Vulnérabilité obscure
Le cryptide est affaibli par ceux qui cherche la vérité. Lorsqu'une créature obtient un succès à un test pour Se souvenir pour identifier le cryptide rumeur, le cryptide rumeur est [[Drainé 1]] (ou [[Drainé 2]] si le test pour Se souvenir était un succès critique).
