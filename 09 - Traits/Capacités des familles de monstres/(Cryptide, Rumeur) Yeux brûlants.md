# (Cryptide, Rumeur) Yeux brûlants
Les yeux du cryptide sont distinctifs. Peut-être qu'ils brûlent d'un rouge vif dans la nuit noire. Le cryptide rumeur obtient Vision dans le noir. Si la créature de base possède déjà la Vision dans le noir, il obtient la Vision dans le noir supérieur.
