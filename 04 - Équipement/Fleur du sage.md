# Fleur du sage
**Activation** F (concentration)


**Déclencheur** Vous tentez un test de Nature pour [[Vous souvenir]] mais n'avez pas encore lancé les dés


**Conditions** Vous êtes qualifié en Nature.





Cette simple fleur blanche est placée sur un chapeau ou tressée dans vos cheveux. Quand elle est activée, elle diffuse un parfum apaisant, qui favorise la concentration. Quand vous Activez ce talisman, vous Vous souvenez 3 fois au lieu d'une. Si vous utilisez Nature pour n'importe lequel de ces tests et que vous obtenez un échec critique, ce test devient un échec.
