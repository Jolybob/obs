# Traceur ectoplasmique
Cette substance collante et fluorescente, stockée dans une buse d'aérosol, se pulvérise sur toutes les créatures situées dans un @Template[cone|distance:15]{cône de 4,50 mètres} lorsqu'elle est libérée. Cela marque toute créature intangible se trouvant dans le cône pour [[/r {1d4}]]{1d4 jours}. Quiconque tente de pister une créature ainsi marquée obtient un bonus d'objet de +2 au test. Le traceur n'a aucun effet sur les créatures corporelles, ni sur les créatures intangibles qui ne sont pas formées d'essence spirituelle, tels que les rêves animés qui sont purement mentaux par nature.


Une créature marquée qui est consciente du traceur peut essayer de le retirer, mais le processus est déplaisant et long. Il faut passer 10 minutes à gratter sa forme intangible pour retirer les effets du traceur.
