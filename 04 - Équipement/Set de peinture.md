# Set de peinture
Cet ensemble de fournitures de peinture comprend des peintures, des pinceaux, des pots, une palette, un ensemble de petites toiles et un chevalet miniature. Vous pouvez remplir votre set de peinture avec des peintures et des toiles supplémentaires pour 1 pièce d'argent.
