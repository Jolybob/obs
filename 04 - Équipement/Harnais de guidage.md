# Harnais de guidage
La poignée de ce *harnais de guidage* vient se placer confortablement dans votre main. Les *harnais de guidage* sont spécialement conçus pour les aventuriers malvoyants ou aveugles qui ont des animaux guides. Généralement attachés par des sangles latérales placées à travers une martingale, de tels *harnais de guidage* peuvent être facilement reconfigurés pour permettre d'être portés par n'importe quel compagnon animal.
