# Traction (rune)
Les armes *de traction* sont capables de déplacer les créatures sur le champ de bataille après une attaque réussie.





**Activation** R (concentration)


**Fréquence** Une fois par heure


**Déclencheur** Vous réussissez un jet d'attaque avec une arme sur laquelle la rune de *traction* est fixée 





**Effet** La cible doit réussir un jet de @Check[reflex|dc:20|name:Rune de traction] ou être poussée de 1,50 mètre dans la direction de votre choix. Ceci est un déplacement forcé.
