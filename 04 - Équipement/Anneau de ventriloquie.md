# Anneau de ventriloquie
Le pourtour de cet élégant anneau de cuivre est gravé de minuscules images d'oiseaux chanteurs. Vous obtenez un bonus d'objet de +1 aux tests de Duperie.





**Activation** 2 (manipulation)


**Fréquence** Une fois par jour





**Effet** Vous faites tourner l'anneau sur votre doigt pour projeter votre voix par magie en produisant les effets du sort [[Ventriloquie]] (@Check[perception|dc:19]).
