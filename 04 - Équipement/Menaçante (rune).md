# Menaçante (rune)
Courante parmi les brutes qui utilisent la magie pour effrayer les autres pour les faire obéir, les runes *menaçantes* vous prêtent une formidable apparence, vous accordant un bonus d'objet de +1 aux tests d'Intimidation pour [[Contraindre]] les autres.
