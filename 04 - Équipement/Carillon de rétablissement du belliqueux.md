# Carillon de rétablissement du belliqueux
Les sculptures de ce carillon représentent des fleurs épanouies. Lorsqu'il est activé, il crée une petite aura de soins dans une @Template[emanation|distance:5]{émanation de 1,50 mètre}. Les créatures situées dans l'aura gagnent guérison accélérée 15. Cette aura reste active pendant 3 rounds. Ce carillon peut être utilisé une fois par semaine.
