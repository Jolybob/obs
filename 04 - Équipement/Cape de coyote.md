# Cape de coyote
Ce manteau poussiéreux est taillé dans une miteuse fourrure de coyote brune et grise. Vous obtenez un bonus d'objet de +1 aux tests de Survie. Si vous obtenez un succès critique à votre test de Survie pour Subsister, vous doublez le nombre de créatures supplémentaires que vous pouvez nourrir.
