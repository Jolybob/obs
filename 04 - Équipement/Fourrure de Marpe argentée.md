# Fourrure de Marpe argentée
**Activation** Lancer un sort





Une marpe qui grignote de l'argent plutôt que de l'or aura une fourrure aux pointes argentées, qui pourra être traitée pour devenir un catalyseur de sort polyvalent. Un lanceur de sort qui utilise une fourrure de marpe argentée avec un sort de [[Pique empaleuse]] créera une pique d'argent plutôt que de fer froid.
