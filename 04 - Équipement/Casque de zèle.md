# Casque de zèle
Ce casque élaboré est décoré avec les symboles d'une divinité choisie lorsque le casque a été fabriqué. Vous obtenez un bonus d'objet de +2 à la Compétence divine de cette divinité.


**Activation - Rallier à la cause** f (concentration)


**Fréquence** Une fois par jour





**Effet** Vous obtenez un Point de focalisation que vous ne pouvez utiliser que pour lancer un sort de dévotion. Si vous ne dépensez pas ce Point de focalisation avant la fin de votre tour, le point est perdu.


**Activation - Ferveur divine** f (concentration)


**Fréquence** Une fois par jour


**Déclencheur** Vous venez juste d'utiliser votre réaction de champion.





**Effet** Vous obtenez une réaction supplémentaire que vous ne pouvez utiliser que pour une réaction de champion. Vous perdez cette réaction si vous ne l'utilisez pas avant le début de votre prochain tour.





**Conditions de fabrication** Vous êtes un champion de la divinité représentée sur le casque.
