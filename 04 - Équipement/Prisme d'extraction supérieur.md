# Prisme d'extraction supérieur
**Utilisation** Fixé sur une armure


**Activation** F (concentration)


**Conditions** Vous disposez d'une main libre.





Ce prisme rectangulaire qui montre des motifs noirs tourbillonnant à l'intérieur, se déplace constamment autour de votre armure, indépendamment de l'endroit où vous l'avez fixé. Vous n'avez pas besoin d'harmoniser le prisme. Il permet de récupérer n'importe que objet en votre possession d'1 Encombrement ou inférieur. Lorsque vous activez ce talisman, vous choisissez l'objet qui se téléporte immédiatement dans votre main.


Le prisme d'extraction ne peut récupérer un objet qui n'est pas sur votre plan. Cela inclut les objets dans un espace extradimensionnel comme un *Sac spacieux*.
