# Queue fouet constrictrice
Vous disposez d'une puissante queue constrictrice. Vous obtenez une attaque à mains nues de queue qui inflige 1d6 dégâts contondants. Cette queue est dans le groupe pugilat. Vous obtenez un bonus d'objet de +1 aux tests d'Acrobaties pour [[Garder l'équilibre]] et aux tests d'Athlétisme pour Escalader. Vous pouvez également utiliser votre queue pour l'action [[Se raccrocher in extremis]], même si vos mains sont autrement occupées.


Vous pouvez utiliser votre attaque à mains nues de queue pour [[Saisir]] même si vous ne disposez pas d'une main libre. Vous obtenez un bonus d'objet de +2 aux tests d'Athlétisme pour Saisir.
