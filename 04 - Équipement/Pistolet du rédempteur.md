# Pistolet du rédempteur
Ce *pistolet de duel de frappe +2* est façonné dans un acier argenté qui brille d'une lumière radieuse. Vous pouvez choisir d'effectuer une attaque non-létale avec le pistolet du rédempteur sans subir de pénalité de -2. Si vous le faites, l'attaque inflige [[/r 1d6[mental]]]{1d6 dégâts mentaux} supplémentaires. Vous pouvez également invoquer l'esprit rédempteur contenu dans le pistolet pour juger vos ennemis.





**Activation** r (concentration)


**Fréquence** Une fois par jour


**Déclencheur** Un ennemi dans un rayon de 9 mètres vous blesse





**Effet** L'esprit protecteur contenu dans l'arme impose une vision de rédemption dans l'esprit de votre ennemi. L'ennemi doit choisir l'une des options suivantes.




- Vous n'êtes pas blessé par les dégâts déclencheurs.

- Vous obtenez une résistance à tous les dégâts contre les dégâts déclencheurs égaux à 2 + votre niveau. Après avoir appliqué les dégâts, l'ennemi est [[Affaibli 2]] jusqu'à la fin de son prochain tour et subit @Damage[4[persistent,spirit]]{4 dégâts spirituels persistants}
