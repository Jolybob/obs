# Table alchimique supérieure
Cette table alchimique solide et rigide contient des références abrégées sur la façon de mélanger rapidement les réactifs pour obtenir un effet maximal. Si vous tenez cette table en main tout en utilisant [[Alchimie rapide]], les objets de niveau 18 ou inférieur que vous créez restent actifs pendant 1 round supplémentaire.
