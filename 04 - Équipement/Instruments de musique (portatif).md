# Instruments de musique (portatif)
Les instruments portatifs comprennent les cornemuses, les petits carillons, les petits tambours, les violons et les violes, les flûtes et les flûtes à bec, les petites harpes, les luths, les trompettes et les instruments de taille similaire. Le MJ peut décider qu'un instrument portatif particulièrement imposant (comme un tuba) possède un Encombrement supérieur.
