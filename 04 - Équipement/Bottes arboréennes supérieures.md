# Bottes arboréennes supérieures
Ces bottes en cuir souples sont ornées de simples scènes forestières. Les bottes octroient un bonus d'objet de +2 aux tests d'Acrobaties et vous permettent d'ignorer le terrain difficile provoqué par les plantes ou les champignons.


Vous obtenez aussi une Vitesse d'escalade de 3 mètres sur les plantes et les champignons et vous n'avez pas besoin de vos mains pour Escalader.
