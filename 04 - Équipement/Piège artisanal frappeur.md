# Piège artisanal frappeur
Vous fixez une ligne de déclenchement ou un autre déclencheur à un groupe de pierres ou de pieux en bois pour frapper une créature qui pénètre dans la case du piège. La créature doit tenter un jet de @Check[reflex|showDC:all|dc:26|basic]. Si vous choisissez les pierres, le piège inflige @Damage[9d8[bludgeoning]]{9d8 dégâts contondants}. Si vous choisissez les pieux, il inflige @Damage[9d8[piercing]]{9d8 dégâts perforants}.
