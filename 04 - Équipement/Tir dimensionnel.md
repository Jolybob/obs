# Tir dimensionnel
**Munitions** toutes


**Activation** 2 (concentration)





Le *tir dimensionnel* est d'un bleu noir profond, mais des volutes de lumière y jouent comme des étoiles dans le ciel nocturne. La munition activée vous permet de vous téléporter à proximité de l'endroit qu'elle touche. Si vous touchez une créature, vous pouvez vous téléporter dans un espace inoccupé adjacent à cette créature. Si vous tirez sur une case, vous pouvez vous téléporter dans un espace qui contient cette case ou dans un espace inoccupé qui lui est adjacent. La téléportation échoue si aucun espace inoccupé n'est disponible pour vous.
