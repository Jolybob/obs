# La Licorne
**Couleur** Couronne (Cha)


**Alignement** chaotique bon





*La Licorne* représente la découverte de ce qu'on cherche. Tant que vous investissez *la Licorne*, vous obtenez un bonus d'objet de +2 aux tests de Perception pour [[Chercher]]. Cela passe à un bonus d'objet de +3 si vous etes au moins de niveau 17.





**Activation** 2 (concentration, manipulation)


**Fréquence** Une fois par jour





**Effet** Vous passez *La Licorne* sur un récipient adjacent fermé, puis vous ouvrez le récipient. À l'intérieur, vous trouverez un objet alchimique ou magique consommable courant dont vous avez besoin pour résoudre un problème ou faire face à une situation proche. Par exemple, si vous êtes gravement blessé, vous pouvez trouver une *Potion de guérison supérieure*. Si vous avez été empoisonné, vous pourriez découvrir une *Panacée*. Si vous êtes confronté à un indice écrit dans une langue que vous ne comprenez pas, le récipient peut contenir un *Élixir de compréhension*. Le MJ décide toujours de l'objet consommable découvert, qui doit être inférieur ou égal à votre niveau. Si l'objet consommable n'est pas utilisé dans la minute qui suit sa découverte, il disparaît. S'il n'y a pas d'objet approprié pour résoudre votre situation, le MJ peut décider qu'aucun objet n'a été trouvé. Dans ce cas, l'utilisation quotidienne de la Licorne n'est pas dépensée.
