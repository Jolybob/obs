# Menaçante supérieure (rune)
Courante parmi les brutes qui utilisent la magie pour effrayer les autres pour les faire obéir, les runes menaçantes vous prêtent une formidable apparence, vous accordant un bonus d'objet de +2 aux tests d'Intimidation pour [[Contraindre]] les autres.





**Activation** 2 (concentration, manipulation)


**Fréquence** Une fois par jour





**Effet** La rune lance un sort de [[Peur]] au rang 3 (DD 25).
