# Loupe euphorisante supérieure
**Activation** Lancer un sort





Ce catalyseur est fait de peau d'écorce de sapin déformé cueilli lors de la pleine lune. Lorsqu'il est utilisé pour Lancer le sort [[Charme]], le sort crée une expérience de béatitude pour toutes les cibles du sort. Lorsque le sort se termine, même si vous le Révoquez, la dissonance mentale entre l'état charmé et la réalité oblige toutes les cibles de *Charme* à tenter un jet de @Check[will|against:spell] contre votre DD de sort.





**Succès critique** La cible n'est pas affectée.


**Succès** La cible est [[Étourdie 1]] ou, si le sort s'est terminé à cause d'une action hostile, [[Confuse]] pendant 1 round.


**Échec** La cible est [[Étourdie 2]] ou, si le sort s'est terminé à cause d'une action hostile, Confuse pendant 1 round.


**Échec critique** La cible est [[Étourdie 3]] ou, si le sort s'est terminé à cause d'une action hostile, Confuse pendant 2 rounds.
