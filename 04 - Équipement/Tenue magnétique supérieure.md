# Tenue magnétique supérieure
**Activation** 2 (manipulation)





Cette tenue magnétisée est attachée à votre corps par-dessus votre armure ou vos vêtements. Lorsque vous l'activez, vous devez choisir de la régler pour attirer ou repousser. Après activation, le costume fournit les avantages indiqués pour le type d'activation choisi pendant 10 minutes, le temps qu'il faut pour que les aimants s'épuisent et que le costume devienne inutile.


Lorsqu'elle est réglée pour attirer, vous subissez une pénalité de statut de -2 à votre CA contre les attaques faites par des armes métalliques, tandis que les alliés situées dans une @Template[emanation|distance:15]{émanation de 4,50 mètres} autour de vous, obtiennent un bonus de statut de +2 à leur CA. Si vous êtes réglé sur repousser, vous obtenez un bonus de statut de +1 à votre CA contre les attaques faites avec des armes en métal.


Lorsque vous attirez le métal, vous obtenez un bonus de statut de +2 aux tests d'Athlétisme pour [[Escalader]] les objets métalliques et pour [[Saisir]] les créatures métalliques, mais vous subissez une pénalité de -2 aux tests d'Athlétisme pour [[Pousser]] les créatures métalliques.


Lorsque vous repoussez le métal, vous obtenez un bonus de statut de +2 aux tests d'Athlétisme pour Pousser les créatures métalliques, mais vous subissez une pénalité de statut de -2 pour Escalader les objets métalliques et Saisir les créatures métalliques.
