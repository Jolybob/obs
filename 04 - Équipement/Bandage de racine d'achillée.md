# Bandage de racine d'achillée
**Activation** [[Prodiguer les premiers soins]]





Cette racine est souvent infusée dans les bandages destinés aux hémorragies mortelles. L'activation de l'objet fait partie de la même activité que celle utilisée pour Prodiguer les premiers soins pour arrêter l'hémorragie sur une créature qui est également mourante. Lorsque vous le faites, vous pouvez Prodiguer les premiers soins pour arrêter l'hémorragie et l'état mourant dans le cadre de la même activité avec un seul test de Médecine. Cependant, le DD pour le test de Médecine est égal à 5 + le plus élevé des deux DD pour Prodiguer les premiers soins.
