# Foulard de l'allié
Les organisations achètent généralement ces simples carrés de tissu en lots importants avec un symbole invisible sur chacun. Ils aident les armées composées de troupes qui ne se connaissent pas, comme des mercenaires ou des conscrits, à reconnaître les unités alliées. Les foulards peuvent être attachés autour de la tête, du cou ou du bras. Ils peuvent également être utilisés pour démasquer les imposteurs.





**Activation - Identifier les alliés** f (concentration)


**Déclencheur** Vous vous déplacez à 4,50 mètres d'une créature portant un foulard allié correspondant





**Effet** Le symbole brille magiquement au-dessus de votre tête. Il est invisible pour tous ceux qui n'ont pas investi un foulard allié qui lui correspond.
