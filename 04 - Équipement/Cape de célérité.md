# Cape de célérité
Cette fine cape est étonnamment légère, comme si les nuages ou le vent même avaient été tissés pour la confectionner. La cape vous confère un bonus d'objet de +3 aux tests d'Acrobaties. Lorsque vous investissez la cape, soit vous augmentez votre modificateur de Dextérité de 1, soit vous le portez à +4, selon ce qui vous donne le meilleur résultat.





**Activation - Chevaucher le vent** 1 (manipulation)





**Fréquence** Une fois par jour





**Effet** Vous tirez sur la cape, vous enveloppant de la puissance du vent. Vous obtenez une Vitesse de vol de 9 mètres pendant 1 heure. Lorsque vous êtes enveloppé dans la cape, vous devenez translucide, ce qui vous permet de devenir [[Masqué]] pendant cette durée.
