# Matériel d'artisan
Vous avez besoin de ce matériel pour créer des objets à partir de matériaux bruts avec la compétence Artisanat. Différents jeux d'outils sont nécessaires pour effectuer différents travaux, tels que déterminés par le MJ. Par exemple, le matériel de forgeron diffère du matériel de menuisier. Si vous portez votre matériel d'artisan, vous pouvez le sortir et le ranger durant l'action nécessaire pour l'utiliser.
