# Noeud dimensionnel
**Activation** Lancer un sort





À l'origine, les Shelynites fabriquaient ce noeud complexe de ficelles de couleurs vives pour des bracelets destinés à lier le destin de deux personnes. Aujourd'hui, cependant, les lanceurs de sorts de toutes les religions les utilisent pour améliorer leurs capacités en matière de magie de téléportation. L'ajout de ce catalyseur à un sort de [[Translocation]] au rang 4 vous permet d'emmener avec vous une seule créature adjacente consentante. Cependant, la téléportation est quelque peu déroutante pour cette créature, ce qui la rendra [[Étourdie]] 1.
