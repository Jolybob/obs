# Bâton de fantasmes majeur
Ce bâton en métal orné brille avec de précieuses incrustations d'or. Lorsque vous lancez un sort à partir de ce bâton, l'image illusoire d'une chose que vous désirez clignote à sa surface. Lorsque vous maniez le bâton, vous bénéficiez d'un bonus de statut de +2 aux tests pour percer une illusion.


**Activation** Lancer un sort


**Effet** Vous dépensez un certain nombre de charges du bâton pour lancer un sort de sa liste.




- **Tour de magie** [[Fantasme]]

- **1er** [[Déguisement illusoire]], [[Objet illusoire]]

- **2e** [[Créature illusoire]], [[Façade]], [[Objet illusoire]]

- **3e** [[Déguisement illusoire]], [[Façade]]

- **4e** [[Créature illusoire]], [[Déguisement illusoire]], [[Scène illusoire]]

- **5e** [[Créature illusoire]], [[Scène illusoire]]

- **6e** [[Double illusoire]], [[Hallucination]]




**Conditions de fabrication** Fournir une incantation de tous les sorts de la liste et à tous les rangs énumérés.
