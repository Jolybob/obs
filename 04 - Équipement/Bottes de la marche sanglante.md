# Bottes de la marche sanglante
Ces bottes en cuir rouge absorbent avidement tout sang qui la touche.


**Activation - Bond sanglant** 2 (concentration, manipulation)


**Fréquence** Une fois par heure





**Effet** Les bottes produisent une petite flaque de sang sous vos pieds et dans un espace que vous pouvez voir dans les 36 mètres. Vous vous fondez dans la flaque dans laquelle vous êtes pour vous reconstituer dans l'autre, avec les effets de [[Translocation]].


**Activation - Marche dans le sang** 1 minute (concentration, manipulation)


**Fréquency** Une fois par jour


**Conditions** Vous vous tenez sur du sang





**Effet** Vous vous fondez dans le sol te vous vous reconstituez dans un lieu qye vous avez précédemment vu dans un rayon de 150 kilomètres, avec les effets de *Translocation*. Cet effet échoue si aucune créature douée de conscience n'est morte en ce lieu au cours des 24 heures précédentes.
