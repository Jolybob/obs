# Réservoir de sort (rune)
Une rune de *réservoir de sort* crée un réservoir d'énergie mystique à l'intérieur de l'arme gravée. Un incantateur peut passer une minute à lancer un sort de rang inférieur ou égal à 3 dans l'arme. Le sort doit avoir un temps d'incantation de 2 actions au maximum et doit être capable de cibler une créature autre que le lanceur. Le sort ne produit aucun effet immédiat — il est stocké à la place pour plus tard.


Quand vous maniez une arme *de réservoir de sort*, vous connaissez immédiatement le nom et le rang du sort stocké. Une arme *de réservoir de sort* trouvée en tant que trésor a 50 % de chances de contenir un sort au choix du MJ.





**Activation - Libération canalisée** 2 (concentration)


**Conditions** Un sort est emmagasiné dans l'arme





**Effet** Faites une Frappe avec l'arme. Vous dépensez le sort stocké dans le cadre de cette attaque. Cela vide l'arme de son sort et permet de lancer à nouveau un sort dans l'arme. Si le coup touche, le sort cible la cible de l'attaque. Si le sort nécessite un jet d'attaque, le résultat de votre jet d'attaque avec l'arme détermine le degré de réussite du sort et, si le sort nécessite un jet de sauvegarde, le DD est de 30.





**Activation - Libération sûre** A (concentration)





**Effet** Permet de dépenser le sort stocké de manière inoffensive. Ceci vide l'arme pour permettre d'incanter un nouveau sort à l'intérieur.
