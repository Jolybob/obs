# Bottes arboréennes
Ces bottes en cuir souples sont ornées de simples scènes forestières. Les bottes octroient un bonus d'objet de +1 aux tests d'Acrobaties et vous permet d'ignorer le terrain difficile provoqué par les plantes ou les champignons.
