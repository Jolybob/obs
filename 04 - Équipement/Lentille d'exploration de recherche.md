# Lentille d'exploration de recherche
**Activation** 1 (manipulation)





Une *lentille d'exploration* est une lentille de verre magique conçue pour une [[Lanterne à capote]]. Lorsque la lumière de la lanterne passe à travers la lentille, elle modifie la lumière pour faciliter l'exécution d'une activité d'exploration courante avec la lanterne.


De manière alternative, une *lentille d'exploration* peut être installée dans un [[Guide]] comme une *pierre d'éternité*. Dans ce cas, la lumière (comme celle d'une [[Lanterne à capote]], d'une [[Torche]] ou d'un sort de [[Lumière]]) doit néanmoins toujours passer à travers la lentille et vous devez tenir le Guide dans votre main pour qu'il fonctionne.


Il existe plusieurs types de *lentilles d'exploration*, chacune accordant des avantages avec un type d'activité d'exploration différent. Chaque type de lentille se distingue de tous les autres types en la tenant devant une lumière vive. Cette lentille a un éclat opalescent lorsqu'elle est tenue à la lumière.


La lentille souligne subtilement les portes cachées et les dangers dissimulés, vous accordant un bonus d'objet de +2 aux tests de Perception pour repérer de tels éléments au cours de l'activité [[Fouiller]].


Même si vous ne Fouillez pas, vous bénéficiez d'un test pour trouver les pièges qui nécessitent normalement que vous soyez en train de Fouiller.
