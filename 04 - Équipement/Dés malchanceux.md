# Dés malchanceux
Sculptés dans de l'os, les dés malchanceux ressemblent à jeu de dés pipés. S'ils ne sont pas identifiés avec succès comme maudits, les dés malchanceux semblent contenir un enchantement mineur qui améliore votre chance. Quoi qu'il en soit, ils fusionnent avec vous lorsque vous les utilisez, vous accablant de malchance. Les dés malchanceux ne vous accordent pas de bonus sur les tests de Connaissance des jeux. Au lieu de cela, lorsque vous les utilisez pour jouer, le MJ lance secrètement le dé, vous accordant le résultat le plus faible. Une fois que vous réalisez que les dés sont maudits, le MJ peut à la place vous autoriser à lancer deux fois les dés pour prendre le résultat inférieur.
