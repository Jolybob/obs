# Maille réactive supérieure
Souvent lourdement marquée par les combats, cette *cotte de mailles de résilience +1* est généralement délivrée aux soldats de première ligne qui ont pour mission de se frayer un chemin à travers les ennemis pour atteindre des cibles de haute valeur sur le champ de bataille.


**Activation - Pointe rapide** r (manipulation, métal)


**Fréquence** Une fois par heure


**Déclencheur** Une créature dans un rayon de 4,50 mètres utilise une action de manipulation





**Effet** Votre armure projette une pointe de fer sur la cible, lui infligeant @Damage[5d8[piercing]]{5d8 dégâts perforants} (@Check[reflex|dc:28|basic]). Si la cible obtient un échec critique, l'action déclencheuse est interrompue.
