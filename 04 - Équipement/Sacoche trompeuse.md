# Sacoche trompeuse
Cette sacoche en cuir marron est fabriquée à partir d'un cuir rustique fortement huilé. La sacoche est assez grande pour contenir des objets d'une valeur de 1 Encombrement.





**Activation** 1 minute (concentration, manipulation)





**Effet** Les documents contenus dans le havresac sont magiquement déguisés en documents de même type mais contenant des informations trompeuses. Toute personne qui inspecte un document remarque le subterfuge avec un test de @Check[perception|dc:20|name:remarquer le subterfuge|showDC:all] réussi, mais pour déterminer le texte réel, un jet de @Check[society|dc:20|name:déchiffrement|traits:action:decipher-writing|showDC:all] réussi est nécessaire pour Déchiffrer le texte. Cela dure jusqu'à ce que vous utilisiez à nouveau cette activation, ce qui met fin à l'effet pour tous les documents précédemment déguisés, jusqu'à ce que vous utilisiez la deuxième activation pour mettre fin à l'effet pour un seul document ou jusqu'à ce qu'un document dans le havresac reste à l'extérieur du havresac pendant au moins 1 heure, ce qui met fin à l'effet pour ce document.





**Activation** 1 (concentration)





**Effet** Vous rétablissez l'un des documents en version originale.
