# Queue fouet
Vous disposez d'une puissante queue préhensile. Vous obtenez une attaque à mains nues de queue qui inflige 1d6 dégâts contondants. Cette queue est dans le groupe pugilat. Vous obtenez un bonus d'objet de +1 aux tests d'Acrobaties pour [[Garder l'équilibre]] et aux tests d'Athlétisme pour Escalader. Vous pouvez également utiliser votre queue pour l'action [[Se raccrocher in extremis]], même si vos mains sont autrement occupées.
