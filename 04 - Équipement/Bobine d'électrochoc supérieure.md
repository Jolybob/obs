# Bobine d'électrochoc supérieure
Contenu dans un petit tube de verre se trouve un filament de fil torsadé crépitant d'électricité, envoyant des picotements d'électricité statique dans les cheveux de quiconque le tient. Le DD de tout sort lancé en activant cet objet est de 24.




- **Arme** Après avoir Lancé un sort d'électricité en activant la bobine, les Frappes avec l'arme infligent 1d6 dégâts d'électricité supplémentaires jusqu'à la fin de votre prochain tour.

- **Armure** Vous obtenez une résistance 3 contre l'électricité.
