# Lunettes d'obsidienne
Les verres noirs et élégants de ces lunettes donnent l'impression que tout est mieux éclairé. Lorsque vous portez ces lunettes, vous bénéficiez d'un bonus d'objet de +1 aux tests de Perception impliquant la vue.





**Activation - Vision dans le noir** 1 (manipulation)


**Fréquence** Une fois par jour





**Effet** En ajustant vos lunettes, vous obtenez vision dans le noir.
