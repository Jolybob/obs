# Charme de contre
Cette amulette scintillante est composée d'une pierre précieuse imparfaite avec une inclusion en plomb. Les incantateurs peuvent lancer des sorts dans ce *Charme de contre* qu'ils ont investi ou qui est investi par une créature consentante. Les effets du sort ne se manifestent pas mais sa puissance est plutôt emmagasinée dans le charme, remplaçant tout sort qui précédemment contenu. Le charme ne peut contenir que des sorts lancés à partir d'emplacement de sorts et ne peut contenir ni tour de magie ni sort focalisé. Tant que le charme est investi, la créature qui l'a investie connaît le sort qui est emmagasiné et l'identifie automatiquement lorsqu'il est lancé.


**Activation - Contre** R (manipulation)


**Déclencheur** Vous êtes la cible ou dans la zone du sort stocké dans votre amulette


**Conditions** Vous disposez d'une main libre





**Effet** Vous présentez votre amulette et tentez de contrer le sort déclencheur, utilisant le rang de sort qui est emmagasiné et un modificateur de contre de [[/r 1d20+20 #Contrer]]{+20}. Ceci dépense le sort qui est contenu dans le charme.
