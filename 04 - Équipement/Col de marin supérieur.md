# Col de marin supérieur
Les marins aguerris aiment porter ce col bleu élégant, noué d'un petit nœud sur le devant et glissé dans la ceinture. Il peut même vous sauver la vie si vous tombez par-dessus bord. Lorsque vous portez le *col marin*, vous obtenez un bonus d'objet de +2 aux tests d'Athlétisme.


**Activation - Bouffée d'air** r (air, concentration)


**Fréquence** Une fois par jour


**Déclencheur** Vous obtenez un échec sur un test pour Nager





**Effet** Votre col se gonfle en vous permettant de trouver de l'air pour respirer. Vous pouvez respirer sous l'eau et vous obtenez une Vitesse de nage de 3 mètres pendant 1 minute.
