# Mutagène d'énergie inférieur
**Activation** 1 (manipulation)





Lorsqu'il est créé, ce mutagène est accordé à l'un des quatre types d'énergie suivants : acide, électricité, feu ou froid. Lorsqu'il est consommé, le mutagène imprègne votre corps d'une énergie qui se déclenche à chaque attaque. Ces effets durent 1 minute.


**Avantage** Vous obtenez une résistance 5 contre le type d'énergie accordée. Chaque fois que vous touchez avec une arme au corps-à-corps, ajoutez 1 point de dégât du type d'énergie accordé.


**Inconvénient** Vous subissez une faiblesse 5 contre les trois autres types d'énergie.
