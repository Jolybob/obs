# Brindille de Sakura
**Activation** F (concentration)


**Déclencheur** Vous Frappez une cible impie avec l'arme à laquelle elle est fixée


**Conditions** Vous êtes qualifié avec l'arme à laquelle elle est fixée.





Cette petite brindille brillante de fleurs de cerisier est seulement accordée par Sakura, le kami d'Arbre argenté. Lorsqu'il est activé, l'arme à laquelle il est fixé obtient le trait saint pour l'attaque déclencheuse et tous les autres attaques pendant 1 minute.
