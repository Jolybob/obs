# Gourdin cauchemar
Fabriqué en bois poli, ce *gourdin de frappe +1* est doté d'une lanière de cuir rouge près du manche. La simple vue du gourdin dans la main d'un garde remplit les prisonniers d'effroi.


Les créatures bonnes sont [[Affaiblies 2]] lorsqu'elles transportent, manient ou portent cet objet fabriqué par les sorcières des mers.





**Activation** 2Interagir (émotion, mental)


**Fréquence** Une fois par jour


**Effet** Vous initiez une démarche intimidante, en frappant le gourdin de manière menaçante contre votre paume. Dans le cadre de l'activation de cet objet, vous pouvez Marcher rapidement deux fois. Pendant la minute suivante, chaque fois que vous réussissez à frapper une créature avec le *gourdin cauchemar*, vous pouvez utiliser une action gratuite pour tenter un test d'Intimidation pour [[Démoraliser]] la cible touchée.
