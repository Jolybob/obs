# Piège artisanal du drake de feu
Le piège artisanal prend la forme d'un minuscule jouet mécanique rappelant un drake. Lorsqu'une créature pénètre dans sa case, le piège s'active, le drake crachant un @Template[cone|distance:15]{cône de feu de 4,50 mètres} dans la direction par laquelle la créature est entrée dans la case.


Par exemple, si la créature est entrée dans la case venant de l'est, le cône pointerait vers l'est afin de toucher tous les alliés derrière la créature déclencheuse. Les créatures dans le cône subissent @Damage[6d6[fire]|options:area-damage]{6d6 dégâts de feu} (@Check[reflex|dc:19|basic|options:area-effect]). Dès qu'il a craché son feu, le piège se désintègre.
