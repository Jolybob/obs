# Huile tueuse
**Activation** 1 (manipulation)





L'*huile tueuse* se présente sous autant de formes que la rune de propriété d'arme *tueuse*. Enduire une arme de cette huile lui permet de bénéficier d'un type de rune [[tueuse]] pendant 1 minute. Une arme ne peut être enduite que d'un seul type d'*huile tueuse* à la fois. Toute nouvelle application de cette huile prend le pas sur une huile précédente. Si une arme possède la rune *tueuse*, cette huile ne produit aucun effet si elle est du même type que la rune.
