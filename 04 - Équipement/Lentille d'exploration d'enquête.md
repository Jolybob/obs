# Lentille d'exploration d'enquête
**Activation** 1 (manipulation)





Une *lentille d'exploration* est une lentille de verre magique conçue pour une [[Lanterne à capote]]. Lorsque la lumière de la lanterne passe à travers la lentille, elle modifie la lumière pour faciliter l'exécution d'une activité d'exploration courante avec la lanterne.


De manière alternative, une *lentille d'exploration* peut être installée dans un [[Guide]] comme une *pierre d'éternité*. Dans ce cas, la lumière (comme celle d'une [[Lanterne à capote]], d'une [[Torche]] ou d'un sort de [[Lumière]]) doit néanmoins toujours passer à travers la lentille et vous devez tenir le Guide dans votre main pour qu'il fonctionne.


Il existe plusieurs types de *lentilles d'exploration*, chacune accordant des avantages avec un type d'activité d'exploration différent. Chaque type de lentille se distingue de tous les autres types en la tenant devant une lumière vive. Le bord extérieur de cette lentille brille faiblement lorsqu'on la tient à la lumière.





Lorsqu'elle est activée, la lentille vous accorde un bonus d'objet de +1 aux tests de compétence pour Vous souvenir lorsque vous [[Enquêtez]] en soulignant les indices potentiels d'une manière qui fait fonctionner votre mémoire.


Si vous enquêtez sur quelque chose tout en utilisant la lentille, vous pouvez toujours lancer un test pour Vous souvenir avec la compétence appropriée à l'enquête pour déterminer l'initiative.
