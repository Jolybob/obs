# Lumière sans mort
**Activation** 1 (concentration)





Ce morceau de chair brillant augmente le rang du sort d'un sort avec le trait lumière de 1 (maximum 7) lorsque vous déterminez si la lumière du sort brillera dans les ténèbres magiques ou contrer un sort de [[Ténèbres]].
