# Mouchoir de passe-passe
Ce mouchoir gris argenté à volants possède toutes les apparences d'être un accessoire élégant pour l'hygiène personnelle, mais il peut être utilisé pour faire disparaître discrètement de très petits objets.





**Activation** 1 (manipulation)


**Conditions** Le mouchoir couvre entièrement un objet d'Encombrement négligeable





**Effet** Le mouchoir transporte l'objet qu'il recouvre dans son espace extradimensionnel. Le mouchoir ne peut contenir qu'un seul objet à la fois dans son espace extradimensionnel, de sorte que tout objet pris est remplacé par tout objet déjà présent dans l'espace. Vous pouvez également utiliser cette action pour expulser un objet déjà présent dans l'espace extradimensionnel sans le remplacer. Cette activation ne peut pas être utilisée sur un objet surveillé à moins que la créature qui l'a en sa possession ne le permette. Placer le mouchoir sur un objet nécessite généralement une action Interagir.
