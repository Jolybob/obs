# Manteau vivant supérieur
La base de cette cape est une épaisse couche de mousse, mais elle ramasse lentement les plantes indigènes de chaque zone dans laquelle elle passe du temps. Vous obtenez un bonus d'objet de + 3 aux tests de Nature. Vous ne subissez aucun dégât à cause du froid modéré ou important.





**Activation - Secrets druidiques** F (concentration)


**Fréquence** Une fois par jour





**Effet** Vous obtenez 1 Point de focalisation que vous ne pouvez dépenser que pour lancer un sort d'ordre. Si vous dépensez pas de Point de focalisation à la fin de ce tour, il est perdu.





**Conditions de fabrication** Vous êtes un druide.
