# Jeux (dés pipés)
Un assortiment quasi infini de jeux existe sur Golarion. Les jeux simples, notamment les dés, un jeu de cartes ou des dominos, coûtent 5 pièces d'argent. Les jeux de société coûtent entre 1 pièce d'or pour les jeux de dextérité comme Bungle, 3 pièces d'or pour les jeux colorés pour enfants comme La Quête du Chaudron et 5 pièces d'or pour les jeux de stratégie complexes comme Faiseur de rois et les Raiders d'Abendego. Les somptueux ensembles de jeux peuvent coûter beaucoup plus que ces prix car ils sont constitués de composants coûteux et sont des œuvres d'art complexes à part entière.





Ces dés sont pipés d'un côté pour s'assurer qu'ils atterrissent toujours avec le nombre désiré tourné vers le haut. Les dés pipés vous accordent un bonus d'objet de +1 aux tests de Connaissance ludique pour jouer avec les dés. Vous pouvez déterminer qu'un dé est pipé en le manipulant, en réussissant un test de @Check[perception|dc:20|name:Dés pipés]. Il est plus difficile de déterminer si les dés sont pipés sans les manipuler, d'autant plus que les tricheurs malins échangent les dés pipés avec des dés normaux pour ne pas obtenir le même nombre de façon suspecte. Dans ce cas, un observateur doit réussir un test secret de Perception contre le DD de Connaissance ludique ou de Vol du lanceur pour remarquer les changements ou les schémas.
