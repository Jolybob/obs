# Jeu de cartes
Un jeu de cartes standard se compose de 54 cartes en papier épais contenues dans un étui en papier. Le jeu le plus communément utilisé pour les jeux et les paris est connu sous le nom de jeu du vieux mage et comporte quatre couleurs ayant pour thème les quatre essences de la magie, chacune avec 13 cartes, ainsi que deux jokers. Le nom et l'apparence du jeu de cartes varient d'une région à l'autre, comme le jeu du magicien à Taldor ou le jeu des Masques dans les Chaînes.
