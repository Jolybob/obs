# Lunettes d'obsidienne supérieures
Les verres noirs et élégants de ces lunettes donnent l'impression que tout est mieux éclairé. Lorsque vous portez ces lunettes, vous bénéficiez d'un bonus d'objet de +2 aux tests de Perception impliquant la vue.





**Activation - Vision dans le noir** 1 (manipulation)


**Fréquence** n'importe quel nombre de fois par jour





**Effet** En ajustant vos lunettes, vous obtenez vision dans le noir jusqu'à ce que vous les désactiviez par une unique action Interagir ou que vous cessiez de les investir, selon ce qui se produit en premier.
