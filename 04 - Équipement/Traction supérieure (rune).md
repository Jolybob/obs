# Traction supérieure (rune)
Les armes de *traction* sont capables de déplacer les créatures sur le champ de bataille après une attaque réussie.





**Activation** R (concentration)


**Fréquence** Une fois par heure


**Déclencheur** Vous réussissez un jet d'attaque pour Frapper avec une arme sur laquelle la rune de *traction supérieure* est gravée





**Effet** La cible doit réussir un jet de @Check[reflex|dc:28|name:Rune de traction supérieure] ou être déplacée de 3 mètres dans la direction de votre choix. Ceci est un déplacement forcé.
