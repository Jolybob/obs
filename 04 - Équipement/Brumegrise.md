# Brumegrise
Cette cape noire semble s'écouler davantage comme un liquide vaporeux plutôt que comme un tissu. La cape vous accorde un bonus d'objet de +3 pour les tests de Discrétion. Lorsque vous investissez la cape, soit vous augmentez votre modificateur de Dextérité de 1, soit vous le passez à +4, selon ce qui vous accorde le résultat le plus élevé.





**Activation** R (manipulation)


**Fréquence** Une fois par heure


**Déclencheur** Une créature vous manque avec une attaque


**Effet** Faites un test de Discrétion contre le DD de Perception de la créature déclencheuse. Si vous obtenez un succès, vous êtes [[Caché]] de cette créature jusqu'à la fin de votre prochain tour ou juste après avoir utiliser une action hostile contre cette creature. Si vous obtenez un succès critique, vous êtes Caché de cette créature jusqu'à la fin de votre prochain tour, même si vous utilisez des actions hostiles contre cette créature.





**Activation** 2 (manipulation)


**Fréquence** Une fois par jour


**Effet** D'un mouvement de la cape, vous vous transformez en une bouffée de fumée grise. Vous Lancez [[Forme vaporeuse]] sur vous-même.
