# Griffe de prédateur
**Activation** F (concentration)


**Déclencheur** Vous obtenez un coup critique sur un jet d'attaque avec l'arme support.





Cette griffe sertie dans une broche de fer attachée par une chaîne est habituellement celle d'un grand prédateur. Lorsque vous activez la griffe, l'attaque déclencheuse obtient l'effet critique spécialisé de l'arme.
