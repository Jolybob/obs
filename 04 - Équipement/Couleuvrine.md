# Couleuvrine
Populaires parmi les corsaires et les mercenaires de Goka, les couleuvrines ne sont guère plus qu'un tube durci auquel sont attachés une poignée et un allumage externe. La couleuvrine peut être utilisée pour tirer presque tout ce qui peut être placé dans son canon. Le porteur d'une couleuvrine peut changer le type de dégât accordé par son trait configurable dans le cadre de l'action Interagir utilisée pour recharger.





Cette arme utilise notamment les [[Munitions (Couleuvrine)]]
