# Fourreau de parade
Vous pouvez tirer ce fourreau renforcé lors de la même action Interagir que vous utilisez pour tirer l'arme qu'il contient, en maniant l'arme dans une main et le fourreau dans l'autre. Un fourreau de parade peut être utilisé pour votre défense de la même manière qu'une arme avec le trait de parade : vous pouvez dépenser une action pour le positionner de manière défensive, obtenant un bonus de circonstances de +1 à la CA jusqu'au début de votre prochain tour. Les fourreaux de parade sont disponibles pour n'importe quelle épée qui peut être maniée à une main.
