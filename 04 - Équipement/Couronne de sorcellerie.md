# Couronne de sorcellerie
Accoutrement élégant pour un sorcier qui a atteint les échelons supérieurs du pouvoir, cette *Couronne de sorcellerie* est habituellement composée d'une guirlande de rameaux fleuris, d'un fin diadème incrusté de pierres précieuses ou d'un grand chapeau composé de tissu fin. Vous obtenez un bonus d'objet de +1 aux tests d'Intimidation et, si vous êtes un sorcier, vous obtenez un bonus d'objet de +2 dans la compétence octroyée par votre patron.


Si vous avez une familier, vous pouvez attacher une petite partie du matériau dans lequel est fait la couronne à votre familier, comme un morceau de tissu du chapeau noué autour de queue ou un brin de matériau naturel glissé dans son collier. Le familier n'a pas besoin d'investir l'objet en lui-même. Si vous le faites, votre familier obtient le pouvoir de familier Robuste tant que investissez la Couronne.


**Activation - Maléfice du défi** F (concentration)


**Fréquence** Une fois par jour





**Effet** Vous obtenez 1 Point de focalisation que vous ne pouvez dépenser que pour lancer un sort de maléfice. Si vous ne dépensez par ce point avant la fin de ce tour, le point est perdu.





**Conditions de fabrication** Vous êtes un sorcier.
