# Vapeurs de pêcheur céleste
**Activation** Lancer un sort





Les vapeurs de pêcheur céleste ne sont visibles que par leur effet sur un sort de [[Nuage toxique]] ou plutôt par leur manque de visibilité. Ces gaz font que le nuage invoqué sera aussi transparent qu'un pêcheur céleste. Le nuage est invisible, ce qui signifie qu'il ne fournit aucune camouflage, mais qu'il faut réussir un test de @Check[perception]{Perception} contre votre DD de sort pour remarquer le nuage par le biais des légères distorsions dans l'air. Votre lien magique avec le nuage vous permet de toujours savoir où il se trouve. Cet effet n'a aucun impact sur ses dégâts.
