# Maille réactive majeure
Souvent lourdement marquée par les combats, cette *cotte de mailles de résilience supérieure +2* est généralement délivrée aux soldats de première ligne qui ont pour mission de se frayer un chemin à travers les ennemis pour atteindre des cibles de haute valeur sur le champ de bataille.


**Activation - Pointe rapide** r (manipulation, métal)


**Fréquence** Une fois par heure


**Déclencheur** Une créature dans un rayon de 4,50 mètres utilise une action de manipulation





**Effet** Votre armure projette une pointe de fer sur la cible, lui infligeant @Damage[7d8[piercing]]{7d8 dégâts perforants} (@Check[reflex|dc:36|basic]). Si la cible obtient un échec critique, l'action déclencheuse est interrompue.
