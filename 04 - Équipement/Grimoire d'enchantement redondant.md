# Grimoire d'enchantement redondant
En ouvrant le livre, on entend des chuchotements dans le vent ou des rires qui résonnent dans le lointain.





**Activation - Conserver l'incantation** F (concentration)


**Fréquence** Une fois par jour


**Déclencheur** Vous lancez un sort mental préparé à partir de ce grimoire qui n'a aucun effet car toutes les cibles ont réussi leurs jets de sauvegarde de manière critique.





**Effet** Vous détournez rapidement l'énergie de l'enchantement ratée en vous-même pour conserver votre sort favori à la place d'un autre. Vous perdez un autre sort que vous avez préparé d'un rang supérieur ou égal à celui du sort mental qui a constitué le déclencheur mais vous conservez la capacité de Lancer le sort mental de nouveau.
