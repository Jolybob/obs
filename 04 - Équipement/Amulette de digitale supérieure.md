# Amulette de digitale supérieure
Ce petit morceau de bois est finement sculpté pour représenter une digitale. Le DD de sort de tout sort lancé en activant cet objet est de 24.




- **Arme** Après avoir lancé un sort de plante en activant l'*amulette digitale*, Vos Frappes avec l'arme à laquelle elle est attachée pour infliger 1d6 dégâts de poison supplémentaires jusqu'à la fin de votre prochain tour.

- **Armure** Vous obtenez une résistance 5 contre les dégâts de poison.

**Activation** Lancer un sort





**Effet** Vous lancez [[Bouffée de poison]].





**Activation** Lancer un sort


**Fréquence** Une fois par jour
