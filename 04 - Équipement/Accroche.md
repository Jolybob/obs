# Accroche
Cet objet animé tente de vous rattraper lorsque vous tombez. Vous pouvez tenter de [[Vous raccrocher in extremis]], même si vos mains sont attachées dans votre dos ou si vous êtes par ailleurs [[Entravé]], tant qu'il y a un bord solide à moins de 3 mètres. Si vous obtenez un succès, vous pouvez vous Raccrocher in extremis même si vous n'avez pas une main de libre.
