# Maille réactive
Souvent lourdement marquée par les combats, cette cotte de mailles est généralement délivrée aux soldats de première ligne qui ont pour mission de se frayer un chemin à travers les ennemis pour atteindre des cibles de haute valeur sur le champ de bataille.


**Activation - Pointe rapide** r (manipulation, métal)


**Fréquence** Une fois par heure


**Déclencheur** Une créature dans un rayon de 4,50 mètres utilise une action de manipulation





**Effet** Votre armure projette une pointe de fer sur la cible, lui infligeant @Damage[2d8[piercing]]{2d8 dégâts perforants} (@Check[reflex|dc:20|basic]). Si la cible obtient un échec critique, l'action déclencheuse est interrompue.
