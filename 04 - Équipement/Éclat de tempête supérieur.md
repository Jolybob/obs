# Éclat de tempête supérieur
Ces éclats d'essence nécromantique coalescente sont parfois trouvés dans le sillage d'une tempête d'ancêtres. Des esprits hurlants sont faiblement visibles, piégés à l'intérieur du verre déchiqueté et vert foncé.


Vous pouvez utiliser l'éclat pour vacher les morts-vivants ou libérer brièvement les âmes tourmentées de l'intérieur du verre. Tant que vous tenez l'éclat, vous bénéficiez d'un bonus d'objet de +2 aux tests d'Intimidation pour influencer les morts-vivants. Lorsque vous tentez l'*Éclat de tempête*, vous obtenez un bonus d'objet de +1 aux tests d'Intimidation pour influencer les morts-vivants. De plus, vous pouvez [[Démoraliser]] les créatures mortes-vivantes, même si ces créatures sont dénuées d'intelligence ou est autrement immunisée aux effets d'émotion, de terreur ou aux effets mentaux.


**Activation - Libérer les esprits** 2 (concentration, manipulation)


**Fréquence** Une fois par jour





**Effet** Vous libérez brièvement les esprits de l'*Éclat de tempête* avant de les faire revenir dans le verre. Chaque créature dans une @Template[emanation|distance:10]{émanation de 3 mètres} subit @Damage[4d8[void]]{4d8 dégâts de vide} (@Check[fortitude|dc:29|basic]). Vous considérez le résultat de votre jet de sauvegarde d'un degré de succès supérieur au résultat obtenu. Vous pouvez choisir d'augmenter le rayon de l'émanation jusqu'à 3 mètres.
