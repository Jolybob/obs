# Cape de coyote supérieure
Ce manteau poussiéreux est taillé dans une miteuse fourrure de coyote brune et grise. Vous obtenez un bonus d'objet de +2 aux tests de Survie. Si vous obtenez un succès critique à un test de Survie pour Subsister, vous quadruplez le nombre de créatures supplémentaires que vous pouvez nourrir.
