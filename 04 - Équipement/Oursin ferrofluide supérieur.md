# Oursin ferrofluide supérieur
**Activation** F (concentration)


**Prérequis** Vous possédez l'effet de spécialisation de l'armure sur laquelle il est fixé


**Déclencheur** Vous subissez des dégâts physiques.





Ce globule hérissé de liquide magnétique se fixe directement sur le métal de votre armure. Lorsque vous activez le globule, il se déforme pour dévier les dégâts. Vous obtenez une résistance 10 contre les dégâts déclencheurs.
