# Remèdes merveilleux supérieur
Ce matériel de guérisseur contient une réserve inépuisable de bandages, d'herbes et d'objets curatifs d'une qualité irréprochable qui vous accordent un bonus d'objet de +3 aux tests de Médecine.


Si vous utilisez les *remèdes merveilleux* pour [[Soigner un empoisonnement]] ou [[Soigner une maladie]], avant de lancer les dés, les médicaments tentent de contrer les effets de poison ou de maladie que vous traitez avec un rang de contre de 8 et un modificateur de contre de [[/r 1d20+30 #Contrer]]{+30}. Ceci est un effet de guérison.


Une fois les remèdes utilisés pour soigner l'empoisonnement ou la maladie d'un patient, vous ne pouvez pas les réutiliser pour soigner la même affliction chez ce patient.
