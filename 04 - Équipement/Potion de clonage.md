# Potion de clonage
**Activation** 1 (manipulation)





Lorsque vous buvez une potion de clonage, vous vous séparez en deux, une version de vous restant dans votre espace et l'autre se déplaçant dans un espace adjacent. Votre clone, qui possède le trait sbire, vous ressemble et reste dans votre espace pendant 1 minute. Si vous êtes tous deux sur le même plan, vous pouvez Diriger votre clone par télépathie par une action unique avec le trait concentration. Vous pouvez également lui donner des ordres verbaux, comme à l'ordinaire pour un sbire. Après une action avec le trait concentration, vous pouvez ressentir à travers votre clone. Dans ce cas, vous perdez toutes les informations sensorielles de votre propre corps. Vous pouvez annuler cet effet de partage des sens.


Vous et votre clone partagez les Points de vie et le clone utilise vos statistiques. Les sorts et les effets vous ciblent, vous et votre clone comme si vous étiez des créatures séparées. Le clone peut Activer vos capacités et Lance vos sorts, limité par son nombre d'actions, mais vous partagez les éléments tels que les limites d'utilisation, la fréquence et les emplacements de sorts. En d'autres mots, votre clone utilisant une de vos ressources fonctionne comme si vous le faisiez ou à partir de l'espace de votre clone. Votre clone possède un équipement identique au vôtre, sauf les artefacts et les consommables. Tout objet pris du clone fond en une poussière argentée dans les secondes, avec les munitions ou les objets lancés durent juste assez longtemps pour voyager jusqu'à et possiblement toucher leur cible.


Lorsque la durée s'est écoulée, votre clone fond en une poussière argentée. Vous devenez temporairement immunisée à la potion de clonage pendant [[/r 1d4 #jours]]{1d4 jours}.
