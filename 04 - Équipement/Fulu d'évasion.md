# Fulu d'évasion
**Activation** F (concentration)


**Déclencheur** Vous tenter de [[Vous échapper]].





Le *Fulu d'évasion* est un charme courant parmi les gens riches, qui portent le talisman en case de kidnapping. Lorsque vous Activez ce fulu, pendant 1 minute, vous obtenez un bonus de statut de +2 à vos tests pour Vous échapper ainsi qu'aux tests de Discrétion pour se [[Cacher]] et [[Être furtif]].
