# Cartes de sort du Tourment
Fabriquée dans un papier solide, chaque carte de ce jeu du Tourment présente une belle illustration à l'aquarelle avec de l'espace pour inscrire un sort en dessous. Lorsqu'elles sont battues, les cartes semblent se mélanger entre elles de leur propre chef.





**Activation** F (concentration, fortune)


**Fréquence** Une fois par jour


**Déclencheur** Votre dernière action a consisté à Lancer un sort à partir de ce grimoire qui possède le trait détection, prédiction, révélation ou scrutation





**Effet** Vous tirez une carte pour vous faire une idée des défis que vous aurez à relever. Tirez une carte de la pioche du jeu du Tourment ou lancez [[/r 1d6]]{1d6} :




- Marteaux (Athlétisme)

- Clés (Acrobaties)

- Boucliers (Survie)

- Livres (n'importe quel test pour Se souvenir)

- Étoiles (Religion)

- Couronnes (Diplomatie)

La prochaine fois que vous ferez un test du même type que votre résultat, lancez deux fois le dé et prenez le meilleur résultat car les esprits du Tourment guident vos actions. Si vous ne l'utilisez pas avant vos prochains préparatifs quotidiens, cet avantage disparaît.
